# ORE6072

> '…' calls itself, so it needs a return type annotation.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A generic nested function or generic function literal of a `const` calls
itself, but its return type is not annotated. The result type of an
instance is inferred from its body, which is not checked yet where it
calls itself.

## Example

```ts
function main() {
    const depth = <T>(xs: T[], i: int) => (i >= xs.length ? 0 : 1 + depth(xs, i + 1))
    console.log(depth([1, 2], 0))
}
```

## How to fix

Annotate the return type:

```ts
function main() {
    const depth = <T>(xs: T[], i: int): int => (i >= xs.length ? 0 : 1 + depth(xs, i + 1))
    console.log(depth([1, 2], 0))
}
```
