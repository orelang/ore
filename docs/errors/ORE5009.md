# ORE5009

> Definitely-assigned fields are not supported.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A definite assignment assertion (`x!: T`) tells TypeScript to trust that a
field is assigned somewhere. Ore does not support it: a field is
initialized in its declaration, by the constructor, or with its type's zero
value, and the compiler checks it.

## Example

```ts
class Server {
    port!: int
}
```

## How to fix

Remove the `!`. A number, string, array or map field starts at its zero
value; give other fields an initializer, or assign them in the constructor:

```ts
class Server {
    port: int
}
```
