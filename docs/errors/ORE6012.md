# ORE6012

> Variable '…' is used before being assigned.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Variables](../spec/02-types.md#variables)

## What it means

A variable declared without a value is read where it may not have been
assigned yet, as in TypeScript's strict mode. Variables of types without a
zero value — classes, object types, interfaces — and variables declared as
`let x`, which take their type from the first assignment, must be assigned on
every path before they are read.

## Example

```ts
class Point {
    x = 0
}
let p: Point
console.log(p.x)
```

## How to fix

Assign the variable before it is read, on every path:

```ts
class Point {
    x = 0
}
let p: Point
p = new Point()
console.log(p.x)
```

Or include `null` in its type and check it.
