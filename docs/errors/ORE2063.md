# ORE2063

> 'infer' is supported in array, tuple, object, function, Map, Set and generic class types.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

Ore matches `infer` in array, tuple, object, function, Map, Set and generic class types, such as `(infer E)[]`, `{ a: infer A }` or `(...args: infer P) => infer R`.

## Example

```ts
type Inner<T> = T extends infer A | null ? A : never
const i: Inner<string | null> = "a"
```

## How to fix

Use `NonNullable`, or one of those forms:

```ts
const i: NonNullable<string | null> = "a"
type First<T> = T extends [infer F, int] ? F : never
const f: First<[string, int]> = "a"
```
