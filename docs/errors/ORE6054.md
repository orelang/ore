# ORE6054

> '//ore:export' applies to a function, or to a top-level 'let' of one name.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

`//ore:export name` exports one function, or one top-level `let` variable,
to C. A declaration of several names cannot share one C name.

## Example

```ts
//ore:export pair
let a = 1, b = 2
```

## How to fix

Declare the variables separately, each with its own C name:

```ts
//ore:export pair_a
let a = 1
//ore:export pair_b
let b = 2
```
