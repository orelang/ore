# ORE2037

> A floating-point constant is not assignable to type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Numeric literals](../spec/02-types.md#numeric-literals)

## What it means

A floating-point constant can only become `f32` or `f64` (or `number`, which
is `f64`). There is no implicit conversion from a number to a string, a
`bool` or an object.

## Example

```ts
const label: string = 1.5
```

## How to fix

Write a value of the expected type, or format the number:

```ts
const label: string = `${1.5}`
```
