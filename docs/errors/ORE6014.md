# ORE6014

> Default exports are not supported in Ore. Use named exports.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

Ore modules have named exports only. A default export has no name of its
own, which makes imports inconsistent between modules; `export default` and
`export =` are rejected.

## Example

```ts
function parse() {}
export default parse
```

## How to fix

Export the declaration by name:

```ts
export function parse() {}
```
