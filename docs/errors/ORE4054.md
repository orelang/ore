# ORE4054

> Cannot infer the type of the channel. Write 'new Chan<T>()' or annotate the variable.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Concurrency](../spec/06-concurrency.md)

## What it means

`new Chan()` takes the type of its values from its type argument or from the
type of the variable it is assigned to. Here there is neither.

## Example

```ts
const results = new Chan()
```

## How to fix

Give the type:

```ts
const results = new Chan<string>()
```
