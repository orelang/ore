# ORE4065

> Abstract method '…' in class '…' cannot be accessed via super expression.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`super.m(...)` runs the base class's version of `m`, and here that version
is abstract: it has no body to run.

## Example

```ts
abstract class Shape {
    abstract area(): f64
}
class Square extends Shape {
    area(): f64 {
        return super.area()
    }
}
```

## How to fix

Implement the method without calling the abstract one:

```ts
abstract class Shape {
    abstract area(): f64
}
class Square extends Shape {
    area(): f64 {
        return 1.0
    }
}
```
