# ORE7006

> Nested generic functions are not supported.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

This message is no longer produced: a function declared inside another
function can have type parameters now, and each instance is a closure that
captures the variables of the enclosing functions. Earlier versions
rejected nested generic functions with this message.
