# ORE7006

> Nested generic functions are not supported.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

A function declared inside another function cannot have type parameters
yet. (Generic functions are instantiated per set of type arguments, and
nested functions capture the variables of their block.)

## Example

```ts
function outer() {
    function first<T>(xs: T[]): T {
        return xs[0]
    }
}
```

## How to fix

Move the generic function to the top level:

```ts
function first<T>(xs: T[]): T {
    return xs[0]
}
function outer() {
    console.log(first([1, 2]))
}
```
