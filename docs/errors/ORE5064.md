# ORE5064

> Overload signatures must all be public, private or protected, as the implementation.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The overload signatures and the implementation of a method are one method,
so they have the same visibility.

## Example

```ts
class Parser {
    private parse(s: string): int
    parse(s: string): int {
        return s.length
    }
}
```

## How to fix

Give all of them the same modifier, or none:

```ts
class Parser {
    parse(s: string): int
    parse(s: string): int {
        return s.length
    }
}
```
