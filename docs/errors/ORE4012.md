# ORE4012

> '…' is not a function.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

The name is called, but it is not a function: it is a variable, constant or
other value of a type that cannot be called.

## Example

```ts
const total = 5
total()
```

## How to fix

Call a function, or remove the parentheses to read the value:

```ts
const total = 5
console.log(total)
```
