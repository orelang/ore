# ORE5063

> Cannot extend a class '…': its constructor is private.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

A subclass calls the constructor of its base class, which a `private`
constructor allows only inside the base class's declaration. Such a class
cannot be extended.

## Example

```ts
class Config {
    private constructor() {}
}
class Local extends Config {}
```

## How to fix

Make the constructor `protected`, which subclasses can call through
`super(...)`:

```ts
class Config {
    protected constructor() {}
}
class Local extends Config {}
```
