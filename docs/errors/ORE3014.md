# ORE3014

> Function '…' has overload signatures and cannot be used as a value.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function with overload signatures has a different result type for each
signature, chosen at each call. As a value it would need one function type,
so it cannot be used as a value.

## Example

```ts
function parse(s: string): int
function parse(s: string[]): int[]
function parse(s: string | string[]): int | int[] {
    return 0
}
const f = parse
```

## How to fix

Wrap a call with the signature you need:

```ts
function parse(s: string): int
function parse(s: string[]): int[]
function parse(s: string | string[]): int | int[] {
    return 0
}
const f = (s: string): int => parse(s)
```
