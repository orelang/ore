# ORE2049

> Type '…' cannot be converted to or from JSON.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

JSON conversion is generated for each type when the program is compiled.
Numbers, `bool`, strings, string literal types, `null`, arrays, tuples,
`Map`s with string keys, object types, classes and unions of these can be
converted. Interfaces cannot, since the fields of the value behind an
interface are not known statically, nor can functions, channels, sets and
`ptr` values. `JSON.stringify` writes an `unknown` as the value it holds,
but `JSON.parse` cannot read one.

## Example

```ts
interface Named {
    name: string
}
const n: Named = { name: "ada" }
console.log(JSON.stringify(n))
```

## How to fix

Use an object type or a class for data that is converted to JSON:

```ts
type Named = { name: string }
const n: Named = { name: "ada" }
console.log(JSON.stringify(n))
```

Convert a `Set` to an array first:

```ts
const tags = new Set<string>(["a", "b"])
console.log(JSON.stringify(Array.from(tags.values())))
```
