# ORE4016

> Sorting '…' needs a comparator: 'sort((a, b) => ...)'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

Without a comparator, `sort` orders numbers by value and strings by bytes.
Other elements, such as objects, have no natural order, so `sort` needs a
comparator. (JavaScript would sort them as the text `[object Object]`.)

## Example

```ts
const people = [{ age: 30 }, { age: 20 }]
people.sort()
```

## How to fix

Pass a comparator that returns a negative number, zero or a positive number:

```ts
const people = [{ age: 30 }, { age: 20 }]
people.sort((a, b) => a.age - b.age)
```
