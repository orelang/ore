# ORE4010

> Only an array or a tuple can be spread into arguments.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

`...x` in the arguments of a call passes the elements of an array (to a rest
parameter) or of a tuple (to any parameters). Other values, such as strings,
maps and sets, cannot be spread there.

## Example

```ts
function count(...xs: string[]): int {
    return xs.length
}
const n = count(..."abc")
```

## How to fix

Convert the value to an array first:

```ts
function count(...xs: string[]): int {
    return xs.length
}
const n = count(..."abc".split(""))
```
