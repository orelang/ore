# ORE4086

> '…' takes a dictionary, an object or a class instance, got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The namespace Object](../spec/03-objects.md#the-namespace-object)

## What it means

The functions of the namespace `Object` take dictionaries, objects and class
instances, whose keys are known.

## Example

```ts
console.log(Object.keys([1, 2]))
```

## How to fix

Use the methods of arrays, maps and sets: `[1, 2].keys()`.
