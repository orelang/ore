# ORE4086

> structuredClone cannot clone '…': an instance of a class with methods would lose them, as JavaScript copies it into a plain object.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

JavaScript's `structuredClone` copies an instance of a class into a plain
object with its fields and without its prototype, so the copy has none of
the methods. Ore cannot give the copy the type of the class and leave the
methods out, so a class with methods (such as `RegExp` or `Promise`)
cannot be cloned. A class with only fields is copied as an instance of the
same class, and `Date` is copied as a `Date`, as in JavaScript.

## Example

```ts
class Counter {
    count = 0
    increment() {
        this.count++
    }
}
const copy = structuredClone(new Counter())
```

## How to fix

Copy the instance with a method of the class, or keep the data in an object
type or a class with only fields and clone that:

```ts
class Counter {
    count = 0
    increment() {
        this.count++
    }
    clone(): Counter {
        const c = new Counter()
        c.count = this.count
        return c
    }
}
const copy = new Counter().clone()
```
