# ORE2044

> Shift count must not be negative.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

A shift of constants by a negative count. At run time, a negative shift
count panics; in a constant expression it is reported when the program is
compiled.

## Example

```ts
const x = 1 << -1
```

## How to fix

Shift by a non-negative count, or shift the other way:

```ts
const x = 1 >> 1
```
