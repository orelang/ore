# ORE4004

> Type '…' has no '[Symbol.dispose]' method.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Resources](../spec/04-functions.md#resources)

## What it means

The value's type has no `[Symbol.dispose]` method, so there is nothing to
call. A resource is a class or object with a `[Symbol.dispose](): void`
method (the built-in interface `Disposable`).

## Example

```ts
class File {}
const f = new File()
f[Symbol.dispose]()
```

## How to fix

Declare the method in the class:

```ts
class File {
    [Symbol.dispose]() {
        console.log("closed")
    }
}
const f = new File()
f[Symbol.dispose]()
```
