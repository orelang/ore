# ORE2021

> Methods in object types are not supported yet. Use an interface.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

This message is no longer produced: an object type with methods,
`{ area(): f64 }`, is a structural interface now, as in TypeScript, and
classes and object literals with methods fit it. Earlier versions rejected
methods in object types with this message.
