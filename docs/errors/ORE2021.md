# ORE2021

> Methods in object types are not supported yet. Use an interface.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

An object type (`type P = { ... }`) is an exact record of fields; it cannot
declare methods yet. An interface can: any class or object with the members
converts to it.

## Example

```ts
type Shape = { area(): f64 }
```

## How to fix

Declare an interface:

```ts
interface Shape {
    area(): f64
}
```

Or, for a record that carries a function, declare a field of a function type:

```ts
type Shape = { area: () => f64 }
const unit: Shape = { area: () => 1.0 }
```
