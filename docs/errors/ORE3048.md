# ORE3048

> Only a tuple can be spread into a tuple.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const [p, q, r] = t
const spread: [int, int, int] = [...t, 1]
const arrays: [int, int] = [...[1, 2]]
```
