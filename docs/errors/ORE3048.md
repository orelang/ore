# ORE3048

> Only a tuple can be spread into a tuple.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

In a tuple literal, `...x` must spread another tuple: a tuple has a fixed
number of elements, known when the program is compiled, and the length of
an array is not.

## Example

```ts
const rest = [2, 3]
const t: [int, int, int] = [1, ...rest]
```

## How to fix

Spread a tuple:

```ts
const rest: [int, int] = [2, 3]
const t: [int, int, int] = [1, ...rest]
```
