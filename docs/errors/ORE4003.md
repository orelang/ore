# ORE4003

> A constant has no '…' method.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Resources](../spec/04-functions.md#resources)

## What it means

`[Symbol.dispose]()` is called on a numeric constant, which has no methods
and holds no resource.

## Example

```ts
const n = 5
n[Symbol.dispose]()
```

## How to fix

Call `[Symbol.dispose]()` on an object whose class declares it, or remove
the call.

```ts
class Lock {
    [Symbol.dispose]() {}
}
new Lock()[Symbol.dispose]()
```
