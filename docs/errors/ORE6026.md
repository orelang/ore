# ORE6026

> A declared function cannot have a body.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

`declare function` declares a C function, implemented outside the program,
so it cannot have a body.

## Example

```ts
declare function abs(n: i32): i32 {
    return n
}
```

## How to fix

Remove the body to declare the C function:

```ts
declare function abs(n: i32): i32
```

Or remove `declare` to write an Ore function.
