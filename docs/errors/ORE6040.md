# ORE6040

> A parameter with a default value is already optional.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A parameter with a default value (`b = 1`) may already be left out, so it
does not take `?` as well.

## Example

```ts
function pad(s: string, width?: int = 8) {}
```

## How to fix

Remove the `?`:

```ts
function pad(s: string, width: int = 8) {}
```
