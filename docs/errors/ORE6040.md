# ORE6040

> A parameter with a default value is already optional.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [07-modules.md](../spec/07-modules.md)

## Example

```ts
function m(...xs: int[], y: int) {}
function n(x: int = "no") {}
function o(x?: int = 1) {}
```
