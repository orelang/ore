# ORE5036

> Static field '…' needs a type annotation or an initializer.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A static field is a global variable of the module, and needs a type, from
its annotation or from its initializer.

## Example

```ts
class Config {
    static port
}
```

## How to fix

Annotate the field or give it a value:

```ts
class Config {
    static port = 80
    static host: string
}
```
