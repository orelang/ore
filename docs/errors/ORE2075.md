# ORE2075

> Property '…' of type '…' is not assignable to 'string' index type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Named entries](../spec/03-objects.md#named-entries)

## What it means

A named entry of a dictionary, `name` in `{ name: string; [key: string]:
string }`, is one of its entries: its type is assignable to the values'
type, as TypeScript requires. In Ore that is the same type, members of a
union of values, any type for `unknown` values, or string literal types of
values that hold `string`, for a required entry; a read of the entry by its
name checks its value at run time.

## Example

```ts
type Counts = { label: string; [name: string]: int }
```

## How to fix

Give the values a type that holds the entry's:

```ts
type Counts = { label: string; [name: string]: int | string }
```
