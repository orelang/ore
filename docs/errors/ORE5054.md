# ORE5054

> Call and construct signatures are not supported.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

Interfaces describe fields and methods. Call signatures (`(x: T): R`) and
construct signatures (`new (): T`) are not supported: functions have
function types, and classes are not values.

The parser of Ore does not accept these members (it reads `new` as the name
of a method, and `(` as a syntax error), so this message is not produced at
present.

## Example

<!-- no-check -->
```ts
interface Parser {
    (text: string): int
}
```

## How to fix

Use a function type, or a named method:

```ts
type Parser = (text: string) => int
interface Parsing {
    parse(text: string): int
}
```
