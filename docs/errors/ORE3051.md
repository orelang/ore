# ORE3051

> Cannot infer the type of an empty array. Add a type annotation, e.g. 'let a: int[] = []'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

An array literal takes its element type from the context, or from its
elements. `[]` has neither, and Ore has no `any[]` to fall back to.

## Example

```ts
const names = []
```

## How to fix

Annotate the variable:

```ts
const names: string[] = []
```
