# ORE5057

> '…' is protected and only accessible inside class '…' and its subclasses.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [03-objects.md](../spec/03-objects.md)

## Example

```ts
const a = new Animal("x")
const s = new Snake(true)
console.log(s.sound)
```
