# ORE5057

> '…' is protected and only accessible inside class '…' and its subclasses.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A `protected` member is accessible only in the class that declares it and
in its subclasses. Privacy is checked by the compiler; it does not count for
interfaces either.

## Example

```ts
class Account {
    protected balance = 0
}
console.log(new Account().balance)
```

## How to fix

Add a public method or getter that gives what callers need:

```ts
class Account {
    protected balance = 0
    get total(): int {
        return this.balance
    }
}
console.log(new Account().total)
```

Or make the member public.
