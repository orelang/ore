# ORE6023

> Default exports are not supported in Ore.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

Ore modules have named exports only, so a function cannot be marked
`default`. It is reported together with [ORE6014](ORE6014.md).

## Example

```ts
export default function parse() {}
```

## How to fix

Export the function by name:

```ts
export function parse() {}
```
