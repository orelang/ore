# ORE2004

> Only string and number literal types are supported yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A literal type can only be a string literal, such as `"circle"`, or `null`.
Numeric and boolean literal types (`1 | 2`, `true`) are not supported yet.

## Example

```ts
let level: 1 | 2 | 3 = 1
```

## How to fix

Use the numeric type and check the range where it matters, or use string
literals:

```ts
let level: int = 1
let size: "small" | "large" = "small"
```
