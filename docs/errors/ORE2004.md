# ORE2004

> Only string, number and boolean literal types are supported yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A literal type can be a string literal (`"circle"`), a number (`1`,
`-0.5`), a boolean (`true`, `false`) or `null`. Other literal types, such
as bigint literals (`10n`), are not supported yet.

## Example

```ts
let big: 10n = 10n
```

## How to fix

Use the wider type, `bigint`:

```ts
let big: bigint = 10n
```
