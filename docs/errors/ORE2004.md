# ORE2004

> Only string and number literal types are supported yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A literal type can be a string literal (`"circle"`), a number (`1`,
`-0.5`) or `null`. Boolean literal types (`true`, `false`) are not
supported yet.

## Example

```ts
let done: true = true
```

## How to fix

Use `bool`, or a union of string literals when the values have names:

```ts
let done: bool = true
let state: "done" | "pending" = "done"
```
