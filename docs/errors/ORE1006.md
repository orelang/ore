# ORE1006

> Identifier expected. '…' is a reserved word in strict mode. …

Group: [Syntax](README.md#ore1xxx-syntax) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

Ore modules are always in strict mode, as ES modules are in TypeScript. Strict
mode reserves `implements`, `interface`, `let`, `package`, `private`,
`protected`, `public`, `static` and `yield`, so they cannot name variables,
parameters, functions or classes. Inside a class the same applies, which the
message states as "Class definitions are automatically in strict mode."
Properties and methods may still have these names (`x.static`,
`readonly private: bool`).

## Example

```ts
function grant(public: bool) {}
```

## How to fix

Choose another name for the binding:

```ts
function grant(isPublic: bool) {}
```
