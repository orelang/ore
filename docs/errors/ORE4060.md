# ORE4060

> A 'super' call must be a statement at the top level of the constructor, and the only one.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

The constructor of a subclass calls `super(...)` exactly once, as a
statement at the top level of its body (not inside an `if`, a loop or a
closure). This lets the compiler know that the base class is initialized
exactly once before the subclass's fields are.

## Example

```ts
class Shape {
    constructor(readonly sides: int) {}
}
class Polygon extends Shape {
    constructor(n: int) {
        super(n)
        super(n)
    }
}
```

## How to fix

Call `super` once, at the top level; compute the arguments before it:

```ts
class Shape {
    constructor(readonly sides: int) {}
}
class Polygon extends Shape {
    constructor(n: int) {
        const sides = n < 3 ? 3 : n
        super(sides)
    }
}
```
