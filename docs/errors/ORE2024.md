# ORE2024

> Duplicate property '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const p: Point = { x: 1, y: 2 }
const bad = { ...5 }
const twice = { a: 1, ...p, a: 2 }
```

`tests/diag/types/object-spread.ore:4`: Duplicate property 'a'.
