# ORE2024

> Duplicate property '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

A property is declared twice in the same object type, or set twice in the
same object literal.

## Example

```ts
type Point = { x: int; x: int }
```

## How to fix

Remove or rename one of them:

```ts
type Point = { x: int; y: int }
```
