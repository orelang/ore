# ORE3062

> Static members of generic classes are not supported yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

This message is no longer produced: a generic class can have static
methods, generic ones too (`Box.of<U>(v)`), which do not see the class's
type parameters, as in TypeScript. Static fields of a generic class are
still rejected, with [ORE3079](ORE3079.md). Earlier versions rejected every
static member of a generic class with this message.
