# ORE3062

> Static members of generic classes are not supported yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A generic class is compiled once per set of type arguments, and Ore does not
support static members on it yet: it is not decided whether each instance
would have its own copy.

## Example

```ts
class Pool<T> {
    static created = 0
}
console.log(Pool.created)
```

## How to fix

Move the static member to a module variable or to a non-generic class:

```ts
let created = 0
class Pool<T> {
    constructor() {
        created++
    }
}
```
