# ORE6025

> Overload signatures must all be exported or not, as the implementation.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

The overload signatures and the implementation of a function are one
function, so they are all exported, or none is.

## Example

```ts
export function parse(s: string): int
function parse(s: string): int {
    return 0
}
```

## How to fix

Mark all of them `export`, or none:

```ts
export function parse(s: string): int
export function parse(s: string): int {
    return 0
}
```
