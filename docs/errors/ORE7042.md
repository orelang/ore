# ORE7042

> A rest element must be last in a destructuring pattern.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

`...rest` takes everything the other elements of a pattern leave, so it
can only be the last element of an array or object pattern, in a
declaration, a parameter, a `for-of` head or an assignment.

## Example

```ts
const [...init, last] = [1, 2, 3]
```

## How to fix

Put the rest element last, or read the other elements by index:

```ts
const xs = [1, 2, 3]
const init = xs.slice(0, xs.length - 1)
const last = xs[xs.length - 1]
```
