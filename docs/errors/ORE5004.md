# ORE5004

> Classes can only extend a single class.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

A class extends at most one class. Its fields are laid out after those of
its base class, at the same offsets, which works for a single chain only.

## Example

```ts
class Named {}
class Aged {}
class Person extends Named, Aged {}
```

## How to fix

Extend one class, and implement interfaces for the other roles:

```ts
interface Named {
    name: string
}
class Aged {
    age = 0
}
class Person extends Aged implements Named {
    name = ""
}
```
