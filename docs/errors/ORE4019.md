# ORE4019

> '…' expects at least 1 argument(s), got 0.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

A call passes fewer arguments than the function needs. The array methods
that take a variable number of arguments (`splice`, `concat`, `unshift`)
take none too, as in JavaScript, and a variadic C function with too few
arguments is reported as [ORE4066](ORE4066.md), so this message is not
produced at present.

## Example

<!-- no-check -->
```ts
const xs = [3, 1, 2]
xs.splice()
```

## How to fix

Pass the index to start at, and how many elements to remove:

```ts
const xs = [3, 1, 2]
xs.splice(1, 1)
```
