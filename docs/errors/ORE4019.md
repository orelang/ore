# ORE4019

> '…' expects at least 1 argument(s), got 0.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`Math.min` and `Math.max` take one or more values; with none, there is no
type to give the result. (JavaScript returns `Infinity` or `-Infinity`.)

## Example

```ts
const m = Math.max()
```

## How to fix

Pass at least one value, or spread an array:

```ts
const xs = [3, 1, 2]
const m = Math.max(...xs)
```
