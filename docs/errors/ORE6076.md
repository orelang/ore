# ORE6076

> A type predicate's type must be assignable to its parameter's type: '…' is not assignable to '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

The type of `x is T` must be a type that the parameter can have: a
member of its union, a subclass of its class, or any type for `unknown`.

## Example

```ts
type Shape = { kind: "circle"; r: f64 } | { kind: "square"; side: f64 }
function isName(s: Shape): s is string {
    return false
}
```

## How to fix

Use a type the parameter can have, or widen the parameter:

```ts
function isName(s: unknown): s is string {
    return typeof s === "string"
}
```
