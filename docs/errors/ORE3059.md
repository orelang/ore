# ORE3059

> A property cannot have type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

A property of an object literal has a value of type `void` (a call that
returns nothing) or `never`, so there is no value to store.

## Example

```ts
const entry = { logged: console.log("x") }
```

## How to fix

Call the function as a statement, and store a value:

```ts
console.log("x")
const entry = { logged: true }
```
