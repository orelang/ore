# ORE4058

> Class '…' is not generic.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

Type arguments were given to `new` for a class that has no type parameters.

## Example

```ts
class Point {
    x = 0
}
const p = new Point<int>()
```

## How to fix

Remove the type arguments:

```ts
class Point {
    x = 0
}
const p = new Point()
```
