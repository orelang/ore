# ORE4002

> '[Symbol.dispose]' takes no arguments.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Resources](../spec/04-functions.md#resources)

## What it means

`[Symbol.dispose]()` releases a resource and takes no arguments: it is the
method a `using` declaration calls when its scope ends.

## Example

```ts
class File {
    [Symbol.dispose]() {}
}
const f = new File()
f[Symbol.dispose](true)
```

## How to fix

Call it without arguments, or better, declare the resource with `using`,
which calls it for you:

```ts
class File {
    [Symbol.dispose]() {}
}
function work() {
    using f = new File()
}
```
