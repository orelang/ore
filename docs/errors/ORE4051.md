# ORE4051

> Cannot infer the type of the Set. Write 'new Set<T>()' or annotate the variable.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Sets](../spec/03-objects.md#sets)

## What it means

`new Set()` takes its element type from its type argument, from the type of
the variable it is assigned to, or from the values it is given. Here there
is none of these.

## Example

```ts
const seen = new Set()
```

## How to fix

Give the type:

```ts
const seen = new Set<string>()
```

Or annotate the variable:

```ts
const seen: Set<string> = new Set()
```
