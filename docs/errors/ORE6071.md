# ORE6071

> A generic function value must be instantiated: give its type arguments or call it.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A generic nested function, or a generic function literal assigned to a
`const`, is used as a value without a call. Each list of its type arguments
makes a separate closure, so the name alone has no single function type.

## Example

```ts
function sizes(words: string[]): int[] {
    const size = <T>(xs: T[]): int => xs.length
    return [words].map(size)
}
```

## How to fix

Call it, with type arguments written or inferred from the arguments, in a
function literal of the type the value needs:

```ts
function sizes(words: string[]): int[] {
    const size = <T>(xs: T[]): int => xs.length
    return [words].map((w) => size(w))
}
```
