# ORE2058

> This type operator is not supported.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

Of the type operators, Ore has `keyof` and `readonly` (which on an array type has no effect yet); `unique symbol` is not supported.

## Example

```ts
type U = unique symbol
```

## How to fix

Use a string literal type instead:

```ts
type U = "u"
```
