# ORE6059

> Cannot infer type argument… of '…'. Specify them, e.g. '…<...>(...)'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

The type arguments of a generic call are inferred from its arguments.
Here a type parameter does not appear in the types of the parameters, so
its type is unknown.

## Example

```ts
function empty<T>(): T[] {
    return []
}
const xs = empty()
```

## How to fix

Give the type arguments:

```ts
function empty<T>(): T[] {
    return []
}
const xs = empty<string>()
```
