# ORE7008

> Cannot continue '…': it labels a switch.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

`continue label` continues a loop. The label names a `switch`, which can be
left with `break label` but not continued.

## Example

```ts
let n = 1
choice: switch (n) {
    case 1:
        for (;;) continue choice
}
```

## How to fix

Use `break` to leave the switch, or label the loop to continue:

```ts
let n = 1
choice: switch (n) {
    case 1:
        for (;;) break choice
}
```
