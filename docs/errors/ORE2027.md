# ORE2027

> '#' private names are not supported. Use the 'private' modifier.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

Ore does not support JavaScript's `#name` private fields. Privacy is checked
by the compiler with the `private` modifier, which has the same effect for an
Ore program: the member is accessible only inside its class.

## Example

```ts
class Counter {
    #count = 0
}
```

## How to fix

Use the `private` modifier:

```ts
class Counter {
    private count = 0
}
```
