# ORE4029

> '…' cannot work on '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

The `unsafe` function reads, writes or measures a value of a type, and the
type here has no values to store: `void`, `never` or `null`.

## Example

```ts
let p = unsafe.alloc(8)
unsafe.store(p, null)
```

## How to fix

Store a value of a type with a representation, such as a number or `ptr`:

```ts
let p = unsafe.alloc(8)
unsafe.store<int>(p, 0)
```
