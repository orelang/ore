# ORE3008

> This expression is not supported yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

The expression is TypeScript syntax that Ore does not support, such as the
`void` operator.

## Example

```ts
const nothing = void 0
```

## How to fix

Rewrite the expression without it. `null` stands for a missing value:

```ts
const nothing: int | null = null
```
