# ORE5039

> Static field '…' of type '…' needs an initializer.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A static field is a global variable, set where the class is declared. Its
type has no zero value — it is a class, an object type or an interface — so
it needs an initializer.

## Example

```ts
class Point {
    x = 0
}
class Origin {
    static point: Point
}
```

## How to fix

Give it an initial value:

```ts
class Point {
    x = 0
}
class Origin {
    static point = new Point()
}
```

Or include `null` in its type, so that it starts as `null`:

```ts
class Point {
    x = 0
}
class Origin {
    static point: Point | null
}
```
