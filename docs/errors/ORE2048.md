# ORE2048

> Type '…' cannot be converted to or from JSON: the keys of a Map must be strings.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const byId = new Map<int, string>()
JSON.stringify(byId)
```

`tests/diag/library/json.ore:6`: Type 'Map<i64, string>' cannot be converted to or from JSON: the keys of a Map must be strings.
