# ORE2048

> Type '…' cannot be converted to or from JSON: the keys of a Map must be strings.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

JSON objects have string keys, so a `Map` is written as a JSON object only
when its keys are strings (or string literal types). The code that converts a
type to and from JSON is generated when the program is compiled, so a type
that cannot be converted is an error there.

## Example

```ts
const counts = new Map<int, string>()
console.log(JSON.stringify(counts))
```

## How to fix

Key the map by strings:

```ts
const counts = new Map<string, string>()
console.log(JSON.stringify(counts))
```

Or convert it to an array of `[key, value]` pairs first:

```ts
const counts = new Map<int, string>()
console.log(JSON.stringify(Array.from(counts.entries())))
```
