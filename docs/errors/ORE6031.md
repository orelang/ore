# ORE6031

> Type '…' cannot be passed to C.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

The parameters of a C function may be numbers, `bool`, `string` (passed as
a NUL-terminated copy) and `ptr`. Objects, arrays, unions and functions have
no C form.

## Example

```ts
class Point {
    x = 0
}
declare function draw(p: Point): void
```

## How to fix

Pass the fields as numbers, or a pointer to memory laid out as C expects:

```ts
declare function draw(x: i64, y: i64): void
```
