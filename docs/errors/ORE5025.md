# ORE5025

> This member cannot have an 'override' modifier because its containing class '…' does not extend another class.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`override` states that a method replaces a method of the base class, but
this class has no base class.

## Example

```ts
class Square {
    override draw() {}
}
```

## How to fix

Remove `override`, or extend the class that declares the method:

```ts
class Square {
    draw() {}
}
```
