# ORE4061

> 'super' can only be used in the methods and constructor of a class that extends another class.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`super.m(...)` calls the base class's version of a method, so it is only
allowed in the methods and constructor of a class declared with `extends`.

## Example

```ts
class Point {
    show() {
        super.show()
    }
}
```

## How to fix

Call the method through `this`, or make the class extend the class whose
method you mean:

```ts
class Shape {
    show() {}
}
class Point extends Shape {
    show() {
        super.show()
    }
}
```
