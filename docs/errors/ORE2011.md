# ORE2011

> Type '…' is not generic.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

Type arguments were given to a type that has no type parameters.

## Example

```ts
class Point {
    x = 0
}
const p: Point<int> = new Point()
```

## How to fix

Remove the type arguments, or declare type parameters on the type if it
should be generic:

```ts
class Point {
    x = 0
}
const p: Point = new Point()
```
