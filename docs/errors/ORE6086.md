# ORE6086

> Parameter '…' needs a type annotation: its default value uses '…', whose type is not known before its declaration.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A parameter without a type annotation has the type of its default value.
The signatures are typed before the top-level code declares the module's
variables, so the variables a default value uses are typed ahead of their
declarations: by their annotations, or by their values. A value with a
function in it (an arrow function or a function expression), or one that
calls a function declared after the parameter's, cannot be typed then.

## Example

```ts
function run(task = defaultTask): int {
    return task()
}

const defaultTask = () => 1
console.log(run())
```

## How to fix

Annotate the parameter, or the variable:

```ts
function run(task: () => int = defaultTask): int {
    return task()
}

const defaultTask = () => 1
console.log(run())
```
