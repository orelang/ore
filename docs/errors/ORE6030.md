# ORE6030

> An external function cannot have optional parameters.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

A C function receives every argument, so a `declare function` cannot have
optional or default parameters.

## Example

```ts
declare function exit(code?: i32): void
```

## How to fix

Make the parameter required, and pass it at every call:

```ts
declare function exit(code: i32): void
```
