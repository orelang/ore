# ORE4039

> An operand of 'unsafe.asm' must be a number or 'ptr', got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

An operand of inline assembly is passed in a register, so it must be a
number or a `ptr`. Strings and objects are references managed by Ore, and
cannot be passed as they are.

## Example

```ts
unsafe.asm("nop", "r", "text")
```

## How to fix

Pass a number or a pointer, such as the bytes of a string:

```ts
unsafe.asm("nop", "r", unsafe.stringData("text"))
```
