# ORE4039

> An operand of 'unsafe.asm' must be a number or 'ptr', got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
const t = "nop"
unsafe.asm(t, "")
unsafe.asm("", "", "s")
```
