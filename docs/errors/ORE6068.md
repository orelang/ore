# ORE6068

> A JSON import has one name: 'import data from "…" with { type: "json" }'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [JSON files](../spec/07-modules.md#json-files)

## What it means

`import name from "./file.json" with { type: "json" }` declares one constant
with the value of the JSON file. It binds exactly one name, as a default
import; named imports have no meaning for a JSON file.

## Example

```ts
import { name } from "./config.json" with { type: "json" }
```

## How to fix

Bind one name and read the properties from it:

```ts
import config from "./config.json" with { type: "json" }
console.log(config.name)
// file: config.json
{ "name": "ore" }
```
