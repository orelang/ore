# ORE5014

> Optional methods are not supported.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

Optional methods (`m?(): T`) are not supported in classes and interfaces: a
method is called directly or through a table, and must exist.

## Example

```ts
interface Plugin {
    start?(): void
}
```

## How to fix

Declare an optional field of a function type, and call it only when it is
not null:

```ts
interface Plugin {
    start?: () => void
}
function run(p: Plugin) {
    const start = p.start
    start?.()
}
```

Or keep the method required, with an empty body where it does nothing.
