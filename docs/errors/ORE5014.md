# ORE5014

> Optional methods are not supported in classes.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A method of a class cannot be optional (`m?(): T`): a class's method is
called directly or through a table, and always exists. Interfaces and
object types can have optional methods, which a class may leave out; earlier
versions rejected those with this message too.

## Example

```ts
class Plugin {
    start?(): void {}
}
```

## How to fix

Declare the method without `?`. To let instances go without it, declare a
field of a function type that may be null, or an interface with the
optional method that the class implements:

```ts
interface Startable {
    start?(): void
}
class Plugin implements Startable {
    start: (() => void) | null = null
}
function run(p: Startable) {
    p.start?.()
}
```
