# ORE4015

> Cannot join elements of type '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

`join` formats each element as text, which works for numbers, `bool`,
strings and unions of them. Objects and arrays have no implicit text form in
Ore.

## Example

```ts
const points = [{ x: 1 }, { x: 2 }]
const s = points.join(", ")
```

## How to fix

Map the elements to strings first:

```ts
const points = [{ x: 1 }, { x: 2 }]
const s = points.map((p) => `${p.x}`).join(", ")
```
