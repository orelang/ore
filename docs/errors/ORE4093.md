# ORE4093

> Method '…' has different types in the members of '…': '…' and '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A method called on a union of classes runs the method of the class the
value holds, so every class must have it with the same parameter and
result types. TypeScript accepts some calls on methods of different types
(it calls the union of the signatures); Ore does not.

## Example

```ts
class Cat {
    speak(): string {
        return "meow"
    }
}
class Robot {
    speak(): int {
        return 42
    }
}
const say = (a: Cat | Robot) => a.speak()
```

## How to fix

Give the methods the same type, or narrow the value first:

```ts
const say = (a: Cat | Robot): string => (a instanceof Cat ? a.speak() : `${a.speak()}`)
```
