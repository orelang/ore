# ORE2017

> Cannot find type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

No type with this name is visible here. Types come from declarations in the
module (`class`, `interface`, `type`), from imports, and from the built-in
types (`int`, `string`, `Map`, ...). The name may be misspelled, or the type
is in another module and not imported.

## Example

```ts
function draw(p: Pointt) {}
```

## How to fix

Correct the name, or import the type from the module that exports it:

```ts
class Point {
    x = 0
}
let p: Point = new Point()
```
