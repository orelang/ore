# ORE4087

> '…' cannot copy '…' into '…': give it ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The namespace Object](../spec/03-objects.md#the-namespace-object)

## What it means

`Object.assign` copies into a dictionary the entries of dictionaries with
the same type of values, or the fields of objects; into an object, the
fields of other objects.

## Example

```ts
const p = { x: 1 }
const d: Record<string, int> = { x: 2 }
Object.assign(p, d)
```

## How to fix

Copy the entries you need by their names: `p.x = d.x ?? p.x`.
