# ORE6063

> Invalid GitHub module URL '…': expected https://github.com/<owner>/<repo>[/tree/<ref>][/<path>].

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules from GitHub](../spec/07-modules.md#modules-from-github)

## What it means

An import that starts with `https://github.com/` names a module of a
GitHub repository, and this one is not of a form Ore reads: an owner and a
repository, then optionally `/tree/<ref>` (or `/blob/<ref>`) and a path in
the repository. Names and refs are letters, digits, `.`, `-` and `_`; a ref
cannot contain `/`, and a URL has no `?`, `#` or `..` parts.

## Example

```ts
import { x } from "https://github.com/acme"
```

## How to fix

Name the repository, and the branch, tag or commit if not the default
branch:

<!-- no-check -->
```ts
import { x } from "https://github.com/acme/geo/tree/v1.2.0/src/point"
```
