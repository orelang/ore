# ORE2033

> Type '…' is not assignable to type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Conversions](../spec/02-types.md#conversions)

## What it means

The value's type does not convert to the type expected here. Ore converts
implicitly only where no representation changes: to a union containing the
type, from a class to its base classes, and from a class or object to an
interface it fits. Distinct numeric types (`i32` and `i64`, `int` and `f64`)
never convert implicitly, and classes are nominal: two classes with the same
members are still different types.

## Example

```ts
const small: i32 = 10
const big: i64 = small
```

## How to fix

For numbers, convert explicitly by calling the type:

```ts
const small: i32 = 10
const big: i64 = i64(small)
```

For strings, format the value with a template literal or `toString()`:

```ts
const count = 3
const label: string = `${count}`
```

Otherwise, change the declared type, or pass a value of the expected type.
