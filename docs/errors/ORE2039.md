# ORE2039

> Ambiguous constant for type '…'. Convert it explicitly, e.g. '…(...)'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
let v: int | string = 1.5
let w: i32 | i64 = 1
let x: i32 | u8 = 1
```

`tests/diag/types/null.ore:39`: Ambiguous constant for type 'i32 | u8'. Convert it explicitly, e.g. 'i32(...)'.
