# ORE2039

> Ambiguous constant for type '…'. Convert it explicitly, e.g. '…(...)'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Numeric literals](../spec/02-types.md#numeric-literals)

## What it means

An untyped constant assigned to a union takes the union's member of its
default type (`int` for integers, `f64` for floats), or the only numeric
member that fits. Here there are several numeric members and none is the
default type, so the compiler cannot choose; it does not guess, since the
member decides how the value is stored and printed.

## Example

```ts
let id: i32 | u8 = 1
```

## How to fix

Convert the constant to the member you mean:

```ts
let id: i32 | u8 = i32(1)
```
