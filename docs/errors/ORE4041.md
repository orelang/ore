# ORE4041

> Unknown function '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

An internal error of the compiler: a generic function of `unsafe` declared
in `std/builtin.d.ore` has no implementation in the checker. Every such
function is implemented today, so this message is not expected; calling a
name that `unsafe` does not declare gives [ORE4005](ORE4005.md) instead.

## Example

<!-- no-check -->
```ts
const n = unsafe.notImplemented<int>()
```

## How to fix

Report the program that produces it as a bug of the compiler. Use the
functions listed in the specification.

```ts
const n = unsafe.sizeOf<int>()
```
