# ORE7010

> 'continue' must be inside a loop.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

`continue` starts the next iteration of the innermost loop, and there is
none around it here: a `switch` is not a loop, and a function literal is a
separate function.

## Example

```ts
[1, 2].forEach((x) => {
    if (x > 1) continue
})
```

## How to fix

Use `return` to end the callback for this element:

```ts
[1, 2].forEach((x) => {
    if (x > 1) return
    console.log(x)
})
```

Or use a `for...of` loop:

```ts
for (const x of [1, 2]) {
    if (x > 1) continue
    console.log(x)
}
```
