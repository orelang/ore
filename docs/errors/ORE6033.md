# ORE6033

> A type parameter without a default cannot follow one with a default.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

Type arguments are matched by position, so the type parameters with
defaults must come after those without.

## Example

```ts
function make<T = int, U>(x: U) {}
```

## How to fix

Put the parameters with defaults last:

```ts
function make<U, T = int>(x: U) {}
```
