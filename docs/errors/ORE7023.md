# ORE7023

> Destructure a property by its name.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

An object pattern reads fields by name, which must be known when the
program is compiled. Computed keys (`{ [key]: v }`) are not supported, as
fields cannot be looked up at run time.

## Example

```ts
const p = { x: 1 }
const { ["x"]: value } = p
```

## How to fix

Name the property, renaming it with `:` if needed:

```ts
const p = { x: 1 }
const { x: value } = p
```
