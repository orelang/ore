# ORE3091

> 'globalThis' cannot be used as a value; use its members, as 'globalThis.Math'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`globalThis` holds the global names, such as `console`, `Math`, `Date` and
`Promise`, as in JavaScript, but Ore resolves its members at compile time:
`globalThis.Math.max(1, 2)` is `Math.max(1, 2)`. It is not an object, so it
cannot be stored, passed or returned.

## Example

```ts
const g = globalThis
```

## How to fix

Use its members directly:

```ts
const max = globalThis.Math.max(1, 2)
```
