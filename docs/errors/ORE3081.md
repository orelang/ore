# ORE3081

> A union of promises and other values cannot be awaited yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Concurrency](../spec/06-concurrency.md#async-functions-and-promises)

## What it means

`await` on a value whose type is a union of a promise and something else,
such as `int | Promise<int>`, would have to test at run time which one it
holds. This is not supported yet.

## Example

```ts
function maybe(cached: bool): int | Promise<int> {
    return cached ? 1 : Promise.resolve(2)
}
console.log(await maybe(true))
```

## How to fix

Make it a promise in every case:

```ts
function maybe(cached: bool): Promise<int> {
    return cached ? Promise.resolve(1) : Promise.resolve(2)
}
console.log(await maybe(true))
```
