# ORE6084

> The return type of an async generator function must be 'AsyncGenerator<T, TReturn, TNext>', 'AsyncIterator<T>' or 'AsyncIterableIterator<T>', not '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

An async generator function returns an `AsyncGenerator`, which converts to
the interfaces `AsyncIterator` and `AsyncIterableIterator`; no other result
type fits, not `Promise<T>` either: the generator gives its values one
promise at a time.

## Example

```ts
async function* count(n: int): Promise<int> {
    for (let i = 0; i < n; i++) yield i
}
```

## How to fix

```ts
async function* count(n: int): AsyncGenerator<int> {
    for (let i = 0; i < n; i++) yield i
}
```
