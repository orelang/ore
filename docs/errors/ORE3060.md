# ORE3060

> Cannot format a value of type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`console.log` and template literals format numbers, `bool`, strings, `null`
and unions of these. Objects, arrays, maps and functions have no implicit
text form in Ore: JavaScript would print `[object Object]` or the source of
a function.

## Example

```ts
const p = { x: 1, y: 2 }
console.log(p)
```

## How to fix

Format the fields you want:

```ts
const p = { x: 1, y: 2 }
console.log(`(${p.x}, ${p.y})`)
```

Or convert the value to JSON:

```ts
const p = { x: 1, y: 2 }
console.log(JSON.stringify(p))
```

Arrays of numbers or strings can be joined:

```ts
const xs = [1, 2, 3]
console.log(xs.join(", "))
```
