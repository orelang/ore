# ORE7027

> The loop variable must be declared with 'const' or 'let'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

The variable of a `for...of` loop is declared by the loop, with `const` (or
`let` to reassign it in the body). Assigning an existing variable as the
loop variable is not supported.

## Example

```ts
let x = 0
for (x of [1, 2]) {}
```

## How to fix

Declare the loop variable, and copy it out if needed:

```ts
let last = 0
for (const x of [1, 2]) last = x
```
