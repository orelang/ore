# ORE6010

> Variable '…' needs a type annotation or an initializer.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Variables](../spec/02-types.md#variables)

## What it means

A variable declared without a type or a value, `let x`, takes the type of
its first assignment. This one is never assigned, so it has no type.

## Example

```ts
let total
```

## How to fix

Annotate the variable, or give it a value:

```ts
let total: int
let count = 0
```
