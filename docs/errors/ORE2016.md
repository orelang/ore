# ORE2016

> This kind of type is not supported yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

The type uses TypeScript syntax that Ore does not support (yet): `keyof`,
`typeof` in a type, indexed access (`T["x"]`), mapped and conditional types,
template literal types, and the like. Types in Ore describe the layout of
values, and these type-level computations have no counterpart there.

## Example

```ts
type Keys = keyof { x: int; y: int }
```

## How to fix

Write the type out. A set of names is a union of string literals:

```ts
type Keys = "x" | "y"
```
