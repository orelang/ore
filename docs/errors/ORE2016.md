# ORE2016

> This kind of type is not supported yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

The type uses TypeScript syntax that the checker does not know. `keyof`,
`typeof` in a type, indexed access, conditional, mapped and template
literal types are supported now (see
[computed types](../spec/03-objects.md#computed-types)), and the parser
rejects the type syntax Ore does not read, such as type predicates
(`x is string`) and constructor types (`new () => T`), with syntax errors.
So this message is not produced at present.
