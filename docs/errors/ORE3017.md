# ORE3017

> '>>>' is not supported in Ore. Use '>>' on an unsigned type.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

In JavaScript, `>>>` is the unsigned right shift of a 32-bit number. Ore has
real unsigned types, where `>>` is already a logical shift (it is
arithmetic on signed types), so `>>>` is not needed and not supported.

## Example

```ts
let n = -8
const half = n >>> 1
```

## How to fix

Shift an unsigned value with `>>`, converting first if needed:

```ts
let n = -8
const half = u64(n) >> 1
```
