# ORE5023

> Non-abstract class '…' does not implement inherited abstract member '…' from class '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

The base class declares an abstract method, and this class — which is not
abstract and so can be instantiated — neither implements it nor inherits an
implementation.

## Example

```ts
abstract class Shape {
    abstract area(): f64
}
class Square extends Shape {}
```

## How to fix

Implement the method:

```ts
abstract class Shape {
    abstract area(): f64
}
class Square extends Shape {
    area(): f64 {
        return 1.0
    }
}
```

Or declare the class abstract as well.
