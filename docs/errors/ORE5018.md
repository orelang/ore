# ORE5018

> A method must have a body.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A method of a class needs a body, unless it is `abstract`. Ore has no
method overload signatures and no ambient declarations.

## Example

```ts
class Point {
    show(): void
}
```

## How to fix

Write the body:

```ts
class Point {
    show(): void {}
}
```
