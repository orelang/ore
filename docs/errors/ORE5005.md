# ORE5005

> Class '…' extends itself.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

A class cannot extend itself, directly or through other classes: its fields
would contain themselves.

## Example

```ts
class Node extends Node {}
```

## How to fix

Remove the `extends` clause, or extend another class. A class can still
refer to itself in its fields:

```ts
class Node {
    next: Node | null = null
}
```
