# ORE4097

> A dictionary is not iterable: use 'Object.entries(d)'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

A dictionary is not iterable, as a JavaScript object is not:
`Object.fromEntries`, `Object.groupBy` and `Map.groupBy` need its entries.

## Example

```ts
const d: Record<string, int> = { a: 1 }
const copy = Object.fromEntries(d)
```

## How to fix

```ts
const d: Record<string, int> = { a: 1 }
const copy = Object.fromEntries(Object.entries(d))
```
