# ORE2047

> Cannot find name '…'. Use '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

The name is a built-in function that moved into a namespace, as in
TypeScript and Node: `println` is `console.log`, `print` is `console.write`,
and `panic` is `process.panic`.

## Example

```ts
println("hello")
```

## How to fix

Use the name the message suggests:

```ts
console.log("hello")
```
