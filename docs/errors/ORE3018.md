# ORE3018

> The comma operator is not supported in Ore.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

The comma operator, which evaluates expressions in order and keeps the last
value, is not supported: it is rarely clearer than separate statements.

## Example

```ts
let a = 0
let b = (a++, a * 2)
```

## How to fix

Write separate statements:

```ts
let a = 0
a++
let b = a * 2
```

In a `for` loop, update several variables in the body, or keep one loop
variable:

```ts
for (let i = 0, j = 10; i < j; i++) {
    j--
}
```
