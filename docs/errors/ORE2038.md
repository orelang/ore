# ORE2038

> A numeric constant is not assignable to type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Numeric literals](../spec/02-types.md#numeric-literals)

## What it means

A numeric constant is assigned to a union that has no numeric member, so it
cannot become any of the union's types.

## Example

```ts
let value: string | bool = 1
```

## How to fix

Add a numeric type to the union, or assign a value of one of its members:

```ts
let value: string | bool | int = 1
```
