# ORE2029

> A value cannot have type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Variables](../spec/02-types.md#variables)

## What it means

`void` and `never` are only result types of functions: `void` means that the
function returns no value, `never` that it does not return. A variable,
parameter, field or element cannot have them as its type, since there would
be no value to store.

## Example

```ts
function done(result: void) {}
```

## How to fix

Use a type that has a value, such as `bool` or `T | null`, or remove the
parameter:

```ts
function done(ok: bool) {}
```
