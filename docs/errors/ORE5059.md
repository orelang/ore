# ORE5059

> Constructor of class '…' is … and only accessible within the class declaration.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A `private` or `protected` constructor can be called with `new` only inside
the declaration of its class, for example by a static factory method. A
subclass calls a `protected` constructor through `super(...)`, not with
`new`.

## Example

```ts
class Connection {
    private constructor(readonly url: string) {}
    static open(url: string): Connection {
        return new Connection(url)
    }
}
const c = new Connection("db://local")
```

## How to fix

Create instances the way the class provides:

```ts
const c = Connection.open("db://local")
```

Or make the constructor public.
