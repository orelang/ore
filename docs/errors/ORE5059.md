# ORE5059

> A 'this' type is available only in a non-static member of a class or interface.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

The type `this` is the type of the receiver of a method, so it exists only
in the fields, methods, accessors and constructor of a class, not in its
static members nor outside classes. TypeScript reports the same error
(TS2526).

## Example

```ts
class Counter {
    count = 0
    static reset(counter: this) {
        counter.count = 0
    }
}
```

## How to fix

Name the class instead:

```ts
class Counter {
    count = 0
    static reset(counter: Counter) {
        counter.count = 0
    }
}
```
