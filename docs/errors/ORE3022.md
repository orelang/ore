# ORE3022

> Only strings can be concatenated with '+'. Use a template literal: `${a}${b}`.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Strings](../spec/02-types.md#strings)

## What it means

`+` concatenates two strings, or adds two numbers of the same type. Ore does
not convert a number to a string implicitly, as JavaScript does for
`"a" + 1`.

## Example

```ts
let count = 3
const label = "items: " + count
```

## How to fix

Use a template literal, which formats numbers and `bool`:

```ts
let count = 3
const label = `items: ${count}`
```

Or convert the value with `toString()`:

```ts
let count = 3
const label = "items: " + count.toString()
```
