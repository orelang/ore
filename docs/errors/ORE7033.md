# ORE7033

> A switch can have only one 'default' clause.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

A `switch` has at most one `default` clause.

## Example

```ts
let n = 1
switch (n) {
    default:
        break
    default:
        break
}
```

## How to fix

Merge the two clauses:

```ts
let n = 1
switch (n) {
    default:
        break
}
```
