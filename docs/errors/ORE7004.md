# ORE7004

> Type '…' is not disposable: it needs a '[Symbol.dispose](): void' method.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Resources](../spec/04-functions.md#resources)

## What it means

`using x = value` calls `x[Symbol.dispose]()` when the block ends, so the
value's type must have that method: it must implement the built-in
interface `Disposable`.

## Example

```ts
class File {
    close() {}
}
function read() {
    using f = new File()
}
```

## How to fix

Add a `[Symbol.dispose](): void` method:

```ts
class File {
    close() {}
    [Symbol.dispose]() {
        this.close()
    }
}
function read() {
    using f = new File()
}
```

Or use `const`, and release the value yourself.
