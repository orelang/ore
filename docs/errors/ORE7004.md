# ORE7004

> Type '…' is not disposable: it needs a '[Symbol.dispose](): void' method.

Group: [Statements](README.md#ore7xxx-statements) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
class Plain {}

using p = new Plain()
```
