# ORE3069

> Type '…' cannot be null; '!' is not needed.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

`x!` asserts that `x` is not `null`. The value's type does not include
`null`, so the assertion is not needed.

## Example

```ts
let name = "ada"
const n = name!
```

## How to fix

Remove the `!`:

```ts
let name = "ada"
const n = name
```
