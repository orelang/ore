# ORE6050

> '//ore:…' needs a C name, e.g. '//ore:… my_function'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

The directive takes a C name: `//ore:export name` exports the function or
variable to C under `name`, and `//ore:runtime name` names the runtime
function it implements.

## Example

```ts
//ore:export
function add(a: int, b: int): int {
    return a + b
}
```

## How to fix

Give the C name:

```ts
//ore:export ore_add
function add(a: int, b: int): int {
    return a + b
}
```
