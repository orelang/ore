# ORE6064

> Cannot download …: …

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules from GitHub](../spec/07-modules.md#modules-from-github)

## What it means

The repository of a module imported from GitHub is not in the cache, and
git could not download it: the repository does not exist or is private, or
the network is down. The rest of the message is git's error.

## Example

```ts
import { x } from "https://github.com/acme/no-such-repository"
```

## How to fix

Check the URL and the network. A repository that was downloaded once is
used offline from the cache (with a warning); one never downloaded needs
the network. Private repositories need git credentials that work without a
prompt.

```ts
import { x } from "https://github.com/acme/geo"
```
