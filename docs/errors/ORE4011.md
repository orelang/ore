# ORE4011

> Class '…' must be instantiated with 'new …(...)'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A class is instantiated with `new`. Calling the class like a function is not
allowed, as in JavaScript.

## Example

```ts
class Point {
    x = 0
}
const p = Point()
```

## How to fix

Add `new`:

```ts
class Point {
    x = 0
}
const p = new Point()
```
