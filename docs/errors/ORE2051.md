# ORE2051

> Only object types and interfaces can be intersected, not '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An intersection combines the members of object types and interfaces. A
primitive type such as `string` or `int`, a union or a function type has no
members to combine, so it cannot be part of one (TypeScript's "branded"
primitives, `string & { brand: ... }`, are not supported).

## Example

```ts
type Id = string & { kind: string }
```

## How to fix

Use an object type with the value as a field:

```ts
type Id = { value: string; kind: string }
```
