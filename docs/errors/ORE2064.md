# ORE2064

> 'intrinsic' is only the type of Uppercase, Lowercase, Capitalize and Uncapitalize.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

`intrinsic` marks a type that the compiler computes itself. Only the four string types of the language are such types: `Uppercase`, `Lowercase`, `Capitalize` and `Uncapitalize`.

## Example

```ts
type Reverse<S extends string> = intrinsic
const r: Reverse<"ab"> = "ba"
```

## How to fix

Write the type out, or use one of the four:

```ts
type Loud<S extends string> = Uppercase<S>
const l: Loud<"ab"> = "AB"
```
