# ORE5007

> Duplicate member '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

Two members of a class have the same name. Fields, methods, accessors and
parameter properties share one namespace, and Ore has no method overloads.
A getter and a setter of the same property are one member.

## Example

```ts
class Point {
    x = 0
    x = 1
}
```

## How to fix

Rename or remove one of them:

```ts
class Point {
    x = 0
    y = 1
}
```
