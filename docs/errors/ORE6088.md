# ORE6088

> '//ore:…' applies to a 'declare function' that is not variadic.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

`//ore:blocking` marks an external C function that may wait (for a lock, a
condition, I/O or another thread): the thread is parked while it runs. It
applies to a `declare function` with fixed parameters only, since the call
goes through a wrapper with the C function's parameters.

## Example

```ts
//ore:blocking
function wait(): void {}
```

## How to fix

Apply it to the declaration of the C function:

```ts
//ore:blocking
declare function pthread_rwlock_wrlock(lock: ptr): i32
```
