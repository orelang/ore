# ORE3034

> Cannot infer the type of '…' from this value. Add a type annotation, e.g. 'let …: T'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Variables](../spec/02-types.md#variables)

## What it means

A variable declared without a type and a value, `let x`, takes the type of
its first assignment. That value here is `null`, or the result of a
function returning `void`, which says nothing about the variable's type.

## Example

```ts
let result
result = null
```

## How to fix

Annotate the variable:

```ts
let result: string | null
result = null
```
