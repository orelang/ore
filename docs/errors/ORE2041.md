# ORE2041

> Operator '~' requires an integer operand.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

The bitwise complement `~` works on integers. A constant with a fraction is
a float constant, and Ore does not truncate it as JavaScript does.

## Example

```ts
const x = ~1.5
```

## How to fix

Apply `~` to an integer, converting explicitly if needed:

```ts
const x = ~int(1.5)
```
