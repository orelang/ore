# ORE6027

> External functions cannot be generic.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

A C function has one machine signature, so a `declare function` cannot have
type parameters.

## Example

```ts
declare function first<T>(xs: ptr): T
```

## How to fix

Declare it with concrete types, one declaration per C function:

```ts
declare function first(xs: ptr): i64
```
