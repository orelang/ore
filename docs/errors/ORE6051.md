# ORE6051

> '//ore:…' takes no argument.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

The directive (`//ore:inline`, `//ore:noinline`, `//ore:cold`,
`//ore:naked`, `//ore:threadlocal`, `//ore:internal`) takes no argument. A
comment may follow it on the same line only after another `//`.

## Example

```ts
//ore:inline always
function add(a: int, b: int): int {
    return a + b
}
```

## How to fix

Remove the argument:

```ts
//ore:inline
function add(a: int, b: int): int {
    return a + b
}
```
