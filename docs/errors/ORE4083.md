# ORE4083

> 'Array.from' takes an object only as '{ length: n }'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

An object passed to `Array.from` gives only the length of the new array,
as `{ length: n }`; Ore has no array-like objects with other properties.

## Example

```ts
Array.from({ size: 3 }, (_, i) => i)
```

## How to fix

Name the property `length`:

```ts
Array.from({ length: 3 }, (_, i) => i)
```
