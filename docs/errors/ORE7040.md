# ORE7040

> Parameter '…' needs a type annotation here.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A parameter of a function literal takes its type from the context: the
function type of the variable or parameter it is assigned to. Here there is
no such context, so the parameter needs an annotation.

## Example

```ts
const double = (x) => x * 2
```

## How to fix

Annotate the parameter:

```ts
const double = (x: int) => x * 2
```

Or give the variable a function type:

```ts
const double: (x: int) => int = (x) => x * 2
```
