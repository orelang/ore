# ORE5017

> Generic methods cannot be abstract.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

A generic method is instantiated per call, and generic methods cannot be
overridden, so an abstract generic method could never be implemented.

## Example

```ts
abstract class Store {
    abstract get<T>(key: string): T
}
```

## How to fix

Make the class generic instead of the method:

```ts
abstract class Store<T> {
    abstract get(key: string): T
}
```
