# ORE4088

> '…' cannot copy the field '…' into '…': it has no writable field '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The namespace Object](../spec/03-objects.md#the-namespace-object)

## What it means

`Object.assign` into an object copies fields that the target has, and can
write: an object has a fixed set of fields.

## Example

```ts
const p = { x: 1 }
Object.assign(p, { y: 2 })
```

## How to fix

Copy into an object that has the field, or into a dictionary.
