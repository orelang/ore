# ORE2055

> Type '…' has no elements indexed by number.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

`T[number]` is the type of the elements of an array or a tuple; other types have no elements indexed by number.

## Example

```ts
type P = { x: int }
type E = P[number]
```

## How to fix

Index an array type:

```ts
type Points = { x: int }[]
type Point = Points[number]
```
