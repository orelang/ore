# ORE3019

> 'in' tests the keys of a dictionary, '{ [key: string]: T }', only, not of '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

`key in object` tests whether an object has a property. The fields of an
object are known when the program is compiled, so `in` tests the keys of
dictionaries only.

## Example

```ts
const p = { x: 1 }
console.log("x" in p)
```

## How to fix

Test a dictionary, or `Object.hasOwn(p, "x")` for an optional field:

```ts
const d: Record<string, int> = { x: 1 }
console.log("x" in d)
```
