# ORE3019

> 'in' is not supported in Ore.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

`key in object` tests at run time whether an object has a property. In Ore
the fields of an object are known when the program is compiled, so the test
has no use for objects; for keys that vary, a `Map` has `has`.

## Example

```ts
const user = { name: "ada" }
const named = "name" in user
```

## How to fix

Use a `Map` and `has`:

```ts
const user = new Map<string, string>([["name", "ada"]])
const named = user.has("name")
```

For a union of object types, tell the members apart by a discriminant field
or with `instanceof`.
