# ORE5020

> A class can have only one constructor.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A class has at most one constructor. Ore has no overloaded constructors.

## Example

```ts
class Point {
    constructor() {}
    constructor(x: int) {}
}
```

## How to fix

Write one constructor with optional parameters or default values:

```ts
class Point {
    constructor(public x = 0) {}
}
```

Or add static methods that create instances in different ways:

```ts
class Point {
    constructor(public x: int) {}
    static origin(): Point {
        return new Point(0)
    }
}
```
