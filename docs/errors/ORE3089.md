# ORE3089

> Only a member named by a string literal can be assigned to: 'object["name"] = value'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

A field of an object is assigned by its name: `p.x = 1` or `p["x"] = 1`. A
key of a `keyof` type, which names one of several fields, is only read.

## Example

```ts
function set(p: { x: int; y: int }, k: "x" | "y") {
    p[k] = 0
}
```

## How to fix

Assign the field by its name, in a `switch` on the key.
