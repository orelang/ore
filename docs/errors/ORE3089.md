# ORE3089

> Only a member named by a string literal or a 'keyof' type can be assigned to: 'object["name"] = value'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

A field of an object is assigned by its name: `p.x = 1` or `p["x"] = 1`, or
by a key of a `keyof` type (string literal types), which stores into the
field the key names at run time: `p[k] = 1` with `k: "x" | "y"`. Any other
string, such as a `string`, may name no field at all. A union of object
types is assigned only by a name.

## Example

```ts
function set(p: { x: int; y: int }, k: string) {
    p[k] = 0
}
```

## How to fix

Give the key the type of the names it can be, `keyof` the object's type:

```ts
type P = { x: int; y: int }

function set(p: P, k: keyof P) {
    p[k] = 0
}
```

or, for any string, keep the values in a
[dictionary](../spec/03-objects.md#dictionaries).
