# ORE7020

> A 'const' declaration must be initialized.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

A `const` cannot be assigned after its declaration, so it must be given its
value there.

## Example

```ts
const limit: int
```

## How to fix

Give it a value, or declare it with `let` if it is assigned later:

```ts
const limit = 10
let max: int
max = 20
```
