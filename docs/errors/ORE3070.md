# ORE3070

> The left side of '??' cannot be null.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

The left side of `??` is a constant, such as a number literal, which is
never `null`, so the right side would never be used.

## Example

```ts
const limit = 10 ?? 20
```

## How to fix

Remove the `??` part, or use a value that can be null on the left:

```ts
function limit(given: int | null): int {
    return given ?? 20
}
```
