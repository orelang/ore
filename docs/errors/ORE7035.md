# ORE7035

> A constructor cannot return a value.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A constructor initializes the instance that `new` returns; it cannot return
another value. `return` without a value may end it early.

## Example

```ts
class Point {
    constructor() {
        return 1
    }
}
```

## How to fix

Remove the value. To create instances in other ways, use a static method:

```ts
class Point {
    constructor(public x: int) {}
    static origin(): Point {
        return new Point(0)
    }
}
```
