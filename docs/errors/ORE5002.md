# ORE5002

> Modifier '…' is not allowed on classes.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A class declaration accepts the modifiers `export` and `abstract`. Others,
such as `declare` or `default`, have no meaning for an Ore class: there are
no ambient classes, since every class is compiled with the program.

## Example

```ts
declare class Point {}
```

## How to fix

Remove the modifier:

```ts
class Point {}
```
