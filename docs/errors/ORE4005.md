# ORE4005

> '…' has no member '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

The built-in namespace (`Math`, `console`, `process`, `fs`, `task`,
`unsafe`, ...) has no member with this name. The members are listed in the
specification; some JavaScript functions are missing or differ, and
`std/builtin.d.ore` declares them all.

## Example

```ts
const r = Math.squareRoot(2.0)
```

## How to fix

Use the name of an existing member:

```ts
const r = Math.sqrt(2.0)
```
