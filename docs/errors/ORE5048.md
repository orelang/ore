# ORE5048

> '…' is not an interface.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

`implements` names interfaces. A class cannot be implemented, since classes
are nominal; to share a class's members, extend it.

## Example

```ts
class Shape {}
class Square implements Shape {}
```

## How to fix

Extend the class, or declare an interface for the members:

```ts
class Shape {}
class Square extends Shape {}
```
