# ORE6087

> An async function needs a return type annotation, such as 'Promise<T>': ….

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Async functions and promises](../spec/06-concurrency.md#async-functions-and-promises)

## What it means

Without an annotation, an async function that returns a value has the type
`Promise<T>`, with T the types of the values it returns. Ore cannot take it
from the body when the type is needed before the body is checked:

- the function is used in its own body, such as a recursive call;
- it is a nested function declaration, which is hoisted: it can be called
  before its body, which sees the variables declared after it;
- it is a method of an object literal that uses `this`, whose type includes
  the method's.

## Example

```ts
async function depth(n: int) {
    if (n === 0) return 0
    return (await depth(n - 1)) + 1
}

console.log(await depth(3))
```

## How to fix

```ts
async function depth(n: int): Promise<int> {
    if (n === 0) return 0
    return (await depth(n - 1)) + 1
}

console.log(await depth(3))
```
