# ORE3085

> The operand of a 'delete' operator cannot be a read-only property.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

An entry of a readonly dictionary cannot be deleted.

## Example

```ts
const d: Readonly<Record<string, int>> = { a: 1 }
delete d.a
```

## How to fix

Delete through a dictionary that is not readonly.
