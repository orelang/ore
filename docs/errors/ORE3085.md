# ORE3085

> 'as const' takes object literals of 'name: value' properties.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

`{ ... } as const` is an object of read-only fields of the values' literal types, so each property is written as `name: value`.

## Example

```ts
const level = 2
const config = { level } as const
```

## How to fix

Write the property with its value:

```ts
const config = { level: 2 } as const
```
