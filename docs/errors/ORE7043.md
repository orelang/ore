# ORE7043

> A rest element cannot have a default value.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

A rest element is never null: it is an array, tuple or object of the
remaining parts, empty when nothing remains. A default value for it would
never be used.

## Example

```ts
const [first, ...others = [0]] = [1, 2]
```

## How to fix

Remove the default value, and check the length of the rest if needed:

```ts
const [first, ...others] = [1, 2]
const more = others.length > 0 ? others : [0]
```
