# ORE3035

> Strings are immutable.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Strings](../spec/02-types.md#strings)

## What it means

Strings are immutable: `s[i]` reads the byte at `i`, but cannot change it.

## Example

```ts
let s = "cat"
s[0] = 98
```

## How to fix

Build a new string:

```ts
let s = "cat"
s = "b" + s.slice(1)
```
