# ORE7012

> Exceptions are not supported in Ore. Return an error value, or call panic() for unrecoverable failures.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Errors](../spec/05-errors.md)

## What it means

Ore has no exceptions: `throw`, `try`, `catch` and `finally` are rejected.
Errors are values. A function that can fail returns a union with `Error`,
and the caller checks it with `instanceof`, as in Go. Bugs and states that
cannot be recovered from end the program with `process.panic(message)`.

## Example

```ts
function parse(s: string): int {
    if (s === "") throw new Error("empty input")
    return s.length
}
```

## How to fix

Return the error, and check it where the function is called:

```ts
function parse(s: string): int | Error {
    if (s === "") return new Error("empty input")
    return s.length
}
const n = parse("abc")
if (n instanceof Error) console.error(n.message)
else console.log(n + 1)
```

For a failure that is a bug, panic:

```ts
function parse(s: string): int {
    if (s === "") process.panic("empty input")
    return s.length
}
```

Cleanup that `finally` would do is written with `using`.
