# ORE7007

> Cannot find loop label '…'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

`break label` and `continue label` name a labeled loop or switch that
encloses them, and none has this label.

## Example

```ts
for (const x of [1, 2]) {
    if (x > 1) break outer
}
```

## How to fix

Label the loop, or correct the name:

```ts
outer: for (const x of [1, 2]) {
    if (x > 1) break outer
}
```
