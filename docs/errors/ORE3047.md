# ORE3047

> An array cannot contain values of type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

An element of an array literal is a call that returns `void` (or never
returns), so there is no value to store.

## Example

```ts
const results = [console.log("a")]
```

## How to fix

Store values; call the function as a statement:

```ts
console.log("a")
const results = ["a"]
```
