# ORE4007

> Conversion '…' expects exactly 1 argument, got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Conversions](../spec/02-types.md#conversions)

## What it means

A conversion — a call of a type name such as `i32(x)` or `f64(x)` — takes
exactly one argument, the value to convert. It has no radix or other
options.

## Example

```ts
const n = i32(1, 2)
```

## How to fix

Pass one value:

```ts
const n = i32(1)
```

To parse a string in a radix, use `Number.parseInt`:

```ts
const n = Number.parseInt("ff", 16)
```
