# ORE7015

> Duplicate label '…'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

A label is used again by a loop or switch inside the one it already names,
so `break` and `continue` with that label would be ambiguous.

## Example

```ts
rows: for (let i = 0; i < 2; i++) {
    rows: for (let j = 0; j < 2; j++) break rows
}
```

## How to fix

Give the inner loop another label:

```ts
rows: for (let i = 0; i < 2; i++) {
    cols: for (let j = 0; j < 2; j++) break rows
}
```
