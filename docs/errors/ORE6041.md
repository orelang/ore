# ORE6041

> A required parameter cannot follow an optional or rest parameter.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

Arguments are matched by position, so the parameters that can be left out —
optional, default and rest parameters — must come after the required ones.

## Example

```ts
function pad(width?: int, s: string) {}
```

## How to fix

Put the required parameters first:

```ts
function pad(s: string, width?: int) {}
```
