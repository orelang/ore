# ORE5011

> Field '…' needs a type annotation or an initializer.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A field needs a type, from its annotation or from its initializer. Ore has
no `any` to fall back to.

## Example

```ts
class Point {
    x
}
```

## How to fix

Annotate the field, or give it an initial value:

```ts
class Point {
    x: int
    y = 0
}
```
