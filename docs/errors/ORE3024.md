# ORE3024

> Operator '…' requires integer operands, got '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

The bitwise operators `&`, `|` and `^` work on integers. They are not
defined on `f32` and `f64`; JavaScript would truncate the floats to 32-bit
integers first.

## Example

```ts
let a = 6.0
const masked = a & 3.0
```

## How to fix

Convert to an integer type first:

```ts
let a = 6.0
const masked = int(a) & 3
```
