# ORE4014

> The callback of 'map' must return a value.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

`a.map(f)` makes a new array of the values `f` returns. The callback here
returns nothing (`void`), so there would be no elements.

## Example

```ts
const xs = [1, 2, 3]
xs.map((x) => {
    console.log(x)
})
```

## How to fix

To run code for each element, use `forEach`:

```ts
const xs = [1, 2, 3]
xs.forEach((x) => {
    console.log(x)
})
```

To build a new array, return a value from the callback:

```ts
const xs = [1, 2, 3]
const doubled = xs.map((x) => x * 2)
```
