# ORE4089

> A dictionary is not iterable: use 'new Map(Object.entries(d))'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

A dictionary is not iterable, as a JavaScript object is not: `new Map(d)`
needs its entries.

## Example

```ts
const d: Record<string, int> = { a: 1 }
const m = new Map(d)
```

## How to fix

```ts
const d: Record<string, int> = { a: 1 }
const m = new Map(Object.entries(d))
```
