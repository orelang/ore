# ORE7037

> A function without a return type annotation cannot return a value.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

The return type of a top-level function or method is not inferred from its
body: a function without a return type annotation returns nothing (`void`).
Only function literals infer their return type, from the context or the
first `return`.

## Example

```ts
function double(x: int) {
    return x * 2
}
```

## How to fix

Annotate the return type:

```ts
function double(x: int): int {
    return x * 2
}
```
