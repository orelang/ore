# ORE4022

> '…' expects … argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

A built-in method or function was called with too few or too many
arguments; the message gives how many it takes.

## Example

```ts
const s = [1, 2].join(",", " ")
```

## How to fix

Pass the arguments it takes:

```ts
const s = [1, 2].join(", ")
```
