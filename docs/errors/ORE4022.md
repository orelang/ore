# ORE4022

> '…' expects … argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
xs.filter((x) => x)
xs.map((s: string) => 1)
xs.reduce((a, b) => a + b)
```

`tests/diag/collections/array-methods.ore:7`: 'reduce' expects 2 argument(s), got 1.
