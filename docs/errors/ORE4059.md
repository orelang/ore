# ORE4059

> A 'super' call is only allowed in the constructor of a class that extends another class.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`super(...)` calls the constructor of the base class, so it is only allowed
in the constructor of a class declared with `extends`.

## Example

```ts
class Point {
    constructor() {
        super()
    }
}
```

## How to fix

Remove the call, or make the class extend its base class:

```ts
class Shape {}
class Point extends Shape {
    constructor() {
        super()
    }
}
```
