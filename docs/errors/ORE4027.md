# ORE4027

> '…' takes one type argument.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

The generic functions of `unsafe` take one type argument: the type of the
value read, written or measured.

## Example

```ts
const n = unsafe.sizeOf<int, int>()
```

## How to fix

Give one type:

```ts
const n = unsafe.sizeOf<int>()
```
