# ORE7031

> Duplicate name '…'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

The key and the value of a `for (const [key, value] of map)` loop are
declared with the same name.

## Example

```ts
const ages = new Map<string, int>()
for (const [x, x] of ages) {}
```

## How to fix

Give them different names, or `_` to one you do not use:

```ts
const ages = new Map<string, int>()
for (const [name, age] of ages) console.log(name, age)
```
