# ORE6057

> A '//ore:naked' function holds only 'unsafe.asm(template, constraints)' statements.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

A `//ore:naked` function has no prologue or epilogue: no stack frame is set
up, so its body may hold only inline assembly, `unsafe.asm(template,
constraints)` statements, possibly chosen by `if` on a constant such as
`target.arch`. The assembly must return by itself.

## Example

```ts
//ore:naked
function entry() {
    console.log("start")
}
```

## How to fix

Write the body in assembly only:

```ts
//ore:naked
function entry() {
    if (target.arch === "arm64") unsafe.asm("ret", "")
    else unsafe.asm("retq", "")
}
```
