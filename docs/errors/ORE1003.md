# ORE1003

> Declaration expected.

Group: [Syntax](README.md#ore1xxx-syntax) · specification: [Source files](../spec/01-programs.md#source-files)

## What it means

A declaration was expected after `export` or `declare`, but the code there
is an expression. `export` and `declare` apply to `function`, `class`,
`interface`, `type`, `let` and `const` declarations only.

## Example

```ts
export 5
```

## How to fix

Declare a name and export the declaration:

```ts
export const five = 5
```
