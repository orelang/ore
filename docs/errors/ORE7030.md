# ORE7030

> Type '…' is not iterable.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

`for...of` iterates arrays, strings (by rune), maps, sets and channels.
Other values — numbers, tuples, objects, class instances — are not
iterable; Ore has no `[Symbol.iterator]` protocol.

## Example

```ts
for (const i of 5) {}
```

## How to fix

Use a counting loop for a range of numbers:

```ts
for (let i = 0; i < 5; i++) {}
```

For an object of your own, iterate an array it returns.
