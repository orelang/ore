# ORE3057

> Missing … … of type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An object literal for an object type must set every field that is not
optional. Fields have no implicit default in object literals.

## Example

```ts
type Point = { x: int; y: int }
const p: Point = { x: 1 }
```

## How to fix

Set the missing fields:

```ts
type Point = { x: int; y: int }
const p: Point = { x: 1, y: 0 }
```

Or make the field optional, so that it is `null` when left out:

```ts
type Point = { x: int; y?: int }
const p: Point = { x: 1 }
```
