# ORE6061

> A parameter property is only allowed in a constructor.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A modifier such as `public`, `private`, `protected` or `readonly` on a
parameter makes it a parameter property: it declares a field of the class and
assigns the argument to it. Only a constructor creates the instance whose
fields these are, so on the parameters of other functions and methods the
modifier has no meaning, as in TypeScript.

## Example

```ts
class Counter {
    add(readonly step: int): void {}
}
```

## How to fix

Leave the modifier out of a method's or function's parameter:

```ts
class Counter {
    add(step: int): void {}
}
```

Or declare the field with a constructor parameter:

```ts
class Counter {
    constructor(readonly step: int) {}
}
```
