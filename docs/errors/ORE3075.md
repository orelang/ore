# ORE3075

> An index must be an integer, got '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

Arrays, tuples and strings are indexed by integers, of any integer type.
A float or a string is not an index, and Ore does not convert it
implicitly. This is also the error for `map["key"]`: a `Map` is read with
`get`.

## Example

```ts
const xs = [1, 2, 3]
let i = 1.0
console.log(xs[i])
```

## How to fix

Convert the index to an integer type:

```ts
const xs = [1, 2, 3]
let i = 1.0
console.log(xs[int(i)])
```

For a map, use `get`:

```ts
const ages = new Map<string, int>()
console.log(ages.get("ada") ?? 0)
```
