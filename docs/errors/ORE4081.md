# ORE4081

> 'Array.isArray' cannot test an 'unknown' yet.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

`Array.isArray(x)` is known from the type of `x`, and tested at run time
when `x` is a union with array members. A value of type `unknown` cannot be
tested for being an array yet.

## Example

```ts
const value: unknown = [1, 2]
Array.isArray(value)
```

## How to fix

Keep the value in a union that names the array types it may be:

```ts
const value: int[] | string = [1, 2]
Array.isArray(value)
```
