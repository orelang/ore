# ORE4081

> 'Array.isArray' cannot test an 'unknown' yet.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

This message is no longer produced: `Array.isArray(x)` of an `unknown`
tells whether it holds an array, of any element type, without narrowing
it. Earlier versions rejected it with this message.
