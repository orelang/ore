# ORE5058

> '…' is private and only accessible inside class '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A `private` member is accessible only inside the class that declares it,
not in subclasses nor elsewhere.

## Example

```ts
class Account {
    private balance = 0
}
console.log(new Account().balance)
```

## How to fix

Add a public method or getter that gives what callers need:

```ts
class Account {
    private balance = 0
    get total(): int {
        return this.balance
    }
}
console.log(new Account().total)
```

Or make the member public, or `protected` to share it with subclasses.
