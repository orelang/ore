# ORE7029

> Iterate a Map with 'for (const [key, value] of map)'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

`for...of` over a map gives `[key, value]` pairs, which Ore destructures in
the loop itself: the loop variable must be an array pattern of two plain
names.

## Example

```ts
const ages = new Map<string, int>()
for (const entry of ages) {}
```

## How to fix

Destructure the key and the value:

```ts
const ages = new Map<string, int>()
for (const [name, age] of ages) console.log(name, age)
```

To iterate only the keys or the values, use `keys()` or `values()`:

```ts
const ages = new Map<string, int>()
for (const name of ages.keys()) console.log(name)
```
