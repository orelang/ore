# ORE3012

> '…' is a module; use its exports, e.g. '….name'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

A module imported with `import * as m` is a namespace for its exports, not
a value: it cannot be stored or passed.

## Example

```ts
import * as config from "./config"
const c = config
// file: config.ore
export const port = 8080
```

## How to fix

Use its exports by name:

```ts
import * as config from "./config"
const port = config.port
// file: config.ore
export const port = 8080
```
