# ORE4049

> 'new Map' takes an array of [key, value] pairs, got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

`new Map(entries)` takes an array of `[key, value]` tuples, or another map
to copy. The argument here is neither.

## Example

```ts
const m = new Map(5)
```

## How to fix

Pass the pairs, or nothing for an empty map:

```ts
const m = new Map([["a", 5]])
```
