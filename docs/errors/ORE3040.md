# ORE3040

> Cannot assign to '…' because it has a getter but no setter.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The property is defined by a getter without a setter, so it is read-only.

## Example

```ts
class Circle {
    constructor(public r: f64) {}
    get diameter(): f64 {
        return this.r * 2
    }
}
const c = new Circle(1)
c.diameter = 4
```

## How to fix

Add a setter of the same type:

```ts
class Circle {
    constructor(public r: f64) {}
    get diameter(): f64 {
        return this.r * 2
    }
    set diameter(d: f64) {
        this.r = d / 2
    }
}
const c = new Circle(1)
c.diameter = 4
```

Or assign the underlying field.
