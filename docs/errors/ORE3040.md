# ORE3040

> Cannot assign to '…' because it has a getter but no setter.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const t = new Thing()
t.readOnly = 1
```

`tests/diag/types/accessors.ore:32`: Cannot assign to 'readOnly' because it has a getter but no setter.
