# ORE4042

> A spread argument must be a tuple, or be passed to a rest parameter.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

`...xs` passes the elements of an array as separate arguments only to a rest
parameter, since the length of an array is not known when the program is
compiled. A tuple, whose length is known, spreads into any parameters.

## Example

```ts
function add(a: int, b: int): int {
    return a + b
}
const xs = [1, 2]
const sum = add(...xs)
```

## How to fix

Use a tuple:

```ts
function add(a: int, b: int): int {
    return a + b
}
const pair: [int, int] = [1, 2]
const sum = add(...pair)
```

Or pass the elements:

```ts
function add(a: int, b: int): int {
    return a + b
}
const xs = [1, 2]
const sum = add(xs[0], xs[1])
```
