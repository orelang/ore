# ORE3039

> Property '…' does not exist on type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

The type has no property with this name. The members of a value are known
from its static type, as in TypeScript; there is no lookup by name at run
time. Some JavaScript properties are missing or named differently in Ore;
the specification lists those of strings, arrays and maps.

## Example

```ts
const p = { x: 1, y: 2 }
console.log(p.z)
```

## How to fix

Correct the name, or add the property to the type:

```ts
const p = { x: 1, y: 2 }
console.log(p.y)
```

If the value is a union, narrow it first to the member that has the
property.
