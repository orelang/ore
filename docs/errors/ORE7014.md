# ORE7014

> Labels are only supported on loops and switches.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

Labels name loops and switches, for `break label` and `continue label`.
Labels on other statements, such as blocks, are rejected.

## Example

```ts
check: {
    console.log("a")
}
```

## How to fix

Remove the label, or wrap the code in a loop that runs once, or in a
function that can `return`:

```ts
function check() {
    console.log("a")
}
check()
```
