# ORE4052

> 'new Set' takes an array or a set of values, got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Sets](../spec/03-objects.md#sets)

## What it means

`new Set(values)` takes an array of values, or another set to copy. The
argument here is neither. A string is not split into characters as in
JavaScript.

## Example

```ts
const letters = new Set("abc")
```

## How to fix

Pass an array:

```ts
const letters = new Set("abc".split(""))
```
