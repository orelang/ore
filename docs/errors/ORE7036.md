# ORE7036

> A return value of type '…' is required.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

The function has a return type, so each `return` must give a value of that
type. Ore has no `undefined` to return implicitly.

## Example

```ts
function find(xs: int[]): int {
    return
}
```

## How to fix

Return a value; if there may be none, include `null` in the return type:

```ts
function find(xs: int[]): int | null {
    return null
}
```
