# ORE6006

> An exported variable holds a number, 'bool' or 'ptr', not '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

A variable exported with `//ore:export` is read and written by C code, so it
must hold a value C understands: a number, a `bool` or a `ptr`.

## Example

```ts
//ore:export label
let label = "x"
```

## How to fix

Export a number or a pointer, such as the bytes of a string:

```ts
//ore:export label
let label = unsafe.stringData("x")
```
