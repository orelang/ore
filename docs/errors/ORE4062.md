# ORE4062

> Type arguments are only allowed for generic functions and methods.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

Type arguments (`m<int>(...)`) choose the instance of a generic function or
method. The method called here has no type parameters.

## Example

```ts
class Counter {
    add(n: int) {}
}
new Counter().add<int>(1)
```

## How to fix

Remove the type arguments:

```ts
class Counter {
    add(n: int) {}
}
new Counter().add(1)
```
