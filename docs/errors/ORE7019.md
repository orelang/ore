# ORE7019

> A destructuring declaration must be initialized.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

A destructuring declaration (`const [a, b] = ...`, `const { x } = ...`)
takes its values from its initializer, so it must have one.

## Example

```ts
let [first, second]
```

## How to fix

Give it a value to destructure:

```ts
let [first, second] = [1, 2]
```

Or declare the variables separately:

```ts
let first: int
let second: int
```
