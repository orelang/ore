# ORE5051

> Member '…' conflicts with an inherited member of a different type.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

An interface inherits a member with the same name from two interfaces, or
from an interface and its own declaration, with different types. A member
has one type.

## Example

```ts
interface A {
    id: int
}
interface B {
    id: string
}
interface C extends A, B {}
```

## How to fix

Give the member the same type everywhere, or rename one of them:

```ts
interface A {
    id: int
}
interface B {
    key: string
}
interface C extends A, B {}
```
