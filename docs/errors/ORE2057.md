# ORE2057

> 'typeof …' needs a variable or a function with a known type.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

`typeof x` in a type names a variable or a function whose type is known: a variable whose value is not checked yet, or a name that is not a value, has none.

## Example

```ts
class C {}
type T = typeof C
```

## How to fix

Use the class itself as the type, or `typeof` of a variable:

```ts
class C {}
const c: C = new C()
type T = typeof c
```
