# ORE3074

> Index … must not be negative.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

A constant index is negative. Arrays and strings are indexed from 0, and
`a[-1]` is not the last element as in some languages; in JavaScript it reads
a property named `"-1"`.

## Example

```ts
const xs = [1, 2, 3]
console.log(xs[-1])
```

## How to fix

Compute the index from the length:

```ts
const xs = [1, 2, 3]
console.log(xs[xs.length - 1])
```
