# ORE7024

> Type '…' cannot be destructured as an array.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

An array pattern (`[a, b]`) reads elements of an array or a tuple. Other
values, such as numbers, strings, maps and objects, cannot be destructured
this way.

## Example

```ts
let n = 5
const [first] = n
```

## How to fix

Destructure an array or a tuple; for a map, take its entries first:

```ts
const ages = new Map<string, int>([["ada", 36]])
const [first] = Array.from(ages.entries())
```
