# ORE6080

> The return type of a generator function must be 'Generator<T, TReturn, TNext>', 'Iterator<T>' or 'IterableIterator<T>', not '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

A generator function returns a `Generator`, which converts to the
interfaces `Iterator` and `IterableIterator`; no other result type fits.

## Example

```ts
function* count(n: int): int[] {
    for (let i = 0; i < n; i++) yield i
}
```

## How to fix

```ts
function* count(n: int): Generator<int> {
    for (let i = 0; i < n; i++) yield i
}
```
