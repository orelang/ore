# ORE7041

> Parameter type '…' does not match the expected '…'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function literal is passed where a function type is expected, and the
annotation of a parameter differs from the type that function type passes.
Parameter types must match exactly.

## Example

```ts
const xs = [1, 2]
xs.forEach((x: string) => {})
```

## How to fix

Use the expected type, or leave out the annotation to take it from the
context:

```ts
const xs = [1, 2]
xs.forEach((x) => console.log(x))
```
