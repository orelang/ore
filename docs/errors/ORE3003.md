# ORE3003

> 'this' can only be used inside a class.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

`this` is the instance in the methods, constructor, accessors and field
initializers of a class, and in arrow functions inside them. Elsewhere — in
top-level functions, top-level code and function expressions — there is no
`this`; JavaScript would give `undefined` or the global object there.

## Example

```ts
function describe(): string {
    return this.name
}
```

## How to fix

Pass the object as a parameter:

```ts
class User {
    constructor(readonly name: string) {}
}
function describe(user: User): string {
    return user.name
}
```

Or make the function a method of the class:

```ts
class User {
    constructor(readonly name: string) {}
    describe(): string {
        return this.name
    }
}
```
