# ORE3015

> '…' is a function and cannot be used as a value yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Conversions](../spec/02-types.md#conversions)

## What it means

The name is a built-in function, such as a numeric conversion (`i32`,
`f64`) or another function the compiler implements itself. It is compiled
in place at each call and has no function value yet.

## Example

```ts
const toByte = u8
```

## How to fix

Wrap the call in a function:

```ts
const toByte = (n: int) => u8(n)
```
