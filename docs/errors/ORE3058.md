# ORE3058

> Object literal may only specify known properties, and '…' does not exist in type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const p: Point = { x: 1 }
const q: Point = { x: 1, y: 2, z: 3 }
```

`tests/diag/types/interfaces.ore:39`: Object literal may only specify known properties, and 'z' does not exist in type 'Point'.
