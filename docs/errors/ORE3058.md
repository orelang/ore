# ORE3058

> Object literal may only specify known properties, and '…' does not exist in type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

An object literal converted to an interface may only have the interface's
fields, as in TypeScript: the object is created for the interface, and an
extra property could never be read through it.

## Example

```ts
interface Named {
    name: string
}
const n: Named = { name: "ada", age: 36 }
```

## How to fix

Remove the property, or add it to the interface:

```ts
interface Named {
    name: string
    age: int
}
const n: Named = { name: "ada", age: 36 }
```
