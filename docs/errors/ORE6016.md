# ORE6016

> Default imports are not supported in Ore. Use 'import { name } from ...'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

Ore modules have no default export, so there is nothing for a default
import to bind. Imports name the exports they use.

## Example

```ts
import shapes from "./shapes"
// file: shapes.ore
export class Square {}
```

## How to fix

Import the names:

```ts
import { Square } from "./shapes"
// file: shapes.ore
export class Square {}
```

Or the whole module as a namespace:

```ts
import * as shapes from "./shapes"
const s = new shapes.Square()
// file: shapes.ore
export class Square {}
```

(A default import with `with { type: "text" }` reads a file as text; see
[ORE6018](ORE6018.md).)
