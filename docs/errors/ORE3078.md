# ORE3078

> Object is of type 'unknown'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [unknown](../spec/02-types.md#unknown)

## What it means

A value of type `unknown` can be anything, so it has no properties,
methods or elements, and it cannot be called. It can only be compared with
`===` and `!==`, printed, passed on as an `unknown`, and narrowed.

## Example

```ts
function size(value: unknown): int {
    return value.length
}
```

## How to fix

Narrow the value first, with `typeof` or `instanceof`; after the check it
has the narrowed type:

```ts
function size(value: unknown): int {
    if (typeof value === "string") return value.length
    return -1
}
```
