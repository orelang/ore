# ORE5065

> Method '…' must have the signatures of the method it overrides in '…': ….

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A method that overrides a method with overload signatures must have the
same signatures, of the same types and in the same order: each is called
through the class table of the instance. A method without overload
signatures cannot be overridden by one with them either.

## Example

```ts
class Shape {
    scale(by: int): int
    scale(by: string): string
    scale(by: int | string): int | string {
        return by
    }
}
class Square extends Shape {
    scale(by: int): int {
        return by * 2
    }
}
```

## How to fix

Declare the same signatures:

```ts
class Shape {
    scale(by: int): int
    scale(by: string): string
    scale(by: int | string): int | string {
        return by
    }
}
class Square extends Shape {
    scale(by: int): int
    scale(by: string): string
    scale(by: int | string): int | string {
        if (typeof by === "string") return by + by
        return by * 2
    }
}
```
