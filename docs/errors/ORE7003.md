# ORE7003

> Cannot redeclare '…' in the same scope.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

A name is declared twice in the same block. Each `let`, `const`, function,
class or parameter name is declared once per scope; an inner block may
declare it again, hiding the outer one.

## Example

```ts
function f() {
    let total = 1
    let total = 2
}
```

## How to fix

Assign the existing variable instead of declaring it again:

```ts
function f() {
    let total = 1
    total = 2
}
```

Or choose another name.
