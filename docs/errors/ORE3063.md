# ORE3063

> Class '…' has no static member '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

`C.name` reads a static member of the class `C` (or of its base classes),
and `C` has no static member with this name. Instance members are reached
through an instance, not through the class.

## Example

```ts
class Counter {
    count = 0
}
console.log(Counter.count)
```

## How to fix

Read the member from an instance:

```ts
class Counter {
    count = 0
}
console.log(new Counter().count)
```

Or declare it `static`, if it belongs to the class:

```ts
class Counter {
    static count = 0
}
console.log(Counter.count)
```
