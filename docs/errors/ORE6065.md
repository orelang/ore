# ORE6065

> Cannot import …: it has no branch or tag '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules from GitHub](../spec/07-modules.md#modules-from-github)

## What it means

The ref after `/tree/` in a GitHub module URL is not a branch or a tag
of the repository. A commit is named by its full 40-digit hash.

## Example

<!-- no-check -->
```ts
import { x } from "https://github.com/acme/geo/tree/v9"
```

## How to fix

Use an existing branch or tag, or a full commit hash:

<!-- no-check -->
```ts
import { x } from "https://github.com/acme/geo/tree/v1.2.0"
```
