# ORE5066

> Overload signatures are not supported for optional methods.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

An optional method `m?(): T` is a read-only field holding a function or
null, and a function value has one type: it cannot have several
signatures. A required method of an interface can.

## Example

```ts
interface Formatter {
    format?(x: int): string
    format?(x: bool): string
}
```

## How to fix

Make the method required, or take a union:

```ts
interface Formatter {
    format?(x: int | bool): string
}
```
