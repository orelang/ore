# ORE5066

> Overload signatures are not supported in interfaces yet.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

An interface has one signature per method. Classes can have overload
signatures, and implement an interface's method with one of them.

## Example

```ts
interface Formatter {
    format(x: int): string
    format(x: bool): string
}
```

## How to fix

Give the methods different names, or take a union:

```ts
interface Formatter {
    format(x: int | bool): string
}
```
