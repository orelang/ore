# ORE6035

> Too many instances of generics; '…' may instantiate itself endlessly.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

Generics are compiled by creating an instance for each set of type
arguments. Here an instance creates another instance with larger type
arguments (`T`, then `T[]`, then `T[][]`, ...), which would never end; the
compiler stops after a limit.

## Example

```ts
function nest<T>(x: T, n: int): int {
    return n === 0 ? 0 : nest<T[]>([x], n - 1)
}
nest(1, 3)
```

## How to fix

Restructure the code so that recursion keeps the same type arguments, for
example with a non-generic data structure:

```ts
function nest(depth: int, n: int): int {
    return n === 0 ? depth : nest(depth + 1, n - 1)
}
nest(0, 3)
```
