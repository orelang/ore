# ORE5012

> Methods cannot be 'readonly'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

`readonly` applies to fields. Methods cannot be assigned anyway, so the
modifier has no meaning for them.

## Example

```ts
class Point {
    readonly show() {}
}
```

## How to fix

Remove `readonly`:

```ts
class Point {
    show() {}
}
```
