# ORE2036

> A floating-point constant is not assignable to integer type '…'. Use '…(...)' to truncate.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
let a: u8 = 256
let b: u8 = N
let c: i32 = 1.5
```

`tests/diag/basics/constants.ore:5`: A floating-point constant is not assignable to integer type 'i32'. Use 'i32(...)' to truncate.
