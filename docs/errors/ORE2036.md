# ORE2036

> A floating-point constant is not assignable to integer type '…'. Use '…(...)' to truncate.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Numeric literals](../spec/02-types.md#numeric-literals)

## What it means

A constant with a fraction or an exponent (`1.5`, `1e3`) is a floating-point
constant, and Ore does not drop its fraction implicitly where an integer is
expected.

## Example

```ts
const count: int = 1.5
```

## How to fix

Write an integer:

```ts
const count: int = 2
```

Or convert explicitly, which truncates toward zero at compile time:

```ts
const count: int = int(1.5)
```
