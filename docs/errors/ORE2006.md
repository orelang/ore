# ORE2006

> 'Map' expects exactly 2 type arguments.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

`Map<K, V>` takes two type arguments: the type of the keys and the type of
the values.

## Example

```ts
function oldest(ages: Map<string>) {}
```

## How to fix

Give both types:

```ts
const ages: Map<string, int> = new Map()
```
