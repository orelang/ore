# ORE2030

> Type 'null' is not assignable to type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

`null` is a value only of types that include it: `string | null`,
`Point | null`. A plain `string`, number, class or array type never holds
`null`, so code that uses a value of that type needs no check.

## Example

```ts
let name: string = null
```

## How to fix

Include `null` in the type, if the value can be missing:

```ts
let name: string | null = null
```

Or start with a value of the type:

```ts
let name: string = ""
```
