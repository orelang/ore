# ORE6060

> A '//ore:naked' function can branch only on conditions known at compile time, such as 'target.arch'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [The target](../spec/09-unsafe.md#the-target)

## What it means

A `//ore:naked` function has no stack frame and runs only inline assembly.
It may choose between assembly blocks with `if`, but only on conditions
known when the program is compiled, such as `target.arch` and `target.os`,
so that no code is generated to evaluate them.

## Example

```ts
//ore:naked
function entry(fast: bool) {
    if (fast) unsafe.asm("ret", "")
}
```

## How to fix

Branch on a compile-time constant, and test run-time conditions in the
assembly itself:

```ts
//ore:naked
function entry() {
    if (target.arch === "arm64") unsafe.asm("ret", "")
    else unsafe.asm("retq", "")
}
```
