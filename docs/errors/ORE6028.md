# ORE6028

> An external function needs a C name.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

The name of a `declare function` is the C symbol it calls, so it must be a
valid C identifier: letters, digits and `_`, not starting with a digit.

## Example

```ts
declare function my$puts(s: string): i32
```

## How to fix

Use the C name of the function:

```ts
declare function puts(s: string): i32
```
