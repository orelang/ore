# ORE3068

> The right side of 'instanceof' must be a class or an interface.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

The right side of `instanceof` must name a class or an interface. Object
types and type aliases describe records without a class at run time, so
there is nothing to check against; primitive types are tested with
`typeof`.

## Example

```ts
type Point = { x: int }
function isPoint(v: Point | string): bool {
    return v instanceof Point
}
```

## How to fix

Use `typeof` for primitive members of a union:

```ts
type Point = { x: int }
function isPoint(v: Point | string): bool {
    return typeof v !== "string"
}
```

For unions of object types, compare a discriminant field, or declare
classes and use `instanceof`.
