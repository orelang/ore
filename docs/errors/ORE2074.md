# ORE2074

> The other members of an object type with an index signature are properties, its named entries: '{ name: string; [key: string]: string }'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Named entries](../spec/03-objects.md#named-entries)

## What it means

An object type or an interface with an index signature is a dictionary: a
hash table of entries. Its properties are named entries of the table; a
method or an accessor has no place in it.

## Example

```ts
type Config = { [key: string]: string; describe(): string }
```

## How to fix

Keep the dictionary in a field of an object, beside the method:

```ts
type Config = { values: { [key: string]: string }; describe(): string }
```
