# ORE3029

> '…=' cannot assign to an accessor; write 'x = x … v'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

`x ??= v`, `x ||= v` and `x &&= v` assign only in some cases, and Ore does
not support them on a property defined by a getter and a setter yet.

## Example

```ts
class Settings {
    get theme(): string | null {
        return null
    }
    set theme(v: string | null) {}
}
const s = new Settings()
s.theme ??= "dark"
```

## How to fix

Write the assignment out, as the message suggests:

```ts
class Settings {
    get theme(): string | null {
        return null
    }
    set theme(v: string | null) {}
}
const s = new Settings()
s.theme = s.theme ?? "dark"
```
