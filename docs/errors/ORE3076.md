# ORE3076

> Accessors are not supported in an object literal with methods yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An object literal with methods is built field by field, with each method a
closure over the object. `get` and `set` accessors are not supported in such
a literal yet.

## Example

```ts
const o = {
    a: 1,
    get double(): int {
        return 2
    },
    twice(): int {
        return this.a * 2
    },
}
```

## How to fix

Write the accessor as a method:

```ts
const o = {
    a: 1,
    double(): int {
        return this.a * 2
    },
}
console.log(o.double())
```
