# ORE3076

> Accessors are not supported in an object literal with methods yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

This message is no longer produced: an object literal can have getters and
setters now, also with methods, as closures whose `this` is the object.
Earlier versions rejected accessors in an object literal with methods with
this message.
