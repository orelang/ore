# ORE3076

> Spreads and accessors are not supported in an object literal with methods yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An object literal with methods is built field by field, with each method a
closure over the object. `...spread` and `get`/`set` accessors are not
supported in such a literal yet.

## Example

```ts
const base = { a: 1 }
const o = { ...base, twice(): int { return this.a * 2 } }
```

## How to fix

Write the fields out, and the accessor as a method:

```ts
const base = { a: 1 }
const o = { a: base.a, twice(): int { return this.a * 2 } }
console.log(o.twice())
```
