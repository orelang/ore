# ORE2025

> Type '…' cannot be a Map key.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

The keys of a `Map` are hashed and compared: numbers and strings by value,
objects, arrays, maps, sets and interface values by identity. Functions,
channels and `ptr` values have no such equality, so they cannot be keys, nor
can a union that contains one of them.

## Example

```ts
function register(handlers: Map<() => void, string>) {}
```

## How to fix

Key the map by something that identifies the value, such as a name or an
id, and keep the function in the value:

```ts
function register(handlers: Map<string, () => void>) {}
```
