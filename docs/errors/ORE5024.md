# ORE5024

> This member cannot have an 'override' modifier because it is not declared in the base class '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`override` states that a method replaces a method of the base class. The
base class has no method with this name, so nothing is overridden; usually
the name is misspelled.

## Example

```ts
class Shape {
    draw() {}
}
class Square extends Shape {
    override drawn() {}
}
```

## How to fix

Correct the name, or remove `override` for a new method:

```ts
class Shape {
    draw() {}
}
class Square extends Shape {
    override draw() {}
}
```
