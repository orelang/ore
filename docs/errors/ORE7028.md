# ORE7028

> The loop variable cannot have a type annotation; its type comes from the iterable.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

TypeScript does not allow a type annotation on a `for...of` variable, and
neither does Ore: its type is the element type of what is iterated.

## Example

```ts
for (const x: int of [1, 2]) {}
```

## How to fix

Remove the annotation; to choose the element type, annotate the array:

```ts
const xs: i32[] = [1, 2]
for (const x of xs) {}
```
