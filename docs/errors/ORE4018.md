# ORE4018

> Expected a function of type '…', got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

The method expects a callback of the type shown, and was given another kind
of value. The callbacks of array methods receive `(element, index)`.

## Example

```ts
const xs = [1, 2]
xs.forEach(true)
```

## How to fix

Pass a function:

```ts
const xs = [1, 2]
xs.forEach((x) => console.log(x))
```
