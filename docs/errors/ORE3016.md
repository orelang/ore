# ORE3016

> '…' is not supported in Ore. Use '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

`==` and `!=` compare with JavaScript's type coercion (`"1" == 1`). Ore has
no implicit conversions, so they are rejected; `===` and `!==` compare
values of the same type.

## Example

```ts
let n = 1
const same = n == 1
```

## How to fix

Use `===` or `!==`:

```ts
let n = 1
const same = n === 1
```
