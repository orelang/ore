# ORE4072

> 'toFixed' expects 0 to 1 argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`toFixed(digits)` formats a number with a given number of decimals: one
argument, or none for no decimals, as in JavaScript.

## Example

```ts
const s = (1.5).toFixed(2, 10)
```

## How to fix

Pass at most the number of digits:

```ts
const s = (1.5).toFixed(2)
```
