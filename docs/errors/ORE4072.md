# ORE4072

> 'toFixed' expects 1 argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`toFixed(digits)` formats a number with a given number of decimals, and the
number of digits is required in Ore.

## Example

```ts
const s = (1.5).toFixed()
```

## How to fix

Pass the number of digits; for no decimals, use `Math.round` and
`toString()`:

```ts
const s = (1.5).toFixed(2)
```
