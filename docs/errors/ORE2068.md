# ORE2068

> A required element cannot follow an optional element.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

An optional element of a tuple type, `T?`, can be left out of a literal,
and only from the end: every element after an optional one must be
optional too, as in TypeScript. This holds for the elements a spread tuple
type `...T` brings in as well.

## Example

```ts
type Entry = [string?, int]
```

## How to fix

Put the required elements first:

```ts
type Entry = [int, string?]
```

Or make the later elements optional too:

```ts
type Entry = [string?, int?]
```
