# ORE2068

> The type '…' is 'readonly' and cannot be assigned to the mutable type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

A `readonly T[]` (or `ReadonlyArray<T>`) promises that the array is not changed through it.
A mutable `T[]` could change it, so a read-only array does not convert to one.

## Example

```ts
const ro: readonly int[] = [1, 2]
const a: int[] = ro
```

## How to fix

Keep the read-only type where the array is used:

```ts
const ro: readonly int[] = [1, 2]
const a: readonly int[] = ro
```

Or make a mutable copy:

```ts
const ro: readonly int[] = [1, 2]
const a: int[] = ro.slice()
```
