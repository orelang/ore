# ORE2068

> An index signature has one parameter and a type: '[key: string]: T'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

An index signature names one key and gives the type of the values.

## Example

```ts
type Scores = { [name: string] }
```

## How to fix

```ts
type Scores = { [name: string]: int }
```
