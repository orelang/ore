# ORE5006

> A class can only extend a class.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`extends` in a class names a class (or an instance of a generic class).
Interfaces and object types are implemented, not extended: they have no
fields or methods to inherit.

## Example

```ts
interface Shape {
    area(): f64
}
class Square extends Shape {
    area(): f64 {
        return 1.0
    }
}
```

## How to fix

Use `implements` for an interface:

```ts
interface Shape {
    area(): f64
}
class Square implements Shape {
    area(): f64 {
        return 1.0
    }
}
```
