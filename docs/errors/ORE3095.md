# ORE3095

> Property '…' is missing in this literal but required in type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Named entries](../spec/03-objects.md#named-entries)

## What it means

A literal of a dictionary with named entries gives each required one: by
name, or from the fields of a spread object or the required named entries
of a spread dictionary.

## Example

```ts
type Env = { home: string; [name: string]: string }
const env: Env = { shell: "sh" }
```

## How to fix

Give the entry, or make it optional:

```ts
type Env = { home: string; [name: string]: string }
const env: Env = { home: "/root", shell: "sh" }
```
