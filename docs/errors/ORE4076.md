# ORE4076

> 'internal' is only for the standard library. Add '//ore:internal' at the top of the file to use it here.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

The namespace `internal` holds the runtime's own functions, whose contracts
may change at any time. It is available to the standard library, and to
other modules only when they opt in with `//ore:internal`.

## Example

```ts
internal.netClose(3)
```

## How to fix

Use the public functions of the standard library. If the module really is
part of a runtime, put `//ore:internal` before its first statement:

```ts
//ore:internal
internal.netClose(3)
```
