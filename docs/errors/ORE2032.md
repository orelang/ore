# ORE2032

> Type '…' is not assignable to type '…': ….

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

A class or object converts to an interface when it has every member of the
interface with the same type; the message says which member is missing or
differs. Private members do not count, a `readonly` field does not satisfy
a writable one, and a getter without a setter implements only a `readonly`
field. Classes and object types are checked
structurally here, as in TypeScript, although classes are otherwise nominal.

## Example

```ts
interface Named {
    name: string
}
class User {
    constructor(readonly id: int) {}
}
const n: Named = new User(1)
```

## How to fix

Add the missing member, with the type the interface asks for:

```ts
interface Named {
    name: string
}
class User {
    constructor(
        readonly id: int,
        public name: string,
    ) {}
}
const n: Named = new User(1, "ada")
```

If the interface only reads the member, mark it `readonly` there, so that a
`readonly` field fits:

```ts
interface Named {
    readonly name: string
}
class User {
    constructor(readonly name: string) {}
}
const n: Named = new User("ada")
```
