# ORE2032

> Type '…' is not assignable to type '…': ….

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
interface Loop extends Loop {}

const p: Point = { x: 1 }
```

`tests/diag/types/interfaces.ore:38`: Type '{ x: f64 }' is not assignable to type 'Point': property 'y' is missing.
