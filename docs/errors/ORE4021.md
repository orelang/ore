# ORE4021

> An array of '…' cannot be spread into '…' of '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`Math.min` and `Math.max` take values of one numeric type, which the result
keeps. An array spread into them must hold elements of that type; numeric
types never convert implicitly.

## Example

```ts
const xs = [1, 2]
let limit: i32 = 3
const m = Math.max(limit, ...xs)
```

## How to fix

Use one numeric type for all the values, converting where needed:

```ts
const xs = [1, 2]
let limit: i32 = 3
const m = Math.max(i64(limit), ...xs)
```
