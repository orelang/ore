# ORE3013

> External function '…' cannot be used as a value.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

A `declare function` is a C function, called with the C calling convention
and with conversions of its arguments (a `string` becomes a NUL-terminated
copy). It is not an Ore function value, and cannot be stored or passed.

## Example

```ts
declare function puts(s: string): i32
const print = puts
```

## How to fix

Wrap the call in an Ore function:

```ts
declare function puts(s: string): i32
const print = (s: string) => puts(s)
```
