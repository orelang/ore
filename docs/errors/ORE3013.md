# ORE3013

> External function '…' cannot be used as a value.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
declare function body(): void {}

const f = bad
```

`tests/diag/modules/ffi.ore:5`: External function 'bad' cannot be used as a value.
