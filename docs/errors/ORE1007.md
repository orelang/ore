# ORE1007

> Unterminated regular expression literal.

Group: [Syntax](README.md#ore1xxx-syntax) · specification: [Regular expressions](../spec/02-types.md#regular-expressions)

## What it means

A `/` where an expression starts begins a regular expression literal, which
must end with another `/` on the same line. Here none was found. After an
operand (a name, a literal, `)`, `]`) a `/` is a division instead.

## Example

```ts
const re = /abc
```

## How to fix

Close the literal with `/`, and escape a `/` that belongs to the pattern as
`\/`:

```ts
const re = /abc/
const path = /usr\/bin/
```
