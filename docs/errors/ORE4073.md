# ORE4073

> Only an array can be spread into an array.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`a.push(...xs)` appends the elements of the array `xs`. Strings, maps, sets
and other values cannot be spread there.

## Example

```ts
const letters: string[] = []
letters.push(..."abc")
```

## How to fix

Convert the value to an array first:

```ts
const letters: string[] = []
letters.push(..."abc".split(""))
```
