# ORE3080

> An expression of type 'void' cannot be awaited.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Concurrency](../spec/06-concurrency.md#async-functions-and-promises)

## What it means

`await` takes a promise, or a value it treats as a fulfilled promise. A call
of a function that returns nothing has no value to wait for.

## Example

```ts
function log(text: string) {
    console.log(text)
}
await log("hello")
```

## How to fix

Call the function without `await`; to wait for work it starts, have it
return a promise:

```ts
async function log(text: string): Promise<void> {
    console.log(text)
}
await log("hello")
```
