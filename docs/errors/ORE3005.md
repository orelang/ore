# ORE3005

> Type assertions are not supported in Ore. Use a conversion such as 'i32(x)'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Conversions](../spec/02-types.md#conversions)

## What it means

`x as T` changes only the static type in TypeScript and checks nothing. Ore
does not allow it: a value's representation follows its type, so treating a
value as another type would be unsound. Numbers convert by calling the type,
unions are narrowed with checks, and `satisfies` checks that a value fits a
type.

## Example

```ts
const n = 300
const b = n as u8
```

## How to fix

Convert numbers explicitly:

```ts
let n = 300
const b = u8(n)
```

Narrow a union with a check instead of asserting its member:

```ts
function size(v: string | int): int {
    if (typeof v === "string") return v.length
    return v
}
```
