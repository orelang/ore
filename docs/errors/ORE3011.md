# ORE3011

> '…' is a namespace; call its functions, e.g. '….…(...)'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

A built-in namespace such as `console`, `process`, `fs`, `Math` or `task`
groups functions; it is not an object and has no value of its own.

## Example

```ts
const out = console
```

## How to fix

Call its functions, or take one of them in a function value:

```ts
const log = (s: string) => console.log(s)
log("hello")
```
