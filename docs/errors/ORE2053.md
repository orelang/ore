# ORE2053

> 'keyof' needs an object type, a class or an interface with members, not '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

`keyof T` is the union of the names of T's members, as string literal types: the public fields and methods of a class or an object type, or the members of an interface. A type without members, such as a number or a string, has no keys.

## Example

```ts
type K = keyof int
```

## How to fix

Use `keyof` on an object type:

```ts
type Point = { x: int; y: int }
type K = keyof Point
const k: K = "x"
```
