# ORE4006

> Spread arguments are not supported yet.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Conversions](../spec/02-types.md#conversions)

## What it means

`new Array<T>(...)` with several arguments makes an array of them, and
does not take an array spread among them yet
(`new Array<int>(0, ...xs)`). Spreads into the arguments of other calls are
described in [functions and closures](../spec/04-functions.md#functions-and-closures).

## Example

```ts
const xs = [1, 2]
const all = new Array<int>(0, ...xs)
```

## How to fix

Write an array literal, which takes spreads:

```ts
const xs = [1, 2]
const all: int[] = [0, ...xs]
```
