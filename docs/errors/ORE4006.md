# ORE4006

> Spread arguments are not supported yet.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Conversions](../spec/02-types.md#conversions)

## What it means

A numeric conversion such as `i32(x)` takes exactly one value, and cannot
take its argument from a spread (`i32(...xs)`).

## Example

```ts
const xs = [1]
const n = i32(...xs)
```

## How to fix

Pass the value itself:

```ts
const xs = [1]
const n = i32(xs[0])
```
