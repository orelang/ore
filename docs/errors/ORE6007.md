# ORE6007

> '…' is already exported.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

Two variables are exported to C under the same name; a C symbol names one
variable.

## Example

```ts
//ore:export counter
let requests = 0
//ore:export counter
let errors = 0
```

## How to fix

Give each one its own C name:

```ts
//ore:export requests
let requests = 0
//ore:export errors
let errors = 0
```
