# ORE4001

> Type arguments are only allowed for generic functions.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

Type arguments (`f<int>(...)`) choose the instance of a generic function.
The function called here has no type parameters, so there is nothing to
choose.

## Example

```ts
function double(x: int): int {
    return x * 2
}
const y = double<int>(2)
```

## How to fix

Remove the type arguments:

```ts
function double(x: int): int {
    return x * 2
}
const y = double(2)
```
