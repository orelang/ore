# ORE3020

> Operator '…' is not supported.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

The operator is TypeScript syntax that Ore does not support, such as
`>>>=`, the compound form of `>>>`: on unsigned types `>>` is already a
logical shift.

## Example

```ts
let n: u32 = 8
n >>>= 1
```

## How to fix

Use `>>=` on an unsigned type:

```ts
let n: u32 = 8
n >>= 1
```
