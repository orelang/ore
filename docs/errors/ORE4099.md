# ORE4099

> The second argument of 'JSON.parse' is a reviver function '(key: string, value: unknown, context: { source: string } | null) => unknown'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

The second argument of `JSON.parse<T>` is a reviver, as in JavaScript: a
function that is given each key and value, untyped as an `unknown`, the
parts of an array or an object first, and returns the value to keep
instead (`JSON.omit` to delete it). What it returns for the whole is then
read as a `T`. Anything else there is not a reviver.

## Example

```ts
const n = JSON.parse<int>("1", 10)
```

## How to fix

Pass a function, or nothing:

```ts
const n = JSON.parse<int>("1")
const doubled = JSON.parse<int[]>("[1, 2]", (key, value) => (typeof value === "number" ? value * 2 : value))
```
