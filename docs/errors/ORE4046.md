# ORE4046

> 'new Map' takes at most one argument: an array of [key, value] pairs.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

`new Map(entries)` takes at most one argument: an array of `[key, value]`
pairs, or another map to copy.

## Example

```ts
const m = new Map([["a", 1]], [["b", 2]])
```

## How to fix

Put all the pairs in one array:

```ts
const m = new Map([["a", 1], ["b", 2]])
```
