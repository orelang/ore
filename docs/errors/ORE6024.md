# ORE6024

> A generic function cannot have overload signatures yet.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A generic function cannot have overload signatures yet.

## Example

```ts
function wrap(x: int): int[]
function wrap<T>(x: T): T[] {
    return [x]
}
```

## How to fix

Remove the signatures; the generic function already takes every type:

```ts
function wrap<T>(x: T): T[] {
    return [x]
}
```
