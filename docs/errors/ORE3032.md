# ORE3032

> Operator '…=' needs a boolean, got '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

`x ||= v` and `x &&= v` work on `bool` only. Ore has no truthiness: a number
or a string is not true or false, so "assign if falsy" has no meaning for
them.

## Example

```ts
let retries = 0
retries ||= 3
```

## How to fix

Write the condition you mean:

```ts
let retries = 0
if (retries === 0) retries = 3
```

For a value that may be missing, use `T | null` and `??=`:

```ts
let retries: int | null = null
retries ??= 3
```
