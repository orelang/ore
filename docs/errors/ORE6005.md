# ORE6005

> '…' is already exported by '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

Two functions are exported to C under the same name; a C symbol names one
function.

## Example

```ts
//ore:export handler
function onOpen() {}
//ore:export handler
function onClose() {}
```

## How to fix

Give each one its own C name:

```ts
//ore:export on_open
function onOpen() {}
//ore:export on_close
function onClose() {}
```
