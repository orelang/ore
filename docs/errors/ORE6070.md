# ORE6070

> Unknown import attribute '…'. Only 'type' is supported.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [JSON files](../spec/07-modules.md#json-files)

## What it means

Import attributes (`with { ... }`) take only `type` in Ore.

## Example

```ts
import data from "./data.json" with { type: "json", mode: "strict" }
```

## How to fix

Remove the other attributes:

```ts
import data from "./data.json" with { type: "json" }
// file: data.json
[1, 2, 3]
```
