# ORE7048

> Type '…' is not async iterable: it needs a '[Symbol.asyncIterator]()' method whose iterator's 'next()' returns a promise of an 'IteratorResult', or a '[Symbol.iterator]()' method.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

`for await`, `yield*` in an async generator and `Array.fromAsync` take an
async iterable: an async generator, or an object whose
`[Symbol.asyncIterator]()` returns an iterator whose `next()` returns a
`Promise<IteratorResult<T>>`. They also take what `for...of` takes (an
array, a map, a set, a generator, an object with `[Symbol.iterator]()`),
and await each of its values.

## Example

```ts
class Feed {
    items: string[] = []
}
async function main() {
    for await (const item of new Feed()) console.log(item)
}
```

## How to fix

Give the class a `[Symbol.asyncIterator]()` method, such as an async
generator:

```ts
class Feed {
    items: string[] = [];
    async *[Symbol.asyncIterator](): AsyncGenerator<string> {
        yield* this.items
    }
}
async function main() {
    for await (const item of new Feed()) console.log(item)
}
```
