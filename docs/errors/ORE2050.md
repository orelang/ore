# ORE2050

> A class or a tuple cannot be part of an intersection; use an interface, or extend the class.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

A class is a nominal type: its instances are made by its constructor, and an
intersection cannot add members to it. A tuple is a fixed list, not an object
with named members. Only object types and interfaces combine with `&`.

## Example

```ts
class Point {
    x = 0
}
type Labeled = Point & { label: string }
```

## How to fix

Describe the shape with an interface, which the class fits:

```ts
interface HasX {
    x: int
}
type Labeled = HasX & { label: string }
```

Or extend the class:

```ts
class Point {
    x = 0
}
class LabeledPoint extends Point {
    label = ""
}
```
