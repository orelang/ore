# ORE3071

> Type '…' cannot be null; '??' is not needed.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

`x ?? y` gives `y` when `x` is `null`. The type of `x` does not include
`null`, so `y` would never be used.

## Example

```ts
function label(name: string): string {
    return name ?? "anonymous"
}
```

## How to fix

Remove the `??` part, or include `null` in the type if the value can be
missing:

```ts
function label(name: string | null): string {
    return name ?? "anonymous"
}
```
