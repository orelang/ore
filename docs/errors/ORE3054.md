# ORE3054

> Cannot tell which member of '…' this object literal is. Give its discriminant field a literal value.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

An object literal for a union of object types must be built as one of the
members. The compiler picks the member by the literal's property names and
the literal values of its discriminant field. Here several members fit,
because the discriminant is not a literal.

## Example

```ts
type Circle = { kind: "circle"; size: f64 }
type Square = { kind: "square"; size: f64 }
function make(kind: "circle" | "square"): Circle | Square {
    return { kind: kind, size: 1.0 }
}
```

## How to fix

Give the discriminant a literal value in each case:

```ts
type Circle = { kind: "circle"; size: f64 }
type Square = { kind: "square"; size: f64 }
function make(kind: "circle" | "square"): Circle | Square {
    if (kind === "circle") return { kind: "circle", size: 1.0 }
    return { kind: "square", size: 1.0 }
}
```
