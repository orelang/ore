# ORE7047

> 'for await' is only allowed in async functions and in the top-level code of a module.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

`for await` awaits each step of the loop, as `await` does, so it can only
be used where `await` can: in an async function, method or arrow function
(an async generator too), or in the top-level code of a module.

## Example

```ts
async function* numbers(): AsyncGenerator<int> {
    yield 1
}
function printAll() {
    for await (const n of numbers()) console.log(n)
}
```

## How to fix

```ts
async function* numbers(): AsyncGenerator<int> {
    yield 1
}
async function printAll() {
    for await (const n of numbers()) console.log(n)
}
```
