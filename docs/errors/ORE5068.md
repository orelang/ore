# ORE5068

> Member '…' is a different generic method in each part of the intersection.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

A generic method of an interface keeps the instances called through it.
An intersection takes a generic method from one of its parts, so two
parts can have one of the same name only when it is the same method, as
when both extend the interface that declares it.

## Example

```ts
interface A {
    get<T>(key: string): T[]
}
interface B {
    get<T>(key: string): T[]
}
type Both = A & B
```

## How to fix

Declare the method once, in an interface that both parts extend:

```ts
interface Getter {
    get<T>(key: string): T[]
}
interface A extends Getter {
    a: int
}
interface B extends Getter {
    b: int
}
type Both = A & B
```
