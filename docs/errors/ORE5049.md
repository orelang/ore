# ORE5049

> Class '…' does not implement '…': ….

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

`class C implements I` checks that `C` has every member of `I`, with the
same types; the message says which one is missing or differs. Private
members and accessors do not count, and a `readonly` field does not satisfy
a writable one.

## Example

```ts
interface Shape {
    area(): f64
}
class Square implements Shape {}
```

## How to fix

Add the member:

```ts
interface Shape {
    area(): f64
}
class Square implements Shape {
    area(): f64 {
        return 1.0
    }
}
```
