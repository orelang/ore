# ORE6058

> A function cannot be both '//ore:noinline' and '//ore:inline'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

`//ore:noinline` and `//ore:inline` contradict each other.

## Example

```ts
//ore:noinline
//ore:inline
function add(a: int, b: int): int {
    return a + b
}
```

## How to fix

Keep one of them:

```ts
//ore:noinline
function add(a: int, b: int): int {
    return a + b
}
```
