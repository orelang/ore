# ORE4064

> Method '…' does not exist on base class '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`super.m(...)` calls a method of the base class (declared there or
inherited by it), and the base class has no method with this name.

## Example

```ts
class Shape {}
class Square extends Shape {
    draw() {
        super.draw()
    }
}
```

## How to fix

Correct the name, or declare the method in the base class:

```ts
class Shape {
    draw() {}
}
class Square extends Shape {
    draw() {
        super.draw()
    }
}
```
