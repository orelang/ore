# ORE2052

> Member '…' has the type '…' in one part of the intersection and '…' in another.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

Each member of an intersection has the members of every part; a member that
two parts declare must have the same type in both, or no value could be both.

## Example

```ts
type A = { id: int }
type B = { id: string }
type C = A & B
```

## How to fix

Give the member one type, or rename one of them:

```ts
type A = { id: int }
type B = { key: string }
type C = A & B
```
