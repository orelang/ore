# ORE4030

> '…' needs an object, array or map type, got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

`unsafe.fromAddress<T>(p)` turns an address back into a reference. `T` must
be a type that is a reference: an object, a class, an array or a map.
Numbers are values, not references, and are read with `unsafe.load<T>(p)`.

## Example

```ts
let p = unsafe.alloc(8)
const n = unsafe.fromAddress<int>(p)
```

## How to fix

Read a number at an address with `load`:

```ts
let p = unsafe.alloc(8)
const n = unsafe.load<int>(p)
```
