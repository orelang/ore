# ORE3010

> '…' is a generic function and cannot be used as a value.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

A generic function is compiled once for each set of type arguments it is
called with. Without a call, there is no instance to take as a value.

## Example

```ts
function identity<T>(x: T): T {
    return x
}
const f = identity
```

## How to fix

Wrap a call in a function of the concrete type you need:

```ts
function identity<T>(x: T): T {
    return x
}
const f = (x: int) => identity(x)
```
