# ORE6003

> An exported function takes and returns numbers, 'bool' and 'ptr' only, not '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

A function exported to C with `//ore:export` is called with the C calling
convention, which passes numbers, booleans and pointers. Strings, arrays,
objects and other Ore values have no C form.

## Example

```ts
//ore:export greet
function greet(name: string) {}
```

## How to fix

Take and return numbers, `bool` or `ptr`; pass text as a pointer and a
length, and build the string with `unsafe.makeString`:

```ts
//ore:export greet
function greet(name: ptr, length: int) {
    console.log(unsafe.makeString(name, length))
}
```
