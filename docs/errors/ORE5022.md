# ORE5022

> This class member is not supported.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The class member is TypeScript syntax that Ore does not support. A class
has fields, one constructor, methods, getters and setters, and static
fields and methods. Index signatures have their own error,
[ORE2046](ORE2046.md), and the parser of Ore rejects other members, such as
static blocks, as syntax errors, so this message is not produced at
present.

## Example

<!-- no-check -->
```ts
class Config {
    static {
        console.log("loaded")
    }
}
```

## How to fix

Move the code to the top level of the module, or to a static method:

```ts
class Config {
    static load() {
        console.log("loaded")
    }
}
Config.load()
```
