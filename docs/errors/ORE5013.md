# ORE5013

> Generators are not supported in Ore.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

Generator functions (`function*`, `*method()`, `yield`) are not supported.
A sequence of values is returned as an array, or produced by a task over a
channel, which `for...of` can iterate.

## Example

```ts
class Range {
    *values() {}
}
```

## How to fix

Return an array:

```ts
class Range {
    values(): int[] {
        return [1, 2, 3]
    }
}
```

Or send the values over a channel from a task:

```ts
function count(n: int): Chan<int> {
    const ch = new Chan<int>()
    task.spawn(() => {
        for (let i = 0; i < n; i++) ch.send(i)
        ch.close()
    })
    return ch
}
for (const i of count(3)) console.log(i)
```
