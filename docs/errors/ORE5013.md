# ORE5013

> Async generators are not supported in Ore.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

This message is no longer produced: async generator functions and methods
(`async function*`, `async *method()`, `async *[Symbol.asyncIterator]()`)
and `for await` are supported now, as in JavaScript. Earlier versions
rejected them with this message.
