# ORE5013

> Async generators are not supported in Ore.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

Generator functions (`function*`, `*method()`, `yield`) are supported, and
so are async functions, but not both at once: `async function*`, `async
*method()` and `for await` have no meaning in Ore yet.

## Example

```ts
class Feed {
    async *items(): AsyncGenerator<string> {}
}
```

## How to fix

Yield promises from a plain generator and await each one:

```ts
async function fetchItem(n: int): Promise<string> {
    return `item ${n}`
}
class Feed {
    *items(): Generator<Promise<string>> {
        yield fetchItem(1)
        yield fetchItem(2)
    }
}
for (const p of new Feed().items()) console.log(await p)
```

Or send the values over a channel from a task:

```ts
function items(): Chan<string> {
    const ch = new Chan<string>()
    task.spawn(() => {
        ch.send("a")
        ch.close()
    })
    return ch
}
for (const item of items()) console.log(item)
```
