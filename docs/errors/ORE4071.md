# ORE4071

> Method '…' does not exist on type '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
n.set("a", "b")
const v: int = n.get("a")
n.put("a", 1)
```

`tests/diag/collections/maps.ore:6`: Method 'put' does not exist on type 'Map<string, i64>'.
