# ORE4071

> Method '…' does not exist on type '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The type has no method with this name. Methods are known from the static
type, as in TypeScript; there is no lookup at run time. Some JavaScript
methods of strings, arrays and maps are missing or differ in Ore; the
specification lists them.

## Example

```ts
class Counter {}
new Counter().reset()
```

## How to fix

Correct the name, or declare the method:

```ts
class Counter {
    reset() {}
}
new Counter().reset()
```
