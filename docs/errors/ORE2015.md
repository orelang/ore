# ORE2015

> A required parameter cannot follow an optional parameter.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

In a function type, the arguments are matched by position, so the optional
parameters (`b?: T`) must come after the required ones.

## Example

```ts
function format(pad: (width?: int, text: string) => string) {}
```

## How to fix

Put the required parameters first:

```ts
let pad: (text: string, width?: int) => string = (text, width) => text
```
