# ORE2015

> A required parameter cannot follow an optional parameter.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const g = (...xs: int) => 0
let h: (a: int, b?: int) => int = (a: int, b: int) => a
type Bad = (a?: int, b: int) => void
```
