# ORE4078

> The depth of 'flat' must be an integer constant or 'Infinity'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

`a.flat(depth)` removes `depth` levels of nesting, and the type of the
result depends on it: `int[][][]` flattened once is `int[][]`, twice
`int[]`. So the depth must be known when the program is checked: an integer
constant, or `Infinity` for every level.

## Example

```ts
const nested = [[[1]], [[2]]]
let depth = 2
nested.flat(depth)
```

## How to fix

Write the depth as a constant:

```ts
const nested = [[[1]], [[2]]]
nested.flat(2)
```
