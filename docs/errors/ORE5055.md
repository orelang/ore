# ORE5055

> Generic methods are not supported in interfaces: calls through an interface cannot pick an instance.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [03-objects.md](../spec/03-objects.md)

## Example

```ts
interface Mapper {
    map<U>(x: int): int
```
