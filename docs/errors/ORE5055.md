# ORE5055

> Generic method '…' of '…' is called through the interface with type arguments that grow without end: '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

A generic method is compiled once per set of type arguments. For a generic
method of an interface, Ore collects the type arguments of every call
through the interface in the whole program, and compiles the method of
each class converted to the interface for each of them. When an instance
calls the method through the interface again with larger type arguments
(`T[]` inside the instance for `T`), each instance needs another, without
end, so the program cannot be compiled. The calls are followed until the
type arguments nest more than 12 levels deep.

## Example

```ts
interface Nest {
    wrap<T>(x: T): int
}

class Deeper implements Nest {
    wrap<T>(x: T): int {
        const next: Nest = this
        return next.wrap([x])
    }
}

const n: Nest = new Deeper()
console.log(n.wrap(1))
```

## How to fix

Make the calls through the interface with type arguments that do not
nest the caller's, so that the instances end:

```ts
interface Nest {
    wrap<T>(xs: T[]): int
}

class Count implements Nest {
    wrap<T>(xs: T[]): int {
        return xs.length
    }
}

const n: Nest = new Count()
console.log(n.wrap([1, 2]))
```
