# ORE5055

> Generic methods are not supported in interfaces: calls through an interface cannot pick an instance.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

A generic method is compiled once per set of type arguments. A call through
an interface reaches the method through a table built when the object was
converted to the interface, which cannot contain an instance for every
possible type, so interface methods cannot be generic.

## Example

```ts
interface Store {
    get<T>(key: string): T | null
}
```

## How to fix

Make the interface generic instead:

```ts
interface Store<T> {
    get(key: string): T | null
}
```
