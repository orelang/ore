# ORE3077

> A method of an object literal needs a return type annotation, or a type to fit.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

The type of an object with methods is known before the methods' bodies are
checked, since `this` in them is that object. A method that returns a value
needs its result type from an annotation, or from the type the literal is
written for.

## Example

```ts
const counter = { count: 0, next() { return this.count + 1 } }
```

## How to fix

Annotate the result:

```ts
const counter = { count: 0, next(): int { return this.count + 1 } }
console.log(counter.next())
```

Or give the literal a type to fit:

```ts
type Counter = { count: int; next(): int }
const counter: Counter = { count: 0, next() { return this.count + 1 } }
console.log(counter.next())
```
