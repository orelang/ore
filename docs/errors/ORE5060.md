# ORE5060

> A 'this' type in an interface is not supported yet.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

In an interface, the type `this` stands for each class that implements it,
so a class's method `self(): this` would return the class while the
interface's returns the interface. Ore calls a class's methods through an
interface directly, which needs the same types, so the type `this` is not
supported in interfaces yet.

## Example

```ts
interface Chain {
    self(): this
}
```

## How to fix

Name the interface:

```ts
interface Chain {
    self(): Chain
}
```
