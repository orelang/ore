# ORE4066

> … expects at least … argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

A variadic C function, declared with a rest parameter, needs at least its
fixed arguments; any number of others may follow.

## Example

```ts
declare function printf(format: string, ...args: i64[]): i32
printf()
```

## How to fix

Pass the fixed arguments:

```ts
declare function printf(format: string, ...args: i64[]): i32
printf("%d\n", 42)
```
