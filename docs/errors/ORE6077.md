# ORE6077

> This result does not show that '…' is '…': return a check of '…' that narrows it, such as 'typeof x === "string"' or 'x instanceof C', or false.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

A function with a type predicate `x is T` must return a check that narrows
`x` to `T` when it is true: `typeof x === "string"`, `x instanceof C`,
`x.kind === "circle"`, `x !== null`, a call of another such function, or
`true` where earlier checks have narrowed `x` already. `false` is always
allowed. The compiler checks this because a narrowed value is checked at
run time: a predicate that is wrong would make the program panic where
the caller reads the value, far from the mistake.

## Example

```ts
function isText(value: unknown): value is string {
    return true
}
```

## How to fix

Return the check itself:

```ts
function isText(value: unknown): value is string {
    return typeof value === "string"
}
```
