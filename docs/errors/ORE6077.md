# ORE6077

> 'yield' without a value yields null, which type '…' does not include.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

`yield` alone yields `null` (JavaScript yields `undefined`), so the value
type of the generator must include `null`.

## Example

```ts
function* ticks(): Generator<int> {
    yield
}
```

## How to fix

```ts
function* ticks(): Generator<int | null> {
    yield
}
```
