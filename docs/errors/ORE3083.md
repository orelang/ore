# ORE3083

> Index signature in type '*' only permits reading.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Regular expressions](../spec/02-types.md#regular-expressions)

## What it means

A `RegExpMatch` is indexed like JavaScript's match arrays, `m[1]`, but its
captures are what the expression matched: they cannot be replaced.

## Example

```ts
const m = /(\d+)/.exec("a 12")!
m[1] = "13"
```

## How to fix

Copy the captures into an array of your own, which can be changed:

```ts
const m = /(\d+)/.exec("a 12")!
const parts = [...m.captures]
parts[1] = "13"
```
