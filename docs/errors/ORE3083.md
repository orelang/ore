# ORE3083

> The key of a dictionary is a string, not '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

A dictionary is indexed by strings. Ore does not convert other values to
strings implicitly.

## Example

```ts
const d: Record<string, int> = {}
d[1] = 2
```

## How to fix

Use a string as the key:

```ts
const d: Record<string, int> = {}
d[`${1}`] = 2
```

For number keys, use a `Map`:

```ts
const m = new Map<int, int>()
m.set(1, 2)
```
