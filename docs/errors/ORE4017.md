# ORE4017

> The comparator of 'sort' must return a number.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

The comparator of `sort(compare)` returns a number: negative when `a` comes
first, positive when `b` does, zero when they are equal. A `bool` is not
converted to a number as in JavaScript (where such a comparator does not
sort correctly anyway).

## Example

```ts
const xs = [3, 1, 2]
xs.sort((a, b) => a > b)
```

## How to fix

Return the difference, or -1, 0 and 1:

```ts
const xs = [3, 1, 2]
xs.sort((a, b) => a - b)
```
