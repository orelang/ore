# ORE6001

> This overload signature has no implementation after it.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function declaration without a body is an overload signature, and must be
followed by the function's implementation, with the same name and a body.
(A C function is declared with `declare function`.)

## Example

```ts
function parse(s: string): int
```

## How to fix

Add the implementation after the signatures:

```ts
function parse(s: string): int
function parse(s: string | int): int {
    return 0
}
```

Or write the function with its body directly, without a signature:

```ts
function parse(s: string): int {
    return 0
}
```

To declare a C function, use `declare`:

```ts
declare function abs(n: i32): i32
```
