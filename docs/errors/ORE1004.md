# ORE1004

> Module specifier expected.

Group: [Syntax](README.md#ore1xxx-syntax) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

An `import` or `export ... from` needs the module to read from as a string
literal: a relative path such as `"./util"`, a package name, or a standard
module such as `"ore:sync"`. A name or an expression cannot be a module
specifier, since modules are resolved when the program is compiled.

## Example

```ts
import { Mutex } from ore:sync
```

## How to fix

Write the specifier as a string:

```ts
import { Mutex } from "ore:sync"
```
