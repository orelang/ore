# ORE3094

> The operand of a 'delete' operator must be optional: '…' is a required entry of '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Named entries](../spec/03-objects.md#named-entries)

## What it means

A required named entry of a dictionary is always there: its type says so,
and reading it by its name gives its type, not null. `delete` would remove
it.

## Example

```ts
type Env = { home: string; [name: string]: string }
const env: Env = { home: "/root" }
delete env.home
```

## How to fix

Make the entry optional, or give it another value:

```ts
type Env = { home?: string; [name: string]: string }
const env: Env = { home: "/root" }
delete env.home
```
