# ORE6044

> Enums are not supported in Ore. Use a union of literal types.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

Ore has no `enum` or `const enum`. A union of string literal types does the
same job: it is a string at run time, prints and converts to JSON as
itself, and a `switch` over it is checked for exhaustiveness.

## Example

```ts
enum Color {
    Red,
    Green,
}
```

## How to fix

Use a union of string literals:

```ts
type Color = "red" | "green"
const c: Color = "red"
```

For numeric values, declare constants:

```ts
const red = 0
const green = 1
```
