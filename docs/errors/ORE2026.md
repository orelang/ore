# ORE2026

> Type '…' cannot be an element of a Set.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Sets](../spec/03-objects.md#sets)

## What it means

The elements of a `Set` are hashed and compared like the keys of a `Map`.
Functions, channels and `ptr` values have no such equality, so they cannot
be elements of a set.

## Example

```ts
function run(tasks: Set<() => void>) {}
```

## How to fix

Store the functions in an array, or in a `Map` keyed by a name:

```ts
function run(tasks: Map<string, () => void>) {}
```
