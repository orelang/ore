# ORE2026

> Type '…' cannot be an element of a Set.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
n.put("a")
n.add()
const bad = new Set<f64[] | (() => void)>()
```

`tests/diag/collections/sets.ore:6`: Type '(() => void) | f64[]' cannot be an element of a Set.
