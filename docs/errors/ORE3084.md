# ORE3084

> Index signature in type '…' only permits reading.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

A readonly dictionary, `{ readonly [key: string]: T }`, as
`Readonly<Record<string, T>>` and `Object.freeze` give, cannot be written.

## Example

```ts
const d: Readonly<Record<string, int>> = { a: 1 }
d.a = 2
```

## How to fix

Write through a dictionary that is not readonly.
