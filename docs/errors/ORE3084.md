# ORE3084

> Index signature in type '…' only permits reading.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries), [Regular expressions](../spec/02-types.md#regular-expressions), [Arrays](../spec/02-types.md#arrays)

## What it means

A readonly dictionary, `{ readonly [key: string]: T }`, as
`Readonly<Record<string, T>>` and `Object.freeze` give, cannot be written.

The elements of a `readonly T[]` (or `ReadonlyArray<T>`) can be read, not
assigned.

Nor can a `RegExpMatch`: it is indexed like JavaScript's match arrays,
`m[1]`, but its captures are what the expression matched, so they cannot
be replaced.

## Example

```ts
const d: Readonly<Record<string, int>> = { a: 1 }
d.a = 2

const m = /(\d+)/.exec("a 12")!
m[1] = "13"

const ro: readonly int[] = [1, 2]
ro[0] = 3
```

## How to fix

Write through a dictionary or an array that is not readonly. Copy the captures of a
match into an array of your own, which can be changed:

```ts
const m = /(\d+)/.exec("a 12")!
const parts = [...m.captures]
parts[1] = "13"
```
