# ORE3084

> 'as const' takes array literals without spread elements.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

`[...] as const` is a read-only tuple of the elements' literal types, so each element is written out.

## Example

```ts
const a = ["x"] as const
const b = [...a, "y"] as const
```

## How to fix

Write the elements:

```ts
const b = ["x", "y"] as const
```
