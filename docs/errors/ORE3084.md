# ORE3084

> Index signature in type '…' only permits reading.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

The elements of a `readonly T[]` (or `ReadonlyArray<T>`) can be read, not assigned.

## Example

```ts
const ro: readonly int[] = [1, 2]
ro[0] = 3
```

## How to fix

Use a mutable array where the elements change:

```ts
const a: int[] = [1, 2]
a[0] = 3
```
