# ORE7038

> Generic closures are not supported.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

Function literals (arrow functions and function expressions) cannot be
generic: a function value has one function type, and generics are compiled
per set of type arguments.

## Example

```ts
const identity = <T>(x: T) => x
```

## How to fix

Declare a generic function:

```ts
function identity<T>(x: T): T {
    return x
}
```

Or give the literal concrete types:

```ts
const identity = (x: int) => x
```
