# ORE7038

> Generic closures are not supported.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function literal (an arrow function or a function expression) can be
generic only when it is assigned to a `const`, which is then called. Anywhere
else, such as an argument, it would be a generic function value, which has
no single function type: generics are compiled per list of type arguments.

## Example

```ts
const firsts = lists.map(<T>(xs: T[]) => xs[0])
```

## How to fix

Give the literal concrete types:

```ts
const firsts = lists.map((xs: int[]) => xs[0])
```

Or name it with a `const` (or a function declaration) and call it:

```ts
const first = <T>(xs: T[]): T => xs[0]
const firsts = lists.map((xs) => first(xs))
```
