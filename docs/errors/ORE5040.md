# ORE5040

> Modifier '…' is not allowed here.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The modifier does not apply to this declaration. Class members take
`public`, `private`, `protected`, `readonly`, `static`, `abstract` and
`override`; top-level functions take `export`.

## Example

```ts
class Client {
    async fetch() {}
}
```

## How to fix

Remove the modifier. Ore has no `async`: a method that waits blocks only its
task.

```ts
class Client {
    fetch() {}
}
```
