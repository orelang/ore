# ORE5040

> Modifier '…' is not allowed here.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The modifier does not apply to this declaration. Class members take
`public`, `private`, `protected`, `readonly`, `static`, `abstract`,
`override` and `async`; top-level declarations take `export`, which a member
cannot have: a class is exported as a whole.

## Example

```ts
class Client {
    export fetch(): void {}
}
```

## How to fix

Remove the modifier, and export the class if other modules use it:

```ts
export class Client {
    fetch(): void {}
}
```
