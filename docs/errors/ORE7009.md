# ORE7009

> 'break' must be inside a loop or switch.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

`break` leaves the innermost loop or switch, and there is none around it
here. A function literal is a separate function: a `break` inside a callback
does not leave a loop of the code around it.

## Example

```ts
[1, 2].forEach((x) => {
    if (x > 1) break
})
```

## How to fix

Use a `for...of` loop, which can be left with `break`:

```ts
for (const x of [1, 2]) {
    if (x > 1) break
}
```

In a callback, `return` ends the call for one element.
