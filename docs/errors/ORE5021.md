# ORE5021

> A constructor must have a body.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A constructor needs a body. Ore has no constructor overload signatures.

## Example

```ts
class Point {
    constructor()
}
```

## How to fix

Write the body, which may be empty:

```ts
class Point {
    constructor() {}
}
```
