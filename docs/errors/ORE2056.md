# ORE2056

> '…' is not known yet here: give it a type annotation to use 'typeof …' before it.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

A type is resolved before the code of the module runs, and a top-level variable gets its type from its value only when that code is checked. `typeof v` in a type before then needs `v` to have a type annotation.

## Example

```ts
function f(a: typeof later): void {}
const later = 1
```

## How to fix

Annotate the variable:

```ts
function f(a: typeof later): void {}
const later: int = 1
```
