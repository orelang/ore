# ORE2056

> '…' is not known yet here: give it a type annotation to use 'typeof …' before it.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

A type is resolved before the code of the module runs, and a top-level variable gets its type from its value only when that code is checked. `typeof v` in a type needs `v` to have a type annotation, unless `v` is a `const` initialized with literals only, such as `{ a: 1, b: "s" }`.

## Example

```ts
function f(a: typeof later): void {}
const later = Math.max(1, 2)
```

## How to fix

Annotate the variable:

```ts
function f(a: typeof later): void {}
const later: int = Math.max(1, 2)
```
