# ORE4038

> The template and the constraints of 'unsafe.asm' must be string literals.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

Inline assembly is compiled into the program, so its template and
constraints must be known when the program is compiled: string literals,
not variables or expressions.

## Example

```ts
let op = "nop"
unsafe.asm(op, "")
```

## How to fix

Write the strings in the call; to choose between instructions, branch on a
constant such as `target.arch`:

```ts
unsafe.asm("nop", "")
```
