# ORE6049

> Unknown directive '//ore:…'. Known: ….

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

A comment `//ore:name` before a top-level declaration is a directive, and
this one is not known. Unknown directives are errors rather than ignored, so
that a misspelled one does not silently do nothing. The message lists the
known directives. A comment that is not meant as a directive must not start
with `//ore:`.

## Example

```ts
//ore:inlined
function add(a: int, b: int): int {
    return a + b
}
```

## How to fix

Use a known directive:

```ts
//ore:inline
function add(a: int, b: int): int {
    return a + b
}
```
