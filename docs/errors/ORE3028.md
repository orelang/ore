# ORE3028

> Cannot compare '…' with '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

`===`, `!==` and the orderings compare two values of the same type (or a
value with a union containing its type). Values of different types are
never equal, and Ore does not convert them implicitly, so the comparison is
rejected.

## Example

```ts
let input = "1"
let n = 1
const same = input === n
```

## How to fix

Convert one side so that both have the same type:

```ts
let input = "1"
let n = 1
const same = input === `${n}`
```
