# ORE3090

> An entry of a dictionary is assigned with '=' or '??=': it is '…' when read.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

Reading an entry of a dictionary gives `null` when it is missing, so
`d.a += 1` and `d.a++` have no value to start from. `=` sets an entry and
`??=` sets a missing one.

## Example

```ts
const d: Record<string, int> = {}
d.a += 1
```

## How to fix

```ts
d.a = (d.a ?? 0) + 1
```
