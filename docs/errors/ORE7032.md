# ORE7032

> Cannot switch on a value of type '…'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

`switch` compares with `===`, and works on numbers, `bool`, strings and
unions of string literals. Objects, arrays and other unions are not
supported.

## Example

```ts
const p = { kind: "circle" }
switch (p) {
}
```

## How to fix

Switch on a field, such as the discriminant of a union of object types:

```ts
type Shape = { kind: "circle"; r: f64 } | { kind: "square"; side: f64 }
function area(s: Shape): f64 {
    switch (s.kind) {
        case "circle":
            return 3.14 * s.r * s.r
        case "square":
            return s.side * s.side
    }
}
```

For classes, use `if` with `instanceof`.
