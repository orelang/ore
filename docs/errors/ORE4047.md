# ORE4047

> An entry of 'new Map' must be a [key, value] pair.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

Each entry of the array given to `new Map` is a pair: a key and a value.

## Example

```ts
const m = new Map([["a", 1, 2]])
```

## How to fix

Write each entry as `[key, value]`:

```ts
const m = new Map([["a", 1], ["b", 2]])
```
