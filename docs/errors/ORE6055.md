# ORE6055

> '//ore:…' applies to a function declaration with a body, not generic.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

The directives `//ore:inline`, `//ore:noinline`, `//ore:cold`,
`//ore:naked` and `//ore:export` (on a function) and `//ore:runtime` apply
to a top-level function declaration with a body. Generic functions are
compiled per instance and cannot take them, nor can classes or other
declarations.

## Example

```ts
//ore:inline
function first<T>(xs: T[]): T {
    return xs[0]
}
```

## How to fix

Remove the directive, or apply it to a non-generic function:

```ts
//ore:inline
function first(xs: int[]): int {
    return xs[0]
}
```
