# ORE6034

> '…' expects … type argument(s), got ….

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

A generic type or function was given a different number of type arguments
than it has type parameters (counting those with defaults as optional).

## Example

```ts
class Box<T> {}
function open(b: Box<int, string>) {}
```

## How to fix

Give one type argument per type parameter:

```ts
class Box<T> {}
function open(b: Box<int>) {}
```
