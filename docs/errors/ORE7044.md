# ORE7044

> The rest of an object pattern must be a name, not a pattern.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

`...rest` in an object pattern is a new object of the remaining public
fields, and must be bound to a name (or, in an assignment, a variable or
property). It cannot be destructured further in the same pattern, as in
TypeScript.

## Example

```ts
const p = { x: 1, y: 2, z: 3 }
const { x, ...{ y } } = p
```

## How to fix

Destructure the fields directly, or bind the rest and destructure it
afterwards:

```ts
const p = { x: 1, y: 2, z: 3 }
const { x, ...others } = p
const { y } = others
```
