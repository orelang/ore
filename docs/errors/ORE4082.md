# ORE4082

> 'Array.from' takes an array, a string, a set, a map or '{ length: n }', got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

`Array.from(items)` makes an array of the elements of an array, the
characters of a string, the values of a set or the entries of a map, or of
`n` values made by a function with `{ length: n }`. Other values have no
elements to take (iterators come later).

## Example

```ts
Array.from(5)
```

## How to fix

Pass something with elements, or a length and a function:

```ts
Array.from({ length: 5 }, (_, i) => i)
```
