# ORE3055

> No member of '…' matches this object literal.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

An object literal for a union of object types must be built as one of the
members, picked by the literal's property names and discriminant values.
No member has the properties of this literal.

## Example

```ts
type Circle = { kind: "circle"; r: f64 }
type Square = { kind: "square"; side: f64 }
const s: Circle | Square = { width: 1.0 }
```

## How to fix

Write the properties of one member:

```ts
type Circle = { kind: "circle"; r: f64 }
type Square = { kind: "square"; side: f64 }
const s: Circle | Square = { kind: "square", side: 1.0 }
```
