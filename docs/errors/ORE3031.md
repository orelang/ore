# ORE3031

> Type '…' cannot be null; '??=' is not needed.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

`x ??= v` assigns `v` when `x` is `null`. The type of `x` does not include
`null`, so it never is, and the assignment would never happen.

## Example

```ts
let name = "ada"
name ??= "anonymous"
```

## How to fix

Remove the assignment, or include `null` in the variable's type:

```ts
let name: string | null = null
name ??= "anonymous"
```
