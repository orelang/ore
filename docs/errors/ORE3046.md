# ORE3046

> Only an array or a tuple can be spread into an array.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`...x` in an array literal copies the elements of an array or a tuple. Other
values, including strings, maps and sets, cannot be spread there: Ore has no
general iteration protocol for spreading.

## Example

```ts
const word = "abc"
const chars = [...word]
```

## How to fix

For a string, split it:

```ts
const word = "abc"
const chars = word.split("")
```

For a map or a set, take its array of values or entries:

```ts
const tags = new Set<string>(["a", "b"])
const list = [...tags.values()]
```
