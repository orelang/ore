# ORE7013

> 'for...in' is not supported in Ore. Use 'for...of'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

`for...in` iterates the property names of an object in JavaScript, and the
indices of an array as strings. Ore objects have fixed fields known when
the program is compiled, so it is rejected; `for...of` iterates the elements
of arrays, strings, maps, sets and channels.

## Example

```ts
const xs = [10, 20]
for (const i in xs) console.log(i)
```

## How to fix

Iterate the elements with `for...of`:

```ts
const xs = [10, 20]
for (const x of xs) console.log(x)
```

For the indices, use a counting loop, or the index argument of `forEach`:

```ts
const xs = [10, 20]
xs.forEach((x, i) => console.log(i, x))
```

For a map, iterate its entries:

```ts
const ages = new Map<string, int>([["ada", 36]])
for (const [name, age] of ages) console.log(name, age)
```
