# ORE7021

> Cannot assign an expression of type '…' to a variable.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

The value of the initializer is a call that returns `void` (or never
returns), so there is nothing to store in the variable.

## Example

```ts
const result = console.log("hi")
```

## How to fix

Call the function as a statement:

```ts
console.log("hi")
```
