# ORE4055

> 'new Chan' takes at most a capacity.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Concurrency](../spec/06-concurrency.md)

## What it means

`new Chan<T>(n)` takes at most one argument, the capacity of its buffer.
Without it, a send waits for a receiver.

## Example

```ts
const c = new Chan<int>(1, 2)
```

## How to fix

Pass one capacity:

```ts
const c = new Chan<int>(2)
```
