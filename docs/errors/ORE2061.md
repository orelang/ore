# ORE2061

> A mapped type needs the type of its fields: '{ [K in Keys]: T }'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

A mapped type needs the type of its fields after the `:`.

## Example

```ts
type T = { [K in "a" | "b"] }
```

## How to fix

Give the type of the fields:

```ts
type T = { [K in "a" | "b"]: int }
```
