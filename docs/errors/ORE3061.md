# ORE3061

> Module '…' has no exported value '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

The module imported with `import * as m` has no exported value with this
name. Only declarations marked `export` are visible to other modules.

## Example

```ts
import * as config from "./config"
console.log(config.host)
// file: config.ore
export const port = 8080
```

## How to fix

Correct the name, or export the declaration from its module:

```ts
import * as config from "./config"
console.log(config.port)
// file: config.ore
export const port = 8080
```
