# ORE5015

> Abstract methods can only appear within an abstract class.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

An abstract method has no body, so a class that declares one cannot be
instantiated: it must be declared `abstract` itself.

## Example

```ts
class Shape {
    abstract area(): f64
}
```

## How to fix

Declare the class abstract:

```ts
abstract class Shape {
    abstract area(): f64
}
```
