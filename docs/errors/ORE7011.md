# ORE7011

> A function declaration must be at the top level or directly in a block.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function declaration is hoisted to the start of its block, so it must be
directly in a block (or at the top level), not the body of an `if`, a loop
or a label. TypeScript allows it with unclear scoping rules.

## Example

```ts
let debug = true
if (debug) function log(s: string) {}
```

## How to fix

Put it in a block:

```ts
let debug = true
if (debug) {
    function log(s: string) {}
    log("on")
}
```

Or assign a function literal to a variable.
