# ORE5032

> This static member is not supported.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A static member needs a name. This message is given for a `static`
constructor, which has none: a class has one constructor, for its instances.

## Example

```ts
class Config {
    static constructor() {}
}
```

## How to fix

Remove `static` to make it the constructor, or use a named static method:

```ts
class Config {
    static init() {}
}
```
