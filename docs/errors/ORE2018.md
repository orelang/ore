# ORE2018

> Only types of modules imported with '… as' can be qualified.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

A qualified type name `a.T` names a type exported by the module `a`, where
`a` was imported with `import * as a`, or a type of a built-in namespace,
such as `fs.FileInfo`. Here `a` is something else: an unknown name, a
variable or a class.

## Example

```ts
function draw(p: geometry.Point) {}
```

## How to fix

Import the module as a namespace:

```ts
import * as geometry from "./geometry"
let p: geometry.Point = new geometry.Point()
// file: geometry.ore
export class Point {
    x = 0
}
```

Or import the type by name and use it without the prefix:

```ts
import { Point } from "./geometry"
let p: Point = new Point()
// file: geometry.ore
export class Point {
    x = 0
}
```
