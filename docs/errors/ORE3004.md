# ORE3004

> 'super' can only call the constructor or a method of the base class: 'super(...)' or 'super.m(...)'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`super` is only allowed in two forms: `super(...)`, which calls the base
class's constructor from a constructor, and `super.m(...)`, which calls the
base class's version of method `m`. It is not a value, and fields of the base
class are reached through `this`, since a subclass shares them.

## Example

```ts
class Shape {
    sides = 0
}
class Square extends Shape {
    count(): int {
        return super.sides
    }
}
```

## How to fix

Read inherited fields through `this`:

```ts
class Shape {
    sides = 0
}
class Square extends Shape {
    count(): int {
        return this.sides
    }
}
```
