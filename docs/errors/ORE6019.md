# ORE6019

> Cannot export '…': it is not declared in this module.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

`export { name }` exports a declaration or an import of this module, and
this module has no such name.

## Example

```ts
export { parse }
```

## How to fix

Declare or import the name first, or correct it:

```ts
function parse() {}
export { parse }
```

To re-export from another module, name it with `from`:

```ts
export { parse } from "./parser"
// file: parser.ore
export function parse() {}
```
