# ORE5041

> Field '…' of type '…' must be initialized in its declaration or at the top level of the constructor.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The field's type has no zero value — it is a class, an object type or an
interface — so it must be assigned before the instance can be used: in its
declaration, or by a statement at the top level of the constructor. An
assignment inside an `if` or a loop may not run.

## Example

```ts
class Point {
    x = 0
}
class Shape {
    origin: Point
    constructor(ok: bool) {
        if (ok) this.origin = new Point()
    }
}
```

## How to fix

Assign the field on every path, at the top level of the constructor:

```ts
class Point {
    x = 0
}
class Shape {
    origin: Point
    constructor(ok: bool) {
        this.origin = new Point()
    }
}
```

Or include `null` in its type, so that it starts as `null`:

```ts
class Point {
    x = 0
}
class Shape {
    origin: Point | null = null
}
```
