# ORE4075

> 'slice' expects at most 2 arguments, got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`a.slice(start?, end?)` takes at most two offsets and returns a copy of that
part of the array.

## Example

```ts
const xs = [1, 2, 3]
const ys = xs.slice(0, 1, 2)
```

## How to fix

Pass a start and an end:

```ts
const xs = [1, 2, 3]
const ys = xs.slice(0, 2)
```
