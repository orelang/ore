# ORE6032

> Type '…' cannot be returned from C.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

The result of a C function may be a number, `bool`, `string` (a returned
`const char *`, copied) or `ptr`. Objects, arrays and unions have no C
form.

## Example

```ts
class Point {
    x = 0
}
declare function origin(): Point
```

## How to fix

Return a pointer, and read the fields with `unsafe.load`:

```ts
declare function origin(): ptr
```
