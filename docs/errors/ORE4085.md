# ORE4085

> A dictionary has no methods: '…' is an entry, of type '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

`d.name` is the entry `name` of a dictionary: a dictionary has no methods,
as `get` or `has` of a `Map`.

## Example

```ts
const d: Record<string, int> = {}
d.get("a")
```

## How to fix

Use the syntax of objects, or the namespace `Object`:

```ts
console.log(d.a, "a" in d, Object.keys(d))
```
