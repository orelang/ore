# ORE4085

> structuredClone cannot clone a function: '…' could not be cloned.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`structuredClone` copies data. The type of the value holds a function: the
value itself, a field, an element or a member of a union. JavaScript throws
a `DataCloneError` ("... could not be cloned.") when it meets one at run
time; Ore knows from the type, so the program does not compile.

## Example

```ts
type Button = { label: string; onClick: () => void }
const b: Button = { label: "ok", onClick: () => {} }
const copy = structuredClone(b)
```

## How to fix

Clone the data only, and attach the function to the copy:

```ts
type Button = { label: string; onClick: () => void }
const b: Button = { label: "ok", onClick: () => {} }
const copy: Button = { label: structuredClone(b.label), onClick: b.onClick }
```
