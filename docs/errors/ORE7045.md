# ORE7045

> A dictionary is not iterable: loop over 'Object.keys(d)' or 'Object.entries(d)'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

A dictionary is not iterable, as a JavaScript object is not.

## Example

```ts
const d: Record<string, int> = { a: 1 }
for (const entry of d) console.log(entry)
```

## How to fix

```ts
const d: Record<string, int> = { a: 1 }
for (const [key, value] of Object.entries(d)) console.log(key, value)
```
