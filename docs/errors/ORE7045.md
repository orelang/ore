# ORE7045

> Type '…' is not iterable: it needs a '[Symbol.iterator]()' method.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

`for...of`, spread, `Array.from`, `new Map`, `new Set` and `yield*` take
an iterable: an array, a string, a map, a set, or an object whose
`[Symbol.iterator]()` returns an iterator, an object with a `next()` that
returns an `IteratorResult`.

## Example

```ts
class Bag {
    items: string[] = []
}
for (const item of new Bag()) console.log(item)
```

## How to fix

```ts
class Bag {
    items: string[] = []

    *[Symbol.iterator](): Generator<string> {
        yield* this.items
    }
}
for (const item of new Bag()) console.log(item)
```
