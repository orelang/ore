# ORE6067

> Invalid JSON: ….

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [JSON files](../spec/07-modules.md#json-files)

## What it means

A file imported with `with { type: "json" }` is read when the program is
compiled and must be valid JSON (RFC 8259). The error points at the line and
column of the JSON file where reading stopped. JSON has no comments, no
trailing commas and only double-quoted strings.

## Example

```ts
import config from "./config.json" with { type: "json" }
// file: config.json
{ "name": "demo", "port": 8080, }
```

## How to fix

Fix the JSON file:

```ts
import config from "./config.json" with { type: "json" }
console.log(config.name)
// file: config.json
{ "name": "demo", "port": 8080 }
```
