# ORE3049

> Expected … element(s) for tuple type '…', got ….

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

An array literal where a tuple is expected must have exactly as many
elements as the tuple type.

## Example

```ts
const pair: [string, int] = ["a"]
```

## How to fix

Give every element:

```ts
const pair: [string, int] = ["a", 1]
```

If an element may be missing, make its type include `null`:

```ts
const pair: [string, int | null] = ["a", null]
```
