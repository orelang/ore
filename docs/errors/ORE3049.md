> Expected … element(s) for tuple type '…', got ….

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

```ts
const t: [int, string] = [1, "a"]
const short: [int, string] = [1]
```

`tests/diag/types/tuples.ore:2`: Expected 2 element(s) for tuple type '[i64, string]', got 1.
