# ORE7001

> Declare one resource per 'using'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Resources](../spec/04-functions.md#resources)

## What it means

A `using` declaration declares one resource. Resources are disposed in the
reverse order of their declarations, which is clearest with one per
statement.

## Example

```ts
class File {
    [Symbol.dispose]() {}
}
function copy() {
    using a = new File(), b = new File()
}
```

## How to fix

Write one `using` per resource:

```ts
class File {
    [Symbol.dispose]() {}
}
function copy() {
    using a = new File()
    using b = new File()
}
```
