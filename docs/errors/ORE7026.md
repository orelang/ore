# ORE7026

> A tuple cannot contain values of type '…'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

An element of a tuple literal is a call that returns `void` (or never
returns), so there is no value to store.

## Example

```ts
const [a, b] = [console.log("x"), 1]
```

## How to fix

Call the function as a statement, and put values in the tuple:

```ts
console.log("x")
const [a, b] = ["x", 1]
```
