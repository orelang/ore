# ORE6074

> Cannot find parameter '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

A type predicate (`x is T`, `asserts x is T` or `asserts x`) names a
parameter that the function does not have.

## Example

```ts
function isText(value: unknown): text is string {
    return typeof value === "string"
}
```

## How to fix

Name one of the function's parameters:

```ts
function isText(value: unknown): value is string {
    return typeof value === "string"
}
```
