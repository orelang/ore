# ORE6074

> A generator function needs a return type annotation, such as 'Generator<T>'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

A generator function, method or function expression returns a `Generator<T, TReturn, TNext>`, whose types
Ore does not infer from the `yield`s: the result type is written, or comes
from the context of a function expression.

## Example

```ts
function* count(n: int) {
    for (let i = 0; i < n; i++) yield i
}
```

## How to fix

```ts
function* count(n: int): Generator<int> {
    for (let i = 0; i < n; i++) yield i
}
```
