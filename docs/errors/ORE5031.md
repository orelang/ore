# ORE5031

> Method '…' is public in '…' and must stay public.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

The method is public in the base class, so it can be called through any
value of the base class; the override cannot restrict it to `protected`.

## Example

```ts
class Shape {
    draw() {}
}
class Square extends Shape {
    protected draw() {}
}
```

## How to fix

Keep the override public:

```ts
class Shape {
    draw() {}
}
class Square extends Shape {
    draw() {}
}
```
