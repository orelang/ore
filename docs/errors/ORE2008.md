# ORE2008

> 'Chan' expects exactly 1 type argument.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Concurrency](../spec/06-concurrency.md)

## What it means

`Chan<T>` takes one type argument, the type of the values sent through the
channel.

## Example

```ts
function collect(results: Chan<string, int>) {}
```

## How to fix

Give one type; to send several values together, send an object or a tuple:

```ts
const results: Chan<[string, int]> = new Chan()
```
