# ORE2028

> Computed property names are not supported.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

A property name must be known when the program is compiled: it becomes the
offset of a field in the object. Computed names (`[key]: T`, `{ [key]: v }`)
are not supported; the only exception is `[Symbol.dispose]`.

## Example

```ts
const key = "x"
type Point = { [key]: int }
```

## How to fix

Write the name itself:

```ts
type Point = { x: int }
```

For keys known only at run time, use a `Map`:

```ts
const values = new Map<string, int>()
values.set("x", 1)
```
