# ORE5010

> Optional field '…' needs a type annotation.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

An optional field `x?: T` has the type `T | null` and starts as `null`. It
needs the type annotation `T`: there is no value to infer it from.

## Example

```ts
class User {
    email?
}
```

## How to fix

Annotate the field:

```ts
class User {
    email?: string
}
```
