# ORE5026

> '…' is private in base class '…' and cannot be redeclared.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

A subclass cannot declare a member with the name of a private member of its
base class. The subclass contains the base class's fields, private ones
too, and the names would collide.

## Example

```ts
class Account {
    private balance = 0
}
class Savings extends Account {
    balance = 0
}
```

## How to fix

Choose another name:

```ts
class Account {
    private balance = 0
}
class Savings extends Account {
    savings = 0
}
```

Or make the member `protected` in the base class and use it from the
subclass.
