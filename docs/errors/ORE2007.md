# ORE2007

> 'Set' expects exactly 1 type argument.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Sets](../spec/03-objects.md#sets)

## What it means

`Set<T>` takes one type argument, the type of its elements.

## Example

```ts
function visit(seen: Set<string, bool>) {}
```

## How to fix

Give the element type only:

```ts
const seen: Set<string> = new Set()
```

To associate a value with each element, use a `Map`:

```ts
const seen: Map<string, bool> = new Map()
```
