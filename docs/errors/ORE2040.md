# ORE2040

> Operator '…' requires integer operands.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

The bitwise operators `&`, `|`, `^` and the shifts `<<`, `>>` work on
integers. In a constant expression, an operand with a fraction is a float
constant, and Ore does not truncate it to an integer as JavaScript does.

## Example

```ts
const mask = 1.5 | 0
```

## How to fix

Use integer constants:

```ts
const mask = 1 | 2
```

To truncate a float constant, convert it explicitly:

```ts
const n = int(1.5) | 0
```
