# ORE2023

> Property '…' must have a type annotation.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

Each property of an object type needs a type annotation: an object type
lists the fields of a record, and there is no value from which to infer a
type.

## Example

```ts
type Point = { x; y: int }
```

## How to fix

Annotate the property:

```ts
type Point = { x: int; y: int }
```
