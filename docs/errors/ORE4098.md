# ORE4098

> Type '…' has no '[Symbol.iterator]' method.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

`x[Symbol.iterator]()` calls the method that makes an iterator of `x`.
Strings, arrays, maps and sets have it, and so does a class or an
interface that declares it; a number, a boolean or a class without it
does not.

## Example

```ts
class Bag {
    items: string[] = []
}
const it = new Bag()[Symbol.iterator]()
```

## How to fix

Declare the method, such as a generator, or iterate what holds the values:

```ts
class Bag {
    *[Symbol.iterator](): Generator<string> {
        yield* this.items
    }
    items: string[] = []
}
const it = new Bag()[Symbol.iterator]()
```
