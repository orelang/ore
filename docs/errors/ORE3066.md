# ORE3066

> A constant is not an object.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

The left side of `instanceof` is a numeric constant. `instanceof` checks the
class of an object at run time, and a constant is never an object.

## Example

```ts
const isError = 5 instanceof Error
```

## How to fix

Test a value of a class, interface or union type:

```ts
function check(r: int | Error) {
    if (r instanceof Error) console.log(r.message)
}
```
