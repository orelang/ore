# ORE6046

> This declaration is not supported at the top level.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Programs](../spec/01-programs.md#programs)

## What it means

The declaration is not supported at the top level of a module. The checker
reports `enum` and `namespace` declarations with their own messages,
[ORE6044](ORE6044.md) and [ORE6045](ORE6045.md), and the parser rejects
other unknown declarations, so this message is not produced at present.

## Example

<!-- no-check -->
```ts
declare global {}
```

## How to fix

Remove the declaration, and use the forms Ore supports: functions,
classes, interfaces, type aliases, variables, imports and exports.

```ts
export const answer = 42
```
