# ORE5034

> Static members cannot be abstract.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

Static members belong to the class, not to instances, and are not
inherited through the class table, so they cannot be overridden: an
abstract static member could never be implemented.

## Example

```ts
abstract class Shape {
    static abstract create(): void {}
}
```

## How to fix

Remove `abstract`, or use an abstract instance method:

```ts
abstract class Shape {
    abstract create(): void
}
```
