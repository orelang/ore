# ORE5069

> Field '…' is used before its type is known: its initializer uses '…', declared further down. Annotate the field.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A field without a type annotation takes its type from its initializer. An
initializer may use any variable of its module, as it runs when an instance
is constructed, but its type is known only once the top-level code has
declared those variables. Top-level code before that declaration used the
field.

## Example

```ts
class Counter {
    count = start * 2
}

const c = new Counter()
console.log(c.count)
let start = 1
```

## How to fix

Annotate the field, so that its type is known before its initializer is
checked, or move the variable above the code that uses the field:

```ts
class Counter {
    count: int = start * 2
}

const c = new Counter()
console.log(c.count)
let start = 1
```

An instance constructed before the variable's declaration runs reads its
zero value, as a function using it does.
