# ORE4044

> A value of type '…' is not a function.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

The expression is called, but its type is not a function type.

## Example

```ts
const handlers = [1, 2]
handlers[0]()
```

## How to fix

Store functions where they are called:

```ts
const handlers = [() => 1, () => 2]
handlers[0]()
```
