# ORE5044

> A getter or setter must have a body.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A getter or setter needs a body: it is called when the property is read or
written.

## Example

```ts
class Circle {
    get area(): f64
}
```

## How to fix

Write the body:

```ts
class Circle {
    get area(): f64 {
        return 1.0
    }
}
```
