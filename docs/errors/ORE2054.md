# ORE2054

> An index type is a string literal or a union of them, not '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

In `T[K]`, the index names members of T: a string literal type, or a union of them (`T["a" | "b"]`). `T[number]` takes the elements of an array or a tuple.

## Example

```ts
type P = { x: int }
type C = P[int]
```

## How to fix

Name the member:

```ts
type P = { x: int }
type X = P["x"]
```
