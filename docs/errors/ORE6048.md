# ORE6048

> Cannot find module '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

The import cannot be resolved. `./x` and `../x` resolve to `x.ore` or
`x/index.ore` next to the importing file; a package name to
`node_modules/<name>` in the importing file's directory or above; `ore:`
names a standard module. Note that the specifier has no `.ts` or `.js`
extension.

## Example

```ts
import { parse } from "./parser"
```

## How to fix

Correct the specifier, create the module, or install the package with npm:

```ts
import { parse } from "./parser"
// file: parser.ore
export function parse() {}
```
