# ORE6045

> Namespaces are not supported in Ore. Use modules.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

TypeScript namespaces (`namespace N { }`, `module N { }`,
`declare module`, `declare global`) are not supported. Each Ore file is a
module, which plays that role.

## Example

```ts
namespace Geometry {
    export const unit = 1
}
```

## How to fix

Move the declarations to their own module, and import it as a namespace:

```ts
import * as Geometry from "./geometry"
console.log(Geometry.unit)
// file: geometry.ore
export const unit = 1
```
