# ORE6002

> '…' is not a C name.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

`//ore:export name` makes a function or variable visible to C under `name`,
which must be a valid C identifier: letters, digits and `_`, not starting
with a digit.

## Example

```ts
//ore:export add-one
function addOne(x: int): int {
    return x + 1
}
```

## How to fix

Use a C identifier:

```ts
//ore:export add_one
function addOne(x: int): int {
    return x + 1
}
```
