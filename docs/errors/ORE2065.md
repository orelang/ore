# ORE2065

> An integer constant is not assignable to type 'bigint'. Write a bigint literal: '…n'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [BigInt](../spec/02-types.md#bigint)

## What it means

An integer constant such as `5` is a number: it becomes any integer or
float type it fits, but not a `bigint`. As in JavaScript, where `1n + 1`
throws a `TypeError`, numbers and bigints do not mix; a bigint constant
is written with the suffix `n`.

## Example

```ts
let total = 0n
total += 1
```

## How to fix

Write the constant as a bigint literal:

```ts
let total = 0n
total += 1n
```

Or convert a number to a bigint with `BigInt(x)`:

```ts
const count = 3
let total = 0n
total += BigInt(count)
```
