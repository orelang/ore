# ORE5028

> '…' is already declared in base class '…' as a …; only methods can be overridden.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [03-objects.md](../spec/03-objects.md)

## Example

```ts
class Cat extends Animal {
    sound = "meow"
```

`tests/diag/types/inheritance.ore:36`: 'sound' is already declared in base class 'Animal' as a field; only methods can be overridden.
