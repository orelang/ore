# ORE5028

> '…' is already declared in base class '…' as a …; only methods can be overridden.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

The base class already has a member with this name that is not a method —
a field — and only methods can be overridden. A subclass has the fields of
its base class at the same offsets, so a field cannot be redeclared or
replaced by a method or an accessor.

## Example

```ts
class Shape {
    sides = 0
}
class Square extends Shape {
    sides = 4
}
```

## How to fix

Set the inherited field in the constructor:

```ts
class Shape {
    sides = 0
}
class Square extends Shape {
    constructor() {
        super()
        this.sides = 4
    }
}
```
