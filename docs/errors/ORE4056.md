# ORE4056

> Cannot create an instance of an abstract class '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

An `abstract` class may have abstract methods without a body, so it cannot
be instantiated itself: only a subclass that implements them can.

## Example

```ts
abstract class Shape {
    abstract area(): f64
}
const s = new Shape()
```

## How to fix

Instantiate a subclass that implements the abstract methods:

```ts
abstract class Shape {
    abstract area(): f64
}
class Square extends Shape {
    area(): f64 {
        return 1.0
    }
}
const s: Shape = new Square()
```
