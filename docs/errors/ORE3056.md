# ORE3056

> Property '…' does not exist in type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const bad = { ...5 }
const twice = { a: 1, ...p, a: 2 }
const extra: Point = { ...p, z: 3 }
```

`tests/diag/types/object-spread.ore:5`: Property 'z' does not exist in type 'Point'.
