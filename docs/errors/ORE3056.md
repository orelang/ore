# ORE3056

> Property '…' does not exist in type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An object literal for an object type must have exactly its fields: an
object type is an exact record, and there is nowhere to store an extra
property.

## Example

```ts
type Point = { x: int; y: int }
const p: Point = { x: 1, y: 2, z: 3 }
```

## How to fix

Remove the property, or add it to the type:

```ts
type Point = { x: int; y: int; z: int }
const p: Point = { x: 1, y: 2, z: 3 }
```
