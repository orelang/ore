# ORE4045

> This function expects … argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function value is called with a number of arguments its type does not
take. A function type lists its parameters; optional ones (`b?: T`) may be
left out, and a rest parameter takes any number.

## Example

```ts
const square = (x: int) => x * x
square(1, 2)
```

## How to fix

Pass the arguments the function takes:

```ts
const square = (x: int) => x * x
square(2)
```
