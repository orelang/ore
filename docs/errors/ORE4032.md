# ORE4032

> '…' converts between numeric types, not '…' and '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
unsafe.bitcast<u32>(1.5)
unsafe.bitcast<ptr>(1)
```

`tests/diag/runtime/unsafe.ore:59`: 'unsafe.bitcast' converts between numeric types, not 'i64' and 'ptr'.
