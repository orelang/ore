# ORE4032

> '…' converts between numeric types, not '…' and '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

`unsafe.bitcast<T>(x)` reinterprets the bits of a number as another numeric
type of the same size, such as `f64` and `u64`. It does not apply to
strings, `bool`, objects or `ptr`.

## Example

```ts
const s = unsafe.bitcast<string>(1.0)
```

## How to fix

Bitcast between numeric types only:

```ts
const bits = unsafe.bitcast<u64>(1.0)
```
