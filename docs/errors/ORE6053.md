# ORE6053

> '//ore:…' goes at the top of the file, before the first statement.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

`//ore:internal` applies to the whole module, so it goes before the first
statement of the file.

## Example

```ts
const a = 1
//ore:internal
const b = 2
```

## How to fix

Move it to the top of the file:

```ts
//ore:internal
const a = 1
const b = 2
```
