# ORE5067

> An optional method of an interface cannot be generic.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

An optional method `m?(): T` is a read-only field holding a function or
null, and a function value cannot be generic: only methods called by name
are instantiated per call.

## Example

```ts
interface Source {
    read?<T>(key: string): T
}
```

## How to fix

Make the method required, or the interface generic:

```ts
interface Source<T> {
    read?(key: string): T
}
```
