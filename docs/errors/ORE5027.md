# ORE5027

> Accessors cannot be overridden yet: '…' is an accessor of base class '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

A getter or setter of a base class cannot be overridden yet: accessors are
called directly, not through the class table.

## Example

```ts
class Shape {
    get name(): string {
        return "shape"
    }
}
class Square extends Shape {
    get name(): string {
        return "square"
    }
}
```

## How to fix

Have the accessor call a method, and override the method:

```ts
class Shape {
    get name(): string {
        return this.describe()
    }
    describe(): string {
        return "shape"
    }
}
class Square extends Shape {
    describe(): string {
        return "square"
    }
}
```
