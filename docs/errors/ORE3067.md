# ORE3067

> A value of type '…' is never an instance of '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

`x instanceof C` narrows a value whose type could hold a `C`: a base class of
`C`, an interface `C` implements, or a union containing a related type.
Classes are nominal, so a value of an unrelated class is never an instance
of `C`, and the test would always be false.

## Example

```ts
class Cat {}
class Dog {}
function isDog(a: Cat): bool {
    return a instanceof Dog
}
```

## How to fix

Give the value a type that can hold both classes, such as a union or a
common base class:

```ts
class Cat {}
class Dog {}
function isDog(a: Cat | Dog): bool {
    return a instanceof Dog
}
```
