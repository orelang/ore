# ORE5045

> Getter '…' must have a return type annotation.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A getter defines the type of its property, so it needs a return type
annotation; it is not inferred from the body.

## Example

```ts
class Circle {
    get area() {
        return 1.0
    }
}
```

## How to fix

Annotate the return type:

```ts
class Circle {
    get area(): f64 {
        return 1.0
    }
}
```
