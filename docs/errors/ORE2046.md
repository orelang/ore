# ORE2046

> An index signature is a type alone, '{ [key: string]: T }', not a member of a class, an interface or an object type with other members.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

An index signature, `[key: string]: T`, makes a dictionary type: a hash
map of string keys used with the syntax of objects. It is a type of its own,
written alone in an object type, `{ [key: string]: T }` (or
`Record<string, T>`). A class, an interface or an object type with fields
cannot also have one: their fields are laid out when the program is compiled.

## Example

```ts
interface Scores {
    [name: string]: int
    total: int
}
```

## How to fix

Keep the dictionary in a field of its own:

```ts
type Scores = { byName: { [name: string]: int }; total: int }
```
