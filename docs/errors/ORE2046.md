# ORE2046

> Index signatures are not supported. Use a 'Map<K, V>'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

Index signatures (`[key: string]: T`) describe objects used as dictionaries.
In Ore an object has a fixed set of fields, known when the program is
compiled, so a dictionary is a `Map`.

## Example

```ts
interface Scores {
    [name: string]: int
}
```

## How to fix

Use a `Map`:

```ts
const scores = new Map<string, int>()
scores.set("ada", 3)
console.log(scores.get("ada") ?? 0)
```
