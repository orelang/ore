# ORE2046

> An index signature makes a dictionary, '{ name: string; [key: string]: T }': it is not a member of a class, of a generic interface or of an interface that extends another.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

An index signature, `[key: string]: T`, makes a dictionary type: a hash
map of string keys used with the syntax of objects. In an object type or an
interface of properties, the properties are its
[named entries](../spec/03-objects.md#named-entries). A class cannot have
one: its fields are laid out when the program is compiled. Nor can a generic
interface or one that extends another, which are interfaces of objects.

## Example

```ts
class Scores {
    total = 0;
    [name: string]: int
}
```

## How to fix

Keep the dictionary in a field of its own, or make the type a dictionary
with named entries:

```ts
class Scores {
    total = 0
    byName: { [name: string]: int } = {}
}
type Totals = { total: int; [name: string]: int }
```
