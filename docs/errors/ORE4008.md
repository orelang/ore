# ORE4008

> Cannot convert … to '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Conversions](../spec/02-types.md#conversions)

## What it means

A conversion of a float constant to an integer type truncates it when the
program is compiled. An infinity or `NaN` has no integer value, so the
conversion is rejected there (at run time it would saturate, or give 0 for
`NaN`).

## Example

```ts
const n = u8(1e400)
```

## How to fix

Convert a finite constant, or the type's bound you mean:

```ts
const n = u8(255)
```
