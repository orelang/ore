# ORE5035

> Static members cannot be protected; make it private or public.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A static member is either visible everywhere (`public`, the default) or only
inside the class declaration (`private`). `protected` is not supported for
static members.

## Example

```ts
class Config {
    protected static port = 80
}
```

## How to fix

Make it private or public:

```ts
class Config {
    private static port = 80
}
```
