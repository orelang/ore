# ORE3023

> Operator '…' cannot be applied to types '…' and '…'. Convert one side explicitly, e.g. '…(x)'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
let a: i32 = 1
let b: f64 = 2
let c = a + b
```

`tests/diag/basics/mixed-types.ore:3`: Operator '+' cannot be applied to types 'i32' and 'f64'. Convert one side explicitly, e.g. 'i32(x)'.
