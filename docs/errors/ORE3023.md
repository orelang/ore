# ORE3023

> Operator '…' cannot be applied to types '…' and '…'. Convert one side explicitly, e.g. '…(x)'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

Arithmetic and bitwise operators need both operands of the same type. Ore
never converts between numeric types implicitly — not even from `i32` to
`i64` — so that the cost and the rounding or truncation of every conversion
is visible in the code. Untyped constants adapt to the other operand.

## Example

```ts
const a: i32 = 1
const b: i64 = 2
const sum = a + b
```

## How to fix

Convert one side explicitly:

```ts
const a: i32 = 1
const b: i64 = 2
const sum = i64(a) + b
```
