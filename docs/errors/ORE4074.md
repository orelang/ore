# ORE4074

> 'pop' expects no arguments, got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`a.pop()` removes and returns the last element, and takes no arguments. To
remove other elements, build a new array.

## Example

```ts
const xs = [1, 2, 3]
xs.pop(0)
```

## How to fix

Call it without arguments:

```ts
const xs = [1, 2, 3]
xs.pop()
```

To drop the first elements, take a slice:

```ts
let xs = [1, 2, 3]
xs = xs.slice(1)
```
