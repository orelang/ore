# ORE6020

> A function declaration must have a name.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function declaration needs a name. Anonymous functions are written as
expressions: arrow functions or function expressions. The parser of Ore
reports a nameless function declaration as a syntax error
([ORE1001](ORE1001.md)), so this message is not produced at present.

## Example

<!-- no-check -->
```ts
function (x: int) {}
```

## How to fix

Name the function, or assign a function expression to a variable:

```ts
function handle(x: int) {}
const other = (x: int) => {}
```
