# ORE3082

> Static members cannot reference class type parameters.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A static field of a generic class `C<T>` is one value shared by all the
instances of the class, `C<int>` and `C<string>` alike, so its type cannot
name `T`: there is no single `T` it could be.

## Example

```ts
class Pool<T> {
    static free: T[] = []
}
```

## How to fix

Give the field a type that does not depend on the type parameter, or keep
the value in each instance:

```ts
class Pool<T> {
    static created = 0
    free: T[] = []
}
```
