# ORE2035

> An integer constant is not assignable to type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Numeric literals](../spec/02-types.md#numeric-literals)

## What it means

An integer literal or constant can become any numeric type it fits, but
nothing else: there is no implicit conversion from a number to `bool`,
`string` or an object. Ore has no truthiness for numbers in assignments.

## Example

```ts
const enabled: bool = 1
```

## How to fix

Write a value of the expected type, or compare the number:

```ts
const enabled: bool = true
const flags = 1
const set: bool = flags !== 0
```
