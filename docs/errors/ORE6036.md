# ORE6036

> Type '…' does not satisfy the constraint '…' of '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

A type parameter declared `T extends C` accepts only type arguments that
convert to `C`. The constraint is checked when the instance is created,
here with the type inferred or given at the call.

## Example

```ts
interface Named {
    name: string
}
function greet<T extends Named>(x: T) {}
greet(42)
```

## How to fix

Pass a value whose type meets the constraint:

```ts
interface Named {
    name: string
}
function greet<T extends Named>(x: T) {}
greet({ name: "ada" })
```
