# ORE6015

> Use 'export { name }' to re-export; 'export …' is not supported.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

`export * from "./m"` re-exports everything a module exports. Ore requires
the names to be listed, so that the exports of each module are visible
where it is written.

## Example

```ts
export * from "./shapes"
// file: shapes.ore
export class Square {}
```

## How to fix

Name the exports to re-export:

```ts
export { Square } from "./shapes"
// file: shapes.ore
export class Square {}
```
