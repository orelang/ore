# ORE6015

> Use 'export { name }' to re-export; 'export …' is not supported.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

This message is no longer produced: `export * from "./m"` re-exports every
export of a module and `export * as ns from "./m"` re-exports the module as
a namespace, as in TypeScript. Earlier versions required the names to be
listed and rejected `export *` with this message.
