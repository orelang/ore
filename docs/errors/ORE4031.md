# ORE4031

> Atomic operations need an integer or 'ptr', got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

The atomic operations of `unsafe` work on integers and `ptr` values, which
the processor can update atomically. Floats, strings and objects are not
supported.

## Example

```ts
let p = unsafe.alloc(8)
const v = unsafe.atomicLoad<f64>(p)
```

## How to fix

Use an integer type; a float can be stored as its bits with
`unsafe.bitcast`:

```ts
let p = unsafe.alloc(8)
const v = unsafe.bitcast<f64>(unsafe.atomicLoad<u64>(p))
```
