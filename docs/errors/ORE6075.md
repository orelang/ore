# ORE6075

> A 'this' type predicate is allowed only in a method.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

`this is T` tells the type of the receiver of a method; a function or a
function literal has no receiver.

## Example

```ts
function isDog(): this is Dog {
    return false
}
```

## How to fix

Declare it as a method of the class, or take the value as a parameter:

```ts
function isDog(a: Animal): a is Dog {
    return a instanceof Dog
}
```
