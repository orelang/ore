# ORE4023

> '…' expects 1 to 3 argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`JSON.stringify(value, replacer?, space?)` takes the value, then optionally
`null` and the number of spaces to indent by.

## Example

```ts
const s = JSON.stringify()
```

## How to fix

Pass the value to convert:

```ts
const s = JSON.stringify([1, 2])
```
