# ORE5019

> Default type arguments are not supported yet.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

The type parameters of a generic method cannot have defaults yet. (Those of
functions, classes, interfaces and aliases can.)

## Example

```ts
class List {
    sum<T = int>(xs: T[]): int {
        return xs.length
    }
}
```

## How to fix

Remove the default; the type argument is inferred from the arguments or
given at the call:

```ts
class List {
    sum<T>(xs: T[]): int {
        return xs.length
    }
}
```
