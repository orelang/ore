# ORE5019

> Default type arguments are not supported yet.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

This message is no longer produced: the type parameters of a generic method
can have defaults now (`sum<T = int>(xs: T[]): int`), as those of functions,
classes, interfaces and aliases can. Earlier versions rejected them with
this message.
