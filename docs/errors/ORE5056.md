# ORE5056

> This interface member is not supported.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

The interface member is TypeScript syntax that Ore does not support. An
interface has fields and methods; index signatures have their own error,
[ORE2046](ORE2046.md). The parser of Ore reads every other member as a
field or a method, so this message is not produced at present.

## Example

<!-- no-check -->
```ts
interface Sized {
    get size(): int
}
```

## How to fix

Declare a field; a class can implement it with a field (accessors do not
implement interface fields):

```ts
interface Sized {
    readonly size: int
}
```
