# ORE2009

> 'Array' expects exactly 1 type argument.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`Array<T>` is another way to write `T[]`, and takes one type argument, the
element type.

## Example

```ts
const xs: Array<int, int> = [1, 2]
```

## How to fix

Give one element type, or use the `T[]` form:

```ts
const xs: Array<int> = [1, 2]
const ys: int[] = [3, 4]
```
