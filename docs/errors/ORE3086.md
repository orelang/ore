# ORE3086

> Only a dictionary of '…' or an object can be spread into '…', got '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

A dictionary literal takes the entries of dictionaries with the same type of
values, and the fields of objects whose fields convert to its values.

## Example

```ts
const names: Record<string, string> = { a: "x" }
const counts: Record<string, int> = { ...names }
```

## How to fix

Spread a dictionary of the same values, or convert the entries:

```ts
const names: Record<string, string> = { a: "x" }
const counts = Object.fromEntries(Object.entries(names).map(([k, v]): [string, int] => [k, v.length]))
console.log(counts)
```
