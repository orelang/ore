# ORE3050

> Array holes are not supported.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

An array literal with an empty slot (`[1, , 3]`) makes a sparse array in
JavaScript. Ore arrays are dense: every element has a value of the element
type.

## Example

```ts
const xs = [1, , 3]
```

## How to fix

Write a value for every element, using `null` in a type that includes it
for a missing one:

```ts
const xs: (int | null)[] = [1, null, 3]
```
