# ORE2012

> Generic function types are not supported.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function type such as `<T>(x: T) => T` would describe a function value that
works for any `T`. Ore compiles generics by instantiating them for each set
of type arguments, so a single function value cannot be generic: only
named generic functions and methods, called with known types, can.

## Example

```ts
function apply(f: <T>(x: T) => T) {}
```

## How to fix

Give the function type concrete types:

```ts
let identity: (x: int) => int = (x) => x
```

Or make the enclosing function or class generic, so that `T` is known in each
instance:

```ts
function apply<T>(x: T, f: (x: T) => T): T {
    return f(x)
}
```
