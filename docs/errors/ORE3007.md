# ORE3007

> 'delete' is not supported in Ore.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

An object has a fixed set of fields, laid out when the program is compiled,
so a field cannot be removed. `delete` is not supported.

## Example

```ts
const user = { name: "ada", email: "a@b.c" }
delete user.email
```

## How to fix

Make the field optional, and set it to `null`:

```ts
type User = { name: string; email?: string }
const user: User = { name: "ada", email: "a@b.c" }
user.email = null
```

For keys added and removed at run time, use a `Map`:

```ts
const fields = new Map<string, string>()
fields.set("email", "a@b.c")
fields.delete("email")
```
