# ORE3007

> 'delete' removes an entry of a dictionary, '{ [key: string]: T }', only.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

An object has a fixed set of fields, laid out when the program is compiled,
so a field cannot be removed. `delete` removes the entries of dictionaries
only.

## Example

```ts
const user = { name: "ada", email: "a@b.c" }
delete user.email
```

## How to fix

Make the field optional and set it to `null`, or use a dictionary:

```ts
const fields: Record<string, string> = { email: "a@b.c" }
delete fields.email
```
