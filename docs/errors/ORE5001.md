# ORE5001

> A class declaration must have a name.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A class declaration needs a name: classes are nominal types, known by their
name, and Ore has no class expressions or anonymous classes.

## Example

```ts
export class {}
```

## How to fix

Name the class:

```ts
export class Point {}
```
