# ORE6038

> A rest parameter must be the last parameter.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A rest parameter `...xs: T[]` receives the remaining arguments, so it must
be the last parameter.

## Example

```ts
function log(...parts: string[], level: int) {}
```

## How to fix

Move it to the end:

```ts
function log(level: int, ...parts: string[]) {}
```
