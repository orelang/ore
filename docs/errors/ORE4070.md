# ORE4070

> Method '….…' expects … argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The method is called with a number of arguments it does not take.

## Example

```ts
class Counter {
    reset() {}
}
new Counter().reset(0)
```

## How to fix

Pass the arguments it takes, or add a parameter (optional if it may be left
out):

```ts
class Counter {
    reset(to = 0) {}
}
new Counter().reset(0)
```
