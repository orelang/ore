# ORE5061

> A method returning 'this' must return 'this' or what a method returning 'this' returns on it.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

A call through a subclass takes the result of a method of the type `this` as
an instance of the subclass, the receiver. So the method must return the
receiver: `this`, a call on `this` (or on `super`) of a method whose result
is `this`, or a conditional of these. Another instance of the class would be
taken for an instance of the subclass. TypeScript reports a new instance as
well (TS2322), but allows other values of the type `this`, such as a
parameter of that type, which Ore rejects.

## Example

```ts
class Counter {
    count = 0
    copy(): this {
        return new Counter()
    }
}
```

## How to fix

Return the receiver, or give the method the class as its result type:

```ts
class Counter {
    count = 0
    copy(): Counter {
        const copy = new Counter()
        copy.count = this.count
        return copy
    }
}
```
