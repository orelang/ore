# ORE5029

> Method '…' must have the type of the method it overrides in '…': '…', not '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

An overriding method must have the same parameter and result types as the
method it overrides: it is called through the same slot of the class table,
with the same arguments. TypeScript allows compatible types; Ore requires
the same ones.

## Example

```ts
class Shape {
    scale(by: f64) {}
}
class Square extends Shape {
    scale(by: int) {}
}
```

## How to fix

Use the base method's types:

```ts
class Shape {
    scale(by: f64) {}
}
class Square extends Shape {
    scale(by: f64) {}
}
```

Or give the method another name if it does something different.
