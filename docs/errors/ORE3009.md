# ORE3009

> '…' is a class. Create an instance with 'new …(...)'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The name of a class is a type, not a value: there is no class object at run
time to store or pass around. An instance is created with `new`.

## Example

```ts
class Point {
    x = 0
}
const p = Point
```

## How to fix

Create an instance:

```ts
class Point {
    x = 0
}
const p = new Point()
```

To pass "a way to make a `Point`", pass a function:

```ts
class Point {
    x = 0
}
const make = () => new Point()
```
