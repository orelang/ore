# ORE3030

> '…=' cannot assign to a field of an interface or a union; write 'x = x … v'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

`x ??= v`, `x ||= v` and `x &&= v` assign only in some cases, and Ore does
not support them yet on a field read through an interface or a union, where
the field's place depends on the object behind the value.

## Example

```ts
interface Named {
    name: string | null
}
const n: Named = { name: null }
n.name ??= "anonymous"
```

## How to fix

Write the assignment out, as the message suggests:

```ts
interface Named {
    name: string | null
}
const n: Named = { name: null }
n.name = n.name ?? "anonymous"
```
