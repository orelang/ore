# ORE5037

> Only fields and methods can be static.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

Only fields and methods can be static. Static getters and setters are not
supported.

## Example

```ts
class Config {
    static get port(): int {
        return 80
    }
}
```

## How to fix

Use a static method or a static field:

```ts
class Config {
    static port(): int {
        return 80
    }
}
```
