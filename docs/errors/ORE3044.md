# ORE3044

> Cannot assign to '…': its type differs between the members of '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A field that every member of a union has can be read without narrowing,
with the union of its types. It can only be assigned without narrowing
when it has the same type in every member: here it does not, so the
compiler cannot tell which values are allowed.

## Example

```ts
type Circle = { kind: "circle"; size: f64 }
type Grid = { kind: "grid"; size: int }
function grow(s: Circle | Grid) {
    s.size = 2
}
```

## How to fix

Narrow the value to one member first:

```ts
type Circle = { kind: "circle"; size: f64 }
type Grid = { kind: "grid"; size: int }
function grow(s: Circle | Grid) {
    if (s.kind === "circle") s.size = 2.0
    else s.size = 2
}
```
