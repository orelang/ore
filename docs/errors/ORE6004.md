# ORE6004

> An exported function cannot have optional or rest parameters.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

A C caller passes every argument, so a function exported with
`//ore:export` cannot have optional, default or rest parameters.

## Example

```ts
//ore:export scale
function scale(x: int, by = 2): int {
    return x * by
}
```

## How to fix

Make every parameter required:

```ts
//ore:export scale
function scale(x: int, by: int): int {
    return x * by
}
```
