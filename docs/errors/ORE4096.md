# ORE4096

> 'Object.fromEntries' takes [string, value] pairs, got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

`Object.fromEntries` makes a dictionary of `[key, value]` pairs whose keys
are strings, from an array or any other iterable of them. The values of
this iterable are not such pairs: a map whose keys are numbers, say, or a
set of single values.

## Example

```ts
const byId = new Map<int, string>([[1, "ada"]])
const names = Object.fromEntries(byId)
```

## How to fix

Give the pairs string keys:

```ts
const byId = new Map<int, string>([[1, "ada"]])
const names = Object.fromEntries(Array.from(byId, ([id, name]): [string, string] => [`${id}`, name]))
```
