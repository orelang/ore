# ORE5046

> Setter '…' must take one parameter with a type annotation.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A setter receives the value assigned to the property, so it takes exactly
one parameter, with a type annotation.

## Example

```ts
class Circle {
    set radius(r) {}
}
```

## How to fix

Annotate the parameter:

```ts
class Circle {
    set radius(r: f64) {}
}
```
