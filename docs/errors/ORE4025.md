# ORE4025

> 'JSON.parse' needs the type to read, e.g. 'JSON.parse<Config>(text)'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`JSON.parse` reads JSON into a value of a type known when the program is
compiled, and checks the shape of the text against it; the type is given as
its one type argument. Without it there is no type to read, as there is no
`any`.

## Example

```ts
const config = JSON.parse('{"port": 80}')
```

## How to fix

Give the type to read. The result is the value or an `Error`:

```ts
type Config = { port: int }
const config = JSON.parse<Config>('{"port": 80}')
if (config instanceof Error) process.panic(config.message)
console.log(config.port)
```
