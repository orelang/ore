# ORE6008

> A thread-local variable holds a number, 'bool' or 'ptr', not '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

A thread-local variable holds a number, a `bool` or a `ptr`. The garbage
collector does not scan thread-local storage, so it cannot hold references
such as strings, arrays or objects.

## Example

```ts
//ore:threadlocal
let name: string
```

## How to fix

Store a number or a pointer:

```ts
//ore:threadlocal
let id: int
```
