# ORE5033

> Duplicate static member '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

Two static members of a class have the same name.

## Example

```ts
class Config {
    static port = 80
    static port = 8080
}
```

## How to fix

Rename or remove one of them:

```ts
class Config {
    static port = 80
    static tlsPort = 443
}
```
