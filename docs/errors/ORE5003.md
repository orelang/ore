# ORE5003

> Duplicate declaration '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

Two top-level declarations of a module declare the same name: functions,
classes, variables and imports share one namespace of values. Unlike
TypeScript, Ore does not merge declarations, and functions are not
redeclared by a later one.

## Example

```ts
function parse() {}
function parse() {}
```

## How to fix

Rename or remove one of them:

```ts
function parse() {}
function parseAll() {}
```

To give one function several signatures, write overload signatures before
one implementation:

```ts
function parse(s: string): int
function parse(s: string[]): int[]
function parse(s: string | string[]): int | int[] {
    return 0
}
```
