# ORE5042

> Constructors for derived classes must contain a 'super' call.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

The constructor of a class with a base class must call `super(...)`, which
initializes the fields of the base class.

## Example

```ts
class Shape {}
class Square extends Shape {
    constructor() {}
}
```

## How to fix

Call `super(...)` as a statement at the top level of the constructor:

```ts
class Shape {}
class Square extends Shape {
    constructor() {
        super()
    }
}
```

Or remove the constructor: a class without one takes the parameters of its
base class's constructor.
