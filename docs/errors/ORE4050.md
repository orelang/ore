# ORE4050

> 'new Set' takes at most one argument: an array or a set of values.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Sets](../spec/03-objects.md#sets)

## What it means

`new Set(values)` takes at most one argument: an array of values, or another
set to copy.

## Example

```ts
const s = new Set([1], [2])
```

## How to fix

Put all the values in one array:

```ts
const s = new Set([1, 2])
```
