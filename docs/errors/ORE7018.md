# ORE7018

> 'var' is not supported in Ore. Use 'let' or 'const'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

`var` declares a function-scoped, hoisted variable. Ore supports only the
block-scoped `let` and `const`.

## Example

```ts
var count = 0
```

## How to fix

Use `let`, or `const` if the variable is not reassigned:

```ts
let count = 0
```
