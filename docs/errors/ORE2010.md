# ORE2010

> Generic type '…' requires type arguments.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

A generic class, interface or type alias is a template: each set of type
arguments makes a separate type, compiled separately. Used as a type, it
needs its type arguments, unless its type parameters have defaults.

## Example

```ts
class Box<T> {
    constructor(readonly value: T) {}
}
const b: Box = new Box(1)
```

## How to fix

Give the type arguments:

```ts
class Box<T> {
    constructor(readonly value: T) {}
}
const b: Box<int> = new Box(1)
```

Or leave out the annotation, and the type is inferred:

```ts
class Box<T> {
    constructor(readonly value: T) {}
}
const b = new Box(1)
```
