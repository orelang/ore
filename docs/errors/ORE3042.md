# ORE3042

> Cannot find name '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Variables](../spec/02-types.md#variables)

## What it means

No variable, function, class, import or built-in has this name here. It may
be misspelled, declared in another scope, or exported by a module that is
not imported. Some JavaScript globals do not exist in Ore: `NaN` and
`Infinity` are `Number.NaN` and `Number.POSITIVE_INFINITY`, and `window`,
`globalThis` or `require` have no counterpart.

## Example

```ts
const total = count + 1
```

## How to fix

Declare the name, or import it from the module that exports it:

```ts
const count = 1
const total = count + 1
```
