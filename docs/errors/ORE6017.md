# ORE6017

> Module '…' has no exported member '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

The module has no export with this name. Only declarations marked `export`
(or listed in `export { ... }`) are visible to other modules.

## Example

```ts
import { Circle } from "./shapes"
// file: shapes.ore
export class Square {}
```

## How to fix

Correct the name, or export the declaration from its module:

```ts
import { Circle } from "./shapes"
// file: shapes.ore
export class Square {}
export class Circle {}
```
