# ORE6052

> '//ore:runtime' is only for the standard library. Add '//ore:internal' at the top of the file to use it here.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

`//ore:runtime name` makes a function the implementation of a function of
the runtime, which the compiler calls directly. It is for the standard
library; other modules must opt in with `//ore:internal`, since the
runtime's contracts may change at any time.

## Example

```ts
//ore:runtime print_int
function printInt(n: int) {}
```

## How to fix

Remove the directive. If the module really is part of a runtime, put
`//ore:internal` before its first statement:

<!-- no-check -->
```ts
//ore:internal
//ore:runtime print_int
function printInt(n: int) {}
```
