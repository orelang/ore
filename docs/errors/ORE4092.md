# ORE4092

> structuredClone cannot clone '…': its values could not be cloned.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`structuredClone` generates the copy for each type when the program is
compiled, and some types have values it cannot copy: an interface or
`unknown`, whose values may be of any class or hold functions, a channel,
a `ptr` and a `TemplateStringsArray`.

## Example

```ts
interface Named {
    name: string
}
const n: Named = { name: "ada" }
const copy = structuredClone(n)
```

## How to fix

Clone a value of an object type or of a class with only fields:

```ts
type Named = { name: string }
const n: Named = { name: "ada" }
const copy = structuredClone(n)
```
