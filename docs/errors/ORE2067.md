# ORE2067

> Constant … is not assignable to type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Numeric literal types](../spec/02-types.md#numeric-literal-types)

## What it means

A numeric literal type such as `0`, or a union of them such as
`0 | 90 | 180`, has only those numbers as values. A constant fits it only
when it equals one of them.

## Example

```ts
type Angle = 0 | 90 | 180 | 270
const a: Angle = 45
```

## How to fix

Use one of the numbers of the type:

```ts
const a: Angle = 90
```

Or, when any number will do, give the value the type `number`:

```ts
const a: number = 45
```
