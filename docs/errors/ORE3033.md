# ORE3033

> Property '…' has a setter but no getter.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The property is defined by a setter only, so it cannot be read: there is no
getter to call. This includes compound assignments such as `p.x += 1`,
which read the property first.

## Example

```ts
class Temperature {
    private c = 0.0
    set celsius(v: f64) {
        this.c = v
    }
}
const t = new Temperature()
console.log(t.celsius)
```

## How to fix

Add a getter of the same type:

```ts
class Temperature {
    private c = 0.0
    get celsius(): f64 {
        return this.c
    }
    set celsius(v: f64) {
        this.c = v
    }
}
const t = new Temperature()
console.log(t.celsius)
```
