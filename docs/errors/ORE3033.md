# ORE3033

> Property '…' has a setter but no getter.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const t = new Thing()
t.readOnly = 1
console.log(t.writeOnly)
```

`tests/diag/types/accessors.ore:33`: Property 'writeOnly' has a setter but no getter.
