# ORE3053

> Methods and accessors in object literals are not supported yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An object literal can have properties, shorthand properties and spreads.
Methods (`{ f() {} }`) and accessors (`{ get x() {} }`) in object literals
are not supported yet.

## Example

```ts
const counter = {
    count: 0,
    next() {
        return 1
    },
}
```

## How to fix

Use a property with an arrow function:

```ts
const counter = {
    count: 0,
    next: () => 1,
}
```

Or declare a class, if the method needs `this`.
