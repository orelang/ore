# ORE3053

> Accessors in object literals are not supported yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An object literal can have properties, shorthand properties, spreads and
methods; `get` and `set` accessors (`{ get x() {} }`) in object literals are
not supported yet. (Before 0.2, this message also named methods, which are
supported now.)

## Example

```ts
const temperature = {
    celsius: 20,
    get fahrenheit(): f64 {
        return 68.0
    },
}
```

## How to fix

Use a method:

```ts
const temperature = {
    celsius: 20.0,
    fahrenheit(): f64 {
        return this.celsius * 9 / 5 + 32
    },
}
console.log(temperature.fahrenheit())
```

Or declare a class, whose accessors are supported.
