# ORE3053

> Accessors in object literals are not supported yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

This message is no longer produced: an object literal can have getters and
setters now, `{ celsius: 20.0, get fahrenheit(): f64 { ... } }`, with the
rules of class accessors. Earlier versions rejected accessors in object
literals with this message.
