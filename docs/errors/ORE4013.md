# ORE4013

> No overload of '…' takes these arguments. Its signatures: ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

The function has overload signatures, and a call takes the first signature
whose parameters accept its arguments. None of them does; the message lists
the signatures.

## Example

```ts
function parse(s: string): int
function parse(s: string[]): int[]
function parse(s: string | string[]): int | int[] {
    return 0
}
const n = parse(42)
```

## How to fix

Pass arguments that one of the signatures takes, or add a signature for
them:

```ts
function parse(s: string): int
function parse(s: string[]): int[]
function parse(s: string | string[]): int | int[] {
    return 0
}
const n = parse("42")
```
