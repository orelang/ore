# ORE2014

> A rest parameter must be the last parameter, of an array type.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

In a function type, a rest parameter `...xs: T[]` collects the remaining
arguments into an array, so it must be the last parameter and have an array
type.

## Example

```ts
function setLogger(log: (...parts: string[], level: int) => void) {}
```

## How to fix

Move the rest parameter to the end, and give it an array type:

```ts
let log: (level: int, ...parts: string[]) => void = (level, ...parts) => {}
```
