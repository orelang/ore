# ORE3072

> A tuple is indexed by a constant integer.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

Each element of a tuple has its own type, so the index must be known when
the program is compiled: an integer constant. A variable index would give a
value whose type is not known.

## Example

```ts
const pair: [string, int] = ["a", 1]
let i = 0
console.log(pair[i])
```

## How to fix

Index with a constant:

```ts
const pair: [string, int] = ["a", 1]
console.log(pair[0])
```

For elements of one type indexed at run time, use an array:

```ts
const xs = [1, 2]
let i = 0
console.log(xs[i])
```
