# ORE3025

> Operator '…' cannot be applied to type '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

The operator is not defined for this type: arithmetic and `++`/`--` work on
numbers, `<` and the other orderings on numbers and strings, `!` on `bool`.
Ore does not convert operands to numbers implicitly.

## Example

```ts
let s = "1"
s++
```

## How to fix

Convert the value to a number first, for example with `Number.parseInt`:

```ts
let s = "1"
let n = Number.parseInt(s) ?? 0
n++
```
