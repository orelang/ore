# ORE4009

> Cannot convert '…' to '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Conversions](../spec/02-types.md#conversions)

## What it means

Conversions such as `i32(x)` and `f64(x)` convert between numeric types
only. Ore does not parse strings or turn `bool` into numbers implicitly;
those have their own functions.

## Example

```ts
const n = i32("42")
```

## How to fix

Parse a string with `Number.parseInt` or `Number.parseFloat`, which return
`null` when the text is not a number:

```ts
const n = Number.parseInt("42") ?? 0
```

Turn a `bool` into a number with `?:`:

```ts
let done = true
const n = done ? 1 : 0
```
