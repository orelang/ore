# ORE2066

> Type '…' exists only in computations on types: values cannot have numeric literal types, or 'never' in a tuple or an object type, yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

Numeric literal types such as `0` or `-1.5`, and `never` inside a tuple or an object type, can be used in types that compute other types, such as `Prev[D]`, `D extends number = 10` or `[D] extends [never]`. A variable, a parameter, a field or a result cannot have such a type yet.

## Example

```ts
const zero: 0 = 0
```

## How to fix

Use a number type for the value, or a union of string literal types:

```ts
const zero: int = 0
const level: "low" | "high" = "low"
```
