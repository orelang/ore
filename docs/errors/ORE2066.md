# ORE2066

> Type '…' exists only in computations on types: values cannot have 'never' in a tuple or an object type yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

`never` inside a tuple or an object type can be used in types that compute
other types, such as `[D] extends [never]`. A variable, a parameter, a field
or a result cannot have such a type yet: no value fits it.

## Example

```ts
function first(pair: [never, int]): int {
    return pair[1]
}
```

## How to fix

Leave `never` out of the type of the value:

```ts
function first(pair: [int, int]): int {
    return pair[1]
}
```
