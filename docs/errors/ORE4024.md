# ORE4024

> The second argument of 'JSON.stringify' is a replacer, and only null is supported: write 'JSON.stringify(value, null, 2)' to indent.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
const s = JSON.stringify([1], 2)
```
