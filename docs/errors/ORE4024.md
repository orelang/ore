# ORE4024

> The second argument of 'JSON.stringify' is a replacer, and only null is supported: write 'JSON.stringify(value, null, 2)' to indent.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

The second argument of `JSON.stringify` is a replacer in JavaScript, a
function or a list of keys. Ore generates the JSON code for each type when
the program is compiled, and supports only `null` there: its use is to
reach the third argument, the indentation.

## Example

```ts
const s = JSON.stringify([1, 2], 2)
```

## How to fix

Pass `null` as the replacer:

```ts
const s = JSON.stringify([1, 2], null, 2)
```

To leave out or rename fields, convert the value to an object type with the
fields you want first.
