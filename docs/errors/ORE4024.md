# ORE4024

> The second argument of 'JSON.stringify' is a replacer, null, an array of keys or a function '(key: string, value: unknown) => unknown': write 'JSON.stringify(value, null, 2)' to indent.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

The second argument of `JSON.stringify` is a replacer, as in JavaScript:
`null`, a `string[]` of the keys to keep, or a function that is given each
key and value, boxed as `unknown`, and returns the value to write instead
(`JSON.omit` to leave it out). A number there is meant as the third
argument, the indentation.

## Example

```ts
const s = JSON.stringify([1, 2], 2)
```

## How to fix

Pass `null` as the replacer, the keys to keep, or a function:

```ts
const s = JSON.stringify([1, 2], null, 2)
const t = JSON.stringify({ a: 1, b: 2 }, ["a"])
const u = JSON.stringify({ a: 1, b: 2 }, (key, value) => (key === "b" ? JSON.omit : value))
```
