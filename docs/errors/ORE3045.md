# ORE3045

> Branches of '?:' cannot be 'void'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

The two branches of `a ? b : c` have different types, and one of them is
`void`: a call that returns nothing. The result of `?:` is a value, the
union of the branches' types, and `void` has no value to be in it.

## Example

```ts
let ok = true
let n = 1
const r = ok ? console.log("yes") : n
```

## How to fix

To run one of two statements, use `if`:

```ts
let ok = true
if (ok) console.log("yes")
else console.log("no")
```
