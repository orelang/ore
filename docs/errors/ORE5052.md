# ORE5052

> Interface '…' extends itself.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

An interface cannot extend itself, directly or through other interfaces.

## Example

```ts
interface Node extends Node {}
```

## How to fix

Remove the `extends` clause; an interface can still refer to itself in its
members:

```ts
interface Node {
    next: Node | null
}
```
