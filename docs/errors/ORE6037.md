# ORE6037

> Parameter '…' must have a type annotation.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

Parameters of top-level functions, methods and constructors need type
annotations: their types are not inferred from the calls. (Parameters of
function literals can take their types from the context.)

## Example

```ts
function show(x) {
    console.log(x)
}
```

## How to fix

Annotate the parameter:

```ts
function show(x: string) {
    console.log(x)
}
```
