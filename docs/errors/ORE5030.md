# ORE5030

> Method '…' overrides a method of '…' and cannot be private.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

A method that overrides a method of the base class can be called through
the base class, so it cannot be `private`.

## Example

```ts
class Shape {
    draw() {}
}
class Square extends Shape {
    private draw() {}
}
```

## How to fix

Remove `private`:

```ts
class Shape {
    draw() {}
}
class Square extends Shape {
    draw() {}
}
```
