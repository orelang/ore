# ORE6047

> Cannot find file '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Files as text](../spec/07-modules.md#files-as-text)

## What it means

The file of a text import (`with { type: "text" }`) is read when the
program is compiled, relative to the importing module, and it does not
exist.

## Example

```ts
import notes from "./notes.txt" with { type: "text" }
```

## How to fix

Correct the path, relative to the file that imports it, or create the file:

```ts
import notes from "./notes.txt" with { type: "text" }
console.log(notes)
// file: notes.txt
remember the milk
```
