# ORE4020

> '…' needs numbers, got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

`Math.min`, `Math.max` and `Math.abs` work on numbers of any numeric type,
and keep that type. They do not compare strings or other values.

## Example

```ts
const m = Math.max("a", "b")
```

## How to fix

Pass numbers, or compare strings with `<` and `>`:

```ts
const a = "a"
const b = "b"
const m = a > b ? a : b
```
