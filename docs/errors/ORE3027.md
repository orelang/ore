# ORE3027

> Type '…' cannot be null, so this comparison is always ….

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

The value's type does not include `null`, so it is never `null` and the
comparison always has the same result. The compiler reports it because the
check is usually a mistake: either the type should include `null`, or the
check is not needed.

## Example

```ts
function greet(name: string) {
    if (name === null) return
    console.log(name)
}
```

## How to fix

Remove the check:

```ts
function greet(name: string) {
    console.log(name)
}
```

Or include `null` in the type, if the value can be missing:

```ts
function greet(name: string | null) {
    if (name === null) return
    console.log(name)
}
```
