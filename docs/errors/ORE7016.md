# ORE7016

> This statement is not supported yet.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Statements](../spec/04-functions.md#statements)

## What it means

The statement is not supported in this place. Classes and interfaces are
declared at the top level of a module, not inside functions or blocks
(type aliases can be declared in both).

## Example

```ts
function area(): f64 {
    interface Size {
        w: f64
        h: f64
    }
    return 1.0
}
```

## How to fix

Move the declaration to the top level:

```ts
interface Size {
    w: f64
    h: f64
}
function area(s: Size): f64 {
    return s.w * s.h
}
```
