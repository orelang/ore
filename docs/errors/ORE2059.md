# ORE2059

> The keys of a mapped type are string literal types, not '…'; for any string, use a Map.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

A mapped type `{ [K in Keys]: T }` makes an object type with a field for each key, so the keys must be string literal types (or a union of them). `string` stands for every string: an object type cannot have a field for each, a Map can.

## Example

```ts
type Scores = Record<string, int>
```

## How to fix

Use a Map for any string key, or list the keys:

```ts
const scores = new Map<string, int>()
type Fixed = Record<"a" | "b", int>
```
