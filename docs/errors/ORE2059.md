# ORE2059

> The keys of a mapped type are string literal types or 'string', not '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

A mapped type `{ [K in Keys]: T }` has a field for each string literal type
of `Keys`; over `string` (as `Record<string, T>`), it is a dictionary. Other
key types, such as numbers or booleans, are not property names.

## Example

```ts
type Flags = { [K in bool]: string }
```

## How to fix

Use string literal keys, `string` for a dictionary, or a `Map`:

```ts
type Flags = Map<bool, string>
```
