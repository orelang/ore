# ORE2003

> 'undefined' is not supported in Ore. Use 'null'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

Ore has one missing value, `null`, where TypeScript has both `null` and
`undefined`. Optional parameters and properties, `map.get` of a missing key
and `?.` all give `null`.

## Example

```ts
let name: string | undefined = undefined
```

## How to fix

Use `null`:

```ts
let name: string | null = null
```
