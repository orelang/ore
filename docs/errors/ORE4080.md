# ORE4080

> 'new Array(length)' needs elements with a zero value, and '…' has none. Use 'Array.from({ length }, (_, i) => ...)'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`new Array<T>(length)` fills the array with the zero value of `T`: 0 for
numbers, `false`, `""`, a new empty array, map or set, or `null` for a type
that includes it. JavaScript leaves holes there, which Ore has not. A class,
an interface, a tuple or a function has no zero value.

## Example

```ts
class Cell {
    value = 0
}
const cells = new Array<Cell>(4)
```

## How to fix

Make each element with `Array.from`, or allow `null`:

```ts
class Cell {
    value = 0
}
const cells = Array.from({ length: 4 }, (_, i) => new Cell())
const empty = new Array<Cell | null>(4)
```
