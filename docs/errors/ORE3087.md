# ORE3087

> A literal of '…' has only properties and spreads.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

A dictionary holds values, not methods or accessors: its literal has
properties and spreads only.

## Example

```ts
const d: Record<string, int> = { get a(): int { return 1 } }
```

## How to fix

```ts
const d: Record<string, int> = { a: 1 }
```
