# ORE2043

> Exponent … is too large.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

Integer constants are exact, with no limit on their size, so `a ** b` of
constants is computed in full while the program is compiled. An exponent
above 4096 would make a number too large to compute (except for a base of
0, 1 or -1).

## Example

```ts
const huge = 2 ** 10000
```

## How to fix

Use a smaller exponent, or compute with floats, where the result saturates
at `Infinity`:

```ts
const huge = 2.0 ** 10000
```
