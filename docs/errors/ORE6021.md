# ORE6021

> Generic overload signatures are not supported yet.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

Overload signatures cannot have type parameters yet.

## Example

```ts
function first<T>(xs: T[]): T
function first<T>(xs: T[]): T {
    return xs[0]
}
```

## How to fix

Write the generic function without overload signatures:

```ts
function first<T>(xs: T[]): T {
    return xs[0]
}
```
