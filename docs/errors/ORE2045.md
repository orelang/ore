# ORE2045

> Shift count … is too large.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

Integer constants are exact, with no limit on their size, so a shift of
constants is computed in full while the program is compiled. A shift count
above 1024 would make a number too large.

## Example

```ts
const x = 1 << 5000
```

## How to fix

Shift by a smaller count. A typed value can be shifted by any count at run
time: shifting by the bit width or more gives 0.

```ts
const one: u64 = 1
const x = one << 63
```
