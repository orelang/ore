# ORE4095

> '…' takes an iterable (an array, a string, a set, a map, a generator...), got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

`Object.fromEntries`, `Object.groupBy` and `Map.groupBy` take the values
they work on from an iterable, as in JavaScript: an array, a string, a set,
a map, a generator or an object with a `[Symbol.iterator]()` method. A
number or another value that is not iterable has no values to give.

## Example

```ts
const groups = Object.groupBy(5, (x) => "all")
```

## How to fix

Pass the values as an array or another iterable:

```ts
const groups = Object.groupBy([5], (x) => "all")
```
