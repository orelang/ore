# ORE6029

> The variadic arguments of a C function are i64, f64 or ptr, as C promotes them: write '...args: i64[]'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [External C functions](../spec/07-modules.md#external-c-functions)

## What it means

A rest parameter declares a variadic C function, like `printf`. C promotes
variadic arguments to `int64`-sized integers, `double` or pointers, so the
element type of the rest parameter is `i64`, `f64` or `ptr`.

## Example

```ts
declare function printf(format: string, ...args: i32[]): i32
```

## How to fix

Use one of the promoted types:

```ts
declare function printf(format: string, ...args: i64[]): i32
```
