# ORE3021

> Operator '…' requires integer operands, got '…' and '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arithmetic](../spec/02-types.md#arithmetic)

## What it means

The shifts `<<` and `>>` work on integers: the left operand of any integer
type, and the count of any integer type. A float cannot be shifted.

## Example

```ts
let x = 1.5
const y = x << 1
```

## How to fix

Convert the float to an integer type first, which truncates it:

```ts
let x = 1.5
const y = int(x) << 1
```
