# ORE7017

> 'using' must be a statement directly in a block.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Resources](../spec/04-functions.md#resources)

## What it means

A `using` resource is disposed when its block ends, so the declaration must
be a statement directly in a block, not the body of an `if` or a loop
without braces.

## Example

```ts
class Lock {
    [Symbol.dispose]() {}
}
function f(ok: bool) {
    if (ok) using l = new Lock()
}
```

## How to fix

Write the block:

```ts
class Lock {
    [Symbol.dispose]() {}
}
function f(ok: bool) {
    if (ok) {
        using l = new Lock()
    }
}
```
