# ORE6066

> Cannot import …: modules from GitHub are kept in the cache, which is off.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Modules from GitHub](../spec/07-modules.md#modules-from-github)

## What it means

Modules imported from GitHub are downloaded into the cache
(`~/.cache/ore/modules`), and the cache is off: `ORE_CACHE=off`, or there is
no home directory.

## Example

<!-- no-check -->
```ts
// ORE_CACHE=off ore run main.ore
import { x } from "https://github.com/acme/geo"
```

## How to fix

Turn the cache on, or point it to a directory with `ORE_CACHE`:

<!-- no-check -->
```ts
// ORE_CACHE=/tmp/ore-cache ore run main.ore
import { x } from "https://github.com/acme/geo"
```
