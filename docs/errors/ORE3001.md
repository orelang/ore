# ORE3001

> Field initializers cannot use 'this'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

Field initializers run while the instance is being built, before the
constructor body, and in Ore they cannot read `this`: the other fields may
not be set yet, and the compiler does not track the order in which they
are. TypeScript allows it and may read a field that is still `undefined`.

## Example

```ts
class Rect {
    width = 2
    area = this.width * 2
}
```

## How to fix

Compute the value in the constructor:

```ts
class Rect {
    width = 2
    area: int
    constructor() {
        this.area = this.width * 2
    }
}
```

Or make it a getter, computed when it is read:

```ts
class Rect {
    width = 2
    get area(): int {
        return this.width * 2
    }
}
```
