# ORE5047

> The getter and setter of '…' must have the same type, got '…' and '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A getter and a setter of the same property define one property with one
type, so the getter's result and the setter's parameter must have the same
type.

## Example

```ts
class Circle {
    get radius(): f64 {
        return 1.0
    }
    set radius(r: int) {}
}
```

## How to fix

Use the same type in both:

```ts
class Circle {
    get radius(): f64 {
        return 1.0
    }
    set radius(r: f64) {}
}
```
