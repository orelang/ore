# ORE2019

> '…' has no type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
// fs and process are implemented in Ore: their exports are members, with their types.
function f(info: fs.Stat): void {}
```

`tests/diag/library/namespaces.ore:2`: 'fs' has no type 'Stat'.
