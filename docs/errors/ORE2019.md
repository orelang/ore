# ORE2019

> '…' has no type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Built-in namespaces](../spec/02-types.md#built-in-namespaces)

## What it means

The built-in namespace (`fs`, `process`, ...) has no type with this name.
Some namespaces export types, such as `fs.FileInfo`, `process.Command` and
`process.Output`; others have only functions.

## Example

```ts
function show(info: fs.Info) {}
```

## How to fix

Use the name of a type the namespace has:

```ts
let info: fs.FileInfo | null = null
```
