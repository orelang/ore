# ORE3064

> '…' is a generic method and cannot be used as a value; call it.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Generics](../spec/03-objects.md#generics)

## What it means

A generic method is compiled once for each set of type arguments it is
called with. Without a call there is no instance, so it cannot be taken as
a bound function value, as other methods can.

## Example

```ts
class Box<T> {
    constructor(readonly value: T) {}
    map<U>(f: (x: T) => U): Box<U> {
        return new Box(f(this.value))
    }
}
const m = new Box(1).map
```

## How to fix

Wrap a call in a function of concrete types:

```ts
class Box<T> {
    constructor(readonly value: T) {}
    map<U>(f: (x: T) => U): Box<U> {
        return new Box(f(this.value))
    }
}
const b = new Box(1)
const m = (f: (x: int) => string) => b.map(f)
```
