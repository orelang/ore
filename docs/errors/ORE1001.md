# ORE1001

> Identifier expected.

Group: [Syntax](README.md#ore1xxx-syntax) · specification: [Source files](../spec/01-programs.md#source-files)

## What it means

The parser needed a name — of a variable, a property, a parameter — or the
start of an expression, and found a token that cannot begin one: an
operator, a closing bracket, or the end of the file. Ore reads exactly the
TypeScript syntax, so this is usually an incomplete expression or a stray
character.

## Example

```ts
const total = 1 +
```

## How to fix

Complete the expression, or remove the stray token:

```ts
const total = 1 + 2
```
