# ORE4048

> Cannot infer the types of the Map. Write 'new Map<K, V>()' or annotate the variable.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Maps](../spec/03-objects.md#maps)

## What it means

`new Map()` takes its key and value types from its type arguments, from
the type of the variable it is assigned to, or from the first pair it is
given. Here there is none of these.

## Example

```ts
const ages = new Map()
```

## How to fix

Give the types:

```ts
const ages = new Map<string, int>()
```

Or annotate the variable:

```ts
const ages: Map<string, int> = new Map()
```
