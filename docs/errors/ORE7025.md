# ORE7025

> Type '…' cannot be destructured as an object.

Group: [Statements](README.md#ore7xxx-statements) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
const p: Point = { x: 1, y: 2 }
const { ...rest } = 5
```

`tests/diag/functions/destructuring.ore:4`: Type 'i64' cannot be destructured as an object.
