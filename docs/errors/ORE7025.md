# ORE7025

> Type '…' cannot be destructured as an object.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Variables](../spec/02-types.md#variables)

## What it means

`...rest` in an object pattern makes a new object of the other fields. The
value here is not an object — a class instance, an object type or an
interface — so it has no fields to collect.

## Example

```ts
let n = 5
const { ...rest } = n
```

## How to fix

Destructure an object:

```ts
const p = { x: 1, y: 2 }
const { x, ...rest } = p
```
