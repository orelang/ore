# ORE1005

> Template continuation expected.

Group: [Syntax](README.md#ore1xxx-syntax) · specification: [Strings](../spec/02-types.md#strings)

## What it means

Inside a template literal, each `${` must hold one expression followed by
`}`. The parser read an expression and then found something other than the
`}` that continues the template: often two expressions, or a missing `}`.

## Example

```ts
const s = `sum: ${1 2}`
```

## How to fix

Write one expression per `${...}`:

```ts
const s = `sum: ${1 + 2}`
```
