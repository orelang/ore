# ORE7022

> Cannot infer a type from 'null'. Add a type annotation, e.g. 'let …: T | null = null'.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A variable takes the type of its initializer, and `null` alone says nothing
about the values the variable will hold later.

## Example

```ts
let current = null
```

## How to fix

Annotate the variable with a type that includes `null`:

```ts
let current: string | null = null
```
