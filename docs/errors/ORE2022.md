# ORE2022

> Only properties are supported in object types.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An object type (`type P = { ... }`) may only declare properties. Call
signatures, construct signatures and other members have no meaning for a
record of fields.

The parser of Ore reads these members as errors of their own (`'(' ...`,
[ORE2021](ORE2021.md), [ORE2046](ORE2046.md)), so this message is not
produced at present.

## Example

<!-- no-check -->
```ts
type Parser = { (text: string): int }
```

## How to fix

Declare a field of a function type instead of a call signature:

```ts
type Parser = { parse: (text: string) => int }
```
