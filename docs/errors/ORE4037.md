# ORE4037

> '…' expects a template and constraints, got … argument(s).

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

`unsafe.asm(template, constraints, ...operands)` needs at least the
assembly template and the constraint string, in LLVM's syntax.

## Example

```ts
unsafe.asm("nop")
```

## How to fix

Pass the constraints, an empty string when there are none:

```ts
unsafe.asm("nop", "")
```
