# ORE1002

> '…' expected.

Group: [Syntax](README.md#ore1xxx-syntax) · specification: [Source files](../spec/01-programs.md#source-files)

## What it means

The parser expected a particular token and found another one. The token is
named as in the TypeScript syntax: `CloseParenToken` is `)`,
`CloseBracketToken` is `]`, `CloseBraceToken` is `}`, `';'` and `':'` are
themselves. Most often a bracket is not closed, or two statements are on one
line without a `;` between them.

## Example

```ts
console.log("a", "b"
```

## How to fix

Add the missing token where the parser points:

```ts
console.log("a", "b")
```

Separate two statements on one line with `;`, or put them on their own
lines:

```ts
let a = 1; let b = 2
```
