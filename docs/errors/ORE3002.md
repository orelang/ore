# ORE3002

> A static method has no 'this'; name the class: '….name'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A static method belongs to the class, not to an instance, and is compiled as
a plain function: it has no `this`. TypeScript binds `this` to the class
object there; Ore has no class object at run time, so static members are
reached through the class name.

## Example

```ts
class Counter {
    static count = 0
    static next(): int {
        return ++this.count
    }
}
```

## How to fix

Name the class:

```ts
class Counter {
    static count = 0
    static next(): int {
        return ++Counter.count
    }
}
```
