# ORE3002

> A static method or block has no 'this'; name the class: '….name'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A static method or a `static { ... }` block belongs to the class, not to an
instance, and has no `this`: a static method is compiled as a plain
function, a block as code where the class is declared. TypeScript binds
`this` to the class object there; Ore has no class object at run time, so
static members are reached through the class name.

## Example

```ts
class Counter {
    static count = 0
    static next(): int {
        return ++this.count
    }
}
```

## How to fix

Name the class:

```ts
class Counter {
    static count = 0
    static next(): int {
        return ++Counter.count
    }
}
```
