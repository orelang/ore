# ORE4028

> '…' needs a type argument, e.g. '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

The `unsafe` function needs its type argument: there is no value from which
to infer the type, as in `unsafe.sizeOf<T>()` and `unsafe.load<T>(p)`.

## Example

```ts
const n = unsafe.sizeOf()
```

## How to fix

Give the type, as the message suggests:

```ts
const n = unsafe.sizeOf<int>()
```
