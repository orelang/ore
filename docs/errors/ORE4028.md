# ORE4028

> '…' needs a type argument, e.g. '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
const p = unsafe.alloc(16)
unsafe.load(p)
```

`tests/diag/runtime/unsafe.ore:6`: 'unsafe.load' needs a type argument, e.g. 'unsafe.load<i64>(p)'.
