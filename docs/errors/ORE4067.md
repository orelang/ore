# ORE4067

> … expects … argument(s), got ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

The function is called with a number of arguments it does not take. Ore
does not drop extra arguments or pass `undefined` for missing ones: a
parameter may be left out only when it is optional (`b?: T`) or has a
default value.

## Example

```ts
function greet(name: string) {}
greet("ada", "lovelace")
```

## How to fix

Pass the arguments the function takes:

```ts
function greet(name: string) {}
greet("ada")
```

Or declare the parameter as optional:

```ts
function greet(name: string, surname?: string) {}
greet("ada", "lovelace")
greet("ada")
```
