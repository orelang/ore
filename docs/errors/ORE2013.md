# ORE2013

> Parameters of function types need a type.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

Each parameter of a function type needs a type: a function type describes
how values are passed, and there is no `any` to fall back to.

## Example

```ts
function filter(check: (value) => bool) {}
```

## How to fix

Annotate every parameter:

```ts
let check: (value: string) => bool = (value) => value.length > 0
```
