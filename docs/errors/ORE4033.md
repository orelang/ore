# ORE4033

> '…' needs types of the same size: '…' has … bits, '…' ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
function h(): void {}

unsafe.bitcast<u32>(1.5)
```

`tests/diag/runtime/unsafe.ore:58`: 'unsafe.bitcast' needs types of the same size: 'f64' has 64 bits, 'u32' 32.
