# ORE4033

> '…' needs types of the same size: '…' has … bits, '…' ….

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

`unsafe.bitcast<T>(x)` keeps the bits of the value, so both types must have
the same size: `f64` with `u64` or `i64`, `f32` with `u32` or `i32`.

## Example

```ts
const bits = unsafe.bitcast<i32>(1.0)
```

## How to fix

Choose the integer type of the float's size, or convert the float first:

```ts
const bits = unsafe.bitcast<u64>(1.0)
const small = unsafe.bitcast<u32>(f32(1.0))
```
