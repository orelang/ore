# ORE4069

> Field '…' is not a method.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The member is a field, not a method, so it cannot be called like one. A
field that holds a function is called through a property read in
parentheses: `(o.f)()`.

## Example

```ts
class Counter {
    count = 0
}
new Counter().count()
```

## How to fix

Read the field without calling it:

```ts
class Counter {
    count = 0
}
console.log(new Counter().count)
```
