# ORE4069

> Field '…' is not a method.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The member is a field, not a method, and its type is not a function type,
so it cannot be called. A field of a function type is called like a method
(`o.f()`); a field that may be `null`, such as `f?: () => void`, is read into
a variable first and called when it is not null.

## Example

```ts
class Counter {
    count = 0
}
new Counter().count()
```

## How to fix

Read the field without calling it:

```ts
class Counter {
    count = 0
}
console.log(new Counter().count)
```

For an optional function field, call it through a variable:

```ts
type Hooks = { done?: () => void }
const hooks: Hooks = {}
const done = hooks.done
done?.()
```
