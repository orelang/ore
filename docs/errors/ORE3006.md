# ORE3006

> 'await' is not supported in Ore.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Concurrency](../spec/06-concurrency.md)

## What it means

Ore has no `async` functions and no promises. Concurrency uses tasks (green
threads) and channels, as in Go: a call that waits — on a channel, a socket,
a timer — blocks only its task, and any function can make it, without being
marked. So there is nothing to `await`.

## Example

```ts
function load(): string {
    return "data"
}
function main() {
    const data = await load()
}
```

## How to fix

Call the function directly; it returns when its result is ready:

```ts
function load(): string {
    return "data"
}
function main() {
    const data = load()
}
```

To run work at the same time, start a task and receive its result from a
channel:

```ts
function load(): string {
    return "data"
}
const result = new Chan<string>()
task.spawn(() => result.send(load()))
console.log(result.receive())
```
