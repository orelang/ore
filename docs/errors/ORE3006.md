# ORE3006

> 'await' is only allowed in async functions and in the top-level code of a module.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Concurrency](../spec/06-concurrency.md#async-functions-and-promises)

## What it means

`await` suspends an async function until a promise is fulfilled, letting the
event loop run meanwhile. A function not marked `async` runs to its end
without suspending, so it cannot await. The top-level code of a module can:
there, `await` runs the event loop until the promise is fulfilled.

## Example

```ts
async function load(): Promise<string> {
    return "data"
}
function main() {
    const data = await load()
}
```

## How to fix

Mark the function `async`; it then returns a promise of its result:

```ts
async function load(): Promise<string> {
    return "data"
}
async function main(): Promise<void> {
    const data = await load()
    console.log(data)
}
main()
```

Or use the promise's `then`:

```ts
async function load(): Promise<string> {
    return "data"
}
function main() {
    load().then((data) => console.log(data))
}
main()
```
