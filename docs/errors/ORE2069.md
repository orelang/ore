# ORE2069

> The keys of a dictionary are strings, not '…'; for other keys, use a 'Map<K, V>'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Dictionaries](../spec/03-objects.md#dictionaries)

## What it means

The keys of a dictionary are strings, as the property names of a JavaScript
object are. A number key would be turned into a string; Ore does not
convert it implicitly.

## Example

```ts
type Names = { [id: number]: string }
```

## How to fix

Use string keys, or a `Map` for other keys:

```ts
const names = new Map<int, string>()
```
