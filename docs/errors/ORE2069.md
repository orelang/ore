# ORE2069

> A rest element of type '…' is not supported: tuples have a fixed length in Ore. Spread a tuple type, or use an array.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

A tuple in Ore is a fixed number of elements, each of its own type, so a
rest element of array type, which TypeScript allows for tuples of any
length (`[int, ...string[]]`), is not supported in the type of a value. A
rest element can spread a tuple type into another one (`[...Pair, bool]`).
In the `extends` clause of a conditional type, rest elements of array type
match any number of elements: `T extends [infer H, ...unknown[]] ? H : never`.

## Example

```ts
const command: [string, ...string[]] = ["ls", "-l"]
```

## How to fix

Use a fixed tuple, or an array for the elements of any number:

```ts
const command: [string, string[]] = ["ls", ["-l"]]
```
