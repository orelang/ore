# ORE4043

> A constant is not a function.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A numeric constant is called as if it were a function.

## Example

```ts
const n = (5)()
```

## How to fix

Remove the call, or call a function.

```ts
const n = 5
```
