# ORE3088

> Type '…' is indexed by the name of a member, a string literal or a 'keyof' type.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

An object, an interface or a class instance is indexed by the names of its
members: a string literal, `p["x"]`, or a value of a `keyof` type (string
literal types), `p[k]` with `k: keyof P`. Any string could name no field.

## Example

```ts
const p = { x: 1, y: 2 }
const name: string = "x"
console.log(p[name])
```

## How to fix

Give the key a `keyof` type, or use a dictionary:

```ts
const key: keyof typeof p = "x"
console.log(p[key])
```
