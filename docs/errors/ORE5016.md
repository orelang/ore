# ORE5016

> Method '…' cannot have an implementation because it is marked abstract.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

An `abstract` method declares a method that subclasses implement; it cannot
have a body of its own.

## Example

```ts
abstract class Shape {
    abstract area(): f64 {
        return 0.0
    }
}
```

## How to fix

Remove the body, or remove `abstract` to give the method a default
implementation that subclasses may override:

```ts
abstract class Shape {
    area(): f64 {
        return 0.0
    }
}
```
