# ORE4084

> 'Array.from({ length })' needs a function to make the elements: '(_, i) => ...'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

Without a function, `Array.from({ length: n })` would be an array of `n`
`undefined` values in JavaScript, which Ore has no type for. The function
makes each element from its index (its first parameter is always null).

## Example

```ts
const squares = Array.from({ length: 4 })
```

## How to fix

Give the function, or use `new Array<T>(n)` for zero values:

```ts
const squares = Array.from({ length: 4 }, (_, i) => i * i)
const zeros = new Array<int>(4)
```
