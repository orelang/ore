# ORE6078

> The function can return here without showing that '…' is '…': it must panic or exit where the assertion does not hold.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

An assertion function (`asserts x is T` or `asserts x`) returns only when
its assertion holds: at each `return` and at its end, the checks before
must have narrowed `x` to `T` (or `x` to `true` for `asserts x`), with a
`process.panic` or `process.exit` on the other paths.

## Example

```ts
function assertText(value: unknown): asserts value is string {
    if (typeof value === "number") process.panic("a number")
}
```

## How to fix

Panic on every path where the assertion does not hold:

```ts
function assertText(value: unknown): asserts value is string {
    if (typeof value !== "string") process.panic("not a string")
}
```
