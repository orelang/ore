# ORE3038

> Cannot assign to '…' because it is not a variable.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

The name is not a variable: it names a function, a class or an import, which
cannot be reassigned.

## Example

```ts
function handler() {}
handler = () => {}
```

## How to fix

Store the function in a variable, which can be reassigned:

```ts
let handler = () => {}
handler = () => console.log("replaced")
```
