# ORE1009

> Unterminated string literal.

Group: [Syntax](README.md#ore1xxx-syntax) · specification: [Strings](../spec/02-types.md#strings)

## What it means

A string in quotes (`"..."` or `'...'`) ends at its closing quote on the
same line. A line break inside it ends the line before the string does, as
in JavaScript; a string over several lines is a template literal.

## Example

```ts
const greeting = "hello
world"
```

## How to fix

Close the string on its line, and write a line break as `\n`:

```ts
const greeting = "hello\nworld"
```

Or use a template literal, which may span lines:

```ts
const greeting = `hello
world`
```
