# ORE6062

> A recursive type alias needs an object type in its cycle: '{ next: T | null }'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

A type alias may refer to itself, directly or through other aliases, only
through an object type: the object is a reference, so `{ next: List | null }`
has a size and an end. An alias that is only arrays and unions of itself,
such as `type Nested = Nested[]`, describes no values Ore can lay out.

## Example

```ts
type Nested = Nested[]
```

## How to fix

Put an object type in the cycle:

```ts
type Nested = { items: Nested[] }
```
