# ORE3065

> … The value may be null: check it with '!== null' first, or use '?.'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
let changing: Box | null = new Box(1)
if (changing !== null) {
    const f = () => changing.value
```

`tests/diag/functions/closure-narrowing.ore:7`: Property 'value' does not exist on type 'Box | null'. The value may be null: check it with '!== null' first, or use '?.'.
