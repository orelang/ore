# ORE3065

> … The value may be null: check it with '!== null' first, or use '?.'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

The value's type includes `null`, and `null` has no properties. The
compiler does not insert a check: you decide what happens when the value is
missing.

## Example

```ts
type User = { name: string }
function show(u: User | null) {
    console.log(u.name)
}
```

## How to fix

Check for `null` first; the type is narrowed after the check:

```ts
type User = { name: string }
function show(u: User | null) {
    if (u !== null) console.log(u.name)
}
```

Or use `?.`, which gives `null` when the value is null:

```ts
type User = { name: string }
function show(u: User | null) {
    console.log(u?.name ?? "nobody")
}
```
