# ORE4063

> Generic method '…' cannot be called through 'super' yet.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

Calling a generic method of the base class through `super` is not supported
yet.

## Example

```ts
class Base {
    wrap<T>(x: T): T[] {
        return [x]
    }
}
class Derived extends Base {
    one(): int[] {
        return super.wrap(1)
    }
}
```

## How to fix

Call it through `this`, which works when the subclass does not have its own
version of the method (generic methods cannot be overridden):

```ts
class Base {
    wrap<T>(x: T): T[] {
        return [x]
    }
}
class Derived extends Base {
    one(): int[] {
        return this.wrap(1)
    }
}
```
