# ORE5050

> Duplicate type '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

Two type declarations of a module have the same name. Ore does not merge
declarations: an interface and a class, or two interfaces, with one name
are an error.

## Example

```ts
interface Point {
    x: int
}
interface Point {
    y: int
}
```

## How to fix

Declare the type once, with all its members:

```ts
interface Point {
    x: int
    y: int
}
```
