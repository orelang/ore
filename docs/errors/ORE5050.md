# ORE5050

> Duplicate type '…'.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

Two type declarations of a module have the same name. Two declarations of
an interface merge into one, as in TypeScript, but other types are not
merged: an interface and a class, two classes, or a type alias and an
interface with one name are an error.

## Example

```ts
class Point {
    x = 0
}
interface Point {
    y: int
}
```

## How to fix

Give the types different names, or declare the members in one of them:

```ts
class Point {
    x = 0
    y = 0
}
```
