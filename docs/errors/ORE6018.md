# ORE6018

> A text import has one name: 'import text from "…" with { type: "text" }'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Files as text](../spec/07-modules.md#files-as-text)

## What it means

`import name from "./file" with { type: "text" }` reads a file when the
program is compiled and declares one string constant with its contents. It
binds exactly one name, as a default import; named imports have no meaning
for a text file.

## Example

```ts
import { text } from "./hello.txt" with { type: "text" }
// file: hello.txt
hello
```

## How to fix

Bind one name:

```ts
import greeting from "./hello.txt" with { type: "text" }
console.log(greeting)
// file: hello.txt
hello
```
