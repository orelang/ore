# ORE6011

> Variable '…' is used by functions, so it must have a value where it is declared.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Programs](../spec/01-programs.md#programs)

## What it means

A top-level variable used by functions is a global: the functions may run
at any time, even before the top-level code assigns it. A variable whose
type has no zero value (a class, an object type or an interface) must
therefore be given its value where it is declared.

## Example

```ts
class Config {
    port = 80
}
let config: Config
function port(): int {
    return config.port
}
config = new Config()
```

## How to fix

Give the variable its value in the declaration:

```ts
class Config {
    port = 80
}
let config = new Config()
function port(): int {
    return config.port
}
```

Or include `null` in its type, and check it where it is used:

```ts
class Config {
    port = 80
}
let config: Config | null = null
function port(): int {
    return config?.port ?? 80
}
```
