# ORE4035

> '…' needs an object, array or map, got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

`unsafe.addressOf(x)` gives the address of an object, an array or a map,
which are references. A number is a value and has no address of its own.

## Example

```ts
const p = unsafe.addressOf(1)
```

## How to fix

Take the address of a reference, or allocate memory and store the number in
it:

```ts
let p = unsafe.alloc(8)
unsafe.store<int>(p, 1)
```
