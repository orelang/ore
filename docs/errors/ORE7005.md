# ORE7005

> A nested function needs a name and a body.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A function declared inside another function needs a name and a body. It
cannot be an overload signature.

## Example

```ts
function outer() {
    function helper(): void
}
```

## How to fix

Write the body:

```ts
function outer() {
    function helper(): void {}
    helper()
}
```
