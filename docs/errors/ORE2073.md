# ORE2073

> A dictionary has one index signature, '[key: string]: T'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Named entries](../spec/03-objects.md#named-entries)

## What it means

An index signature makes an object type a dictionary of string keys. Its
keys are strings only, so a second index signature has nothing to describe.

## Example

```ts
type Table = { [name: string]: string; [id: string]: string }
```

## How to fix

Keep one, with a union for values of several types:

```ts
type Table = { [name: string]: string | int }
```
