# ORE2042

> Division by zero.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Changed semantics](../spec/10-differences.md#changed-semantics)

## What it means

A constant expression divides by zero, with `/` or `%`. Constants are
computed when the program is compiled, so this is reported there; integer
division by zero at run time panics, and float division at run time gives
`Infinity` or `NaN`.

## Example

```ts
const ratio = 1 / 0
```

## How to fix

Correct the divisor. For an infinity, use `Number.POSITIVE_INFINITY`:

```ts
const ratio = Number.POSITIVE_INFINITY
```
