# ORE2060

> A key of a mapped type is a string literal type, not '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

The `as` clause of a mapped type renames each key; the new name must be a string literal type (or `never`, which leaves the field out).

## Example

```ts
type T = { [K in "a" as int]: int }
```

## How to fix

Make the new name a string, for example with a template literal type:

```ts
type T = { [K in "a" as `get${Capitalize<K>}`]: int }
```
