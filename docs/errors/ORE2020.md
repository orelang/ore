# ORE2020

> Module '…' has no exported type '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Modules and packages](../spec/07-modules.md#modules-and-packages)

## What it means

The module imported with `import * as m` has no exported type with this
name. Only declarations marked `export` are visible to other modules.

## Example

```ts
import * as geometry from "./geometry"
function draw(p: geometry.Pointt) {}
// file: geometry.ore
export class Point {
    x = 0
}
```

## How to fix

Correct the name, or export the type from its module:

```ts
import * as geometry from "./geometry"
let p: geometry.Point = new geometry.Point()
// file: geometry.ore
export class Point {
    x = 0
}
```
