# ORE2034

> Constant … overflows '…' (range …..…).

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
const N = 300

let a: u8 = 256
```

`tests/diag/basics/constants.ore:3`: Constant 256 overflows 'u8' (range 0..255).
