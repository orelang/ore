# ORE2034

> Constant … overflows '…' (range …..…).

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Numeric literals](../spec/02-types.md#numeric-literals)

## What it means

Numeric literals and constant expressions are exact while the program is
compiled, and take the type their context asks for. A constant that does
not fit that type is an error, rather than wrapping silently: the message
gives the type's range.

## Example

```ts
const b: u8 = 256
```

## How to fix

Use a type with a larger range:

```ts
const b: u16 = 256
```

Or, if wrapping is intended, convert a typed value (not a constant), which
keeps the low bits:

```ts
let n = 256
const b: u8 = u8(n)
```
