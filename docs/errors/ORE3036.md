# ORE3036

> Type '…' cannot be indexed.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`x[i]` with an integer index works on arrays, tuples and strings. Other
types — numbers, objects, maps — cannot be indexed: Ore has no dynamic
property access, and a `Map` uses `get` and `set`.

## Example

```ts
const count = 5
const first = count[0]
```

## How to fix

Index only strings, arrays, tuples, dictionaries and objects (by the names
of their members):

```ts
const counts = [5, 6]
const first = counts[0]
```
