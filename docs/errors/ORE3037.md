> Cannot assign to '…' because it is a read-only property.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

```ts
"abc".search(re, 1)
const x: string = re.exec("a")
re.source = "b"
```
