# ORE3037

> Cannot assign to '…' because it is a read-only property.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

The field is `readonly`: it is assigned by the constructor of the class that
declares it, and cannot change after that.

## Example

```ts
class Point {
    constructor(readonly x: int) {}
}
const p = new Point(1)
p.x = 2
```

## How to fix

Remove `readonly`, if the field should change:

```ts
class Point {
    constructor(public x: int) {}
}
const p = new Point(1)
p.x = 2
```

Or create a new object with the new value:

```ts
class Point {
    constructor(readonly x: int) {}
}
let p = new Point(1)
p = new Point(2)
```
