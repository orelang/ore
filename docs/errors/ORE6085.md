# ORE6085

> 'yield*' yields values of type '…', which type '…' does not include.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

`yield* iterable` in an async generator yields each value of the iterable
(awaited, for an iterable of promises), so the generator's value type T
must include the type of those values.

## Example

```ts
async function* names(): AsyncGenerator<string> {
    yield* [1, 2]
}
```

## How to fix

```ts
async function* names(): AsyncGenerator<string> {
    yield* ["a", "b"]
}
```
