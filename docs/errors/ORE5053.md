# ORE5053

> An interface can only extend interfaces and classes.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

The name after `extends` in an interface is not an interface or a class:
a type alias, a union or a built-in type cannot be extended. An interface
that extends a class takes the class's public fields and methods.

## Example

```ts
type Id = int | string
interface Labeled extends Id {}
```

## How to fix

Extend an interface or a class, or declare the members:

```ts
interface HasId {
    id: int | string
}
interface Labeled extends HasId {
    label: string
}
```
