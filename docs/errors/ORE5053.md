# ORE5053

> An interface can only extend interfaces.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Interfaces](../spec/03-objects.md#interfaces)

## What it means

An interface extends other interfaces only, to include their members. A
class is nominal, and an interface cannot inherit from it as in
TypeScript.

## Example

```ts
class Point {
    x = 0
}
interface Labeled extends Point {}
```

## How to fix

Declare the members in an interface, and extend that:

```ts
interface HasX {
    x: int
}
interface Labeled extends HasX {
    label: string
}
```
