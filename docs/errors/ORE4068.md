# ORE4068

> An array of '…' cannot be spread into an array of '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
const ints = [1, 2]
const strings = ["a"]
const mixed = [...ints, ...strings]
```

`tests/diag/collections/array-spread.ore:3`: An array of 'string' cannot be spread into an array of 'i64'.
