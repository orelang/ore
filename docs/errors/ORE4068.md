# ORE4068

> An array of '…' cannot be spread into an array of '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`...xs` in an array literal or in `push` copies the elements of another
array, which must have the same element type. Arrays are not covariant, and
numeric types never convert implicitly.

## Example

```ts
const xs = [1, 2]
const ys: i32[] = []
ys.push(...xs)
```

## How to fix

Convert the elements first:

```ts
const xs = [1, 2]
const ys: i32[] = []
ys.push(...xs.map((x) => i32(x)))
```
