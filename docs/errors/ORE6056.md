# ORE6056

> '//ore:threadlocal' applies to a top-level 'let' of plain names.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

`//ore:threadlocal` applies to a top-level `let` declaration of plain names
(no destructuring), each with a type and no value.

## Example

```ts
//ore:threadlocal
function depth(): int {
    return 0
}
```

## How to fix

Apply it to a variable:

```ts
//ore:threadlocal
let depth: int
```
