# ORE2062

> 'infer' declares a type only in the 'extends' clause of a conditional type.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Computed types](../spec/03-objects.md#computed-types)

## What it means

`infer X` declares a type X in the `extends` clause of a conditional type, bound to the part of the checked type it stands for; it means nothing anywhere else.

## Example

```ts
type T = infer X
```

## How to fix

Use it in a conditional type:

```ts
type Elem<T> = T extends (infer E)[] ? E : never
```
