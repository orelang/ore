# ORE5008

> Only methods can be abstract.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

Only methods can be `abstract`. Fields are inherited as they are, at the
same offsets, and cannot be overridden, so an abstract field would have no
implementation.

## Example

```ts
abstract class Shape {
    abstract sides: int
}
```

## How to fix

Declare an abstract method instead:

```ts
abstract class Shape {
    abstract sides(): int
}
```

Or a field that subclasses set in their constructor:

```ts
abstract class Shape {
    constructor(readonly sides: int) {}
}
```
