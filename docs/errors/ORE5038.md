# ORE5038

> Generic static methods are not supported yet.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

Static methods cannot have type parameters yet.

## Example

```ts
class List {
    static of<T>(x: T): T[] {
        return [x]
    }
}
```

## How to fix

Use a generic top-level function:

```ts
function listOf<T>(x: T): T[] {
    return [x]
}
```
