# ORE5038

> Generic static methods are not supported yet.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

This message is no longer produced: a static method can have type
parameters (`static of<T>(x: T): T[]`), in a generic class too, and they
are inferred from the arguments of each call as those of functions are.
Earlier versions rejected generic static methods with this message.
