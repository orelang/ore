# ORE3079

> Static fields of generic classes are not supported yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

This message is no longer produced: a generic class `C<T>` can have static
fields now, `static count = 0`, one for all its instances, as in TypeScript.
Their types cannot use the class's type parameters (see
[ORE3082](ORE3082.md)). Earlier versions rejected static fields of generic
classes with this message.
