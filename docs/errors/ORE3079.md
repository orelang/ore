# ORE3079

> Static fields of generic classes are not supported yet.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

A generic class `C<T>` can have static methods, which are shared by all its
instances and cannot use `T`. Static fields of a generic class are not
implemented yet.

## Example

```ts
class Box<T> {
    static count = 0
    constructor(public value: T) {}
}
console.log(Box.count)
```

## How to fix

Keep the value in a top-level variable next to the class:

```ts
let boxCount = 0
class Box<T> {
    constructor(public value: T) {}
}
console.log(boxCount)
```
