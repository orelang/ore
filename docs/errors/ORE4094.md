# ORE4094

> Spread arguments are not supported in a call of '…' on a union.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A method called on a union of classes takes its arguments one by one;
`...args` is not supported there yet.

## Example

```ts
class Cat {
    move(x: int, y: int): void {}
}
class Dog {
    move(x: int, y: int): void {}
}
function go(a: Cat | Dog, to: [int, int]) {
    a.move(...to)
}
```

## How to fix

Pass the arguments one by one:

```ts
class Cat {
    move(x: int, y: int): void {}
}
class Dog {
    move(x: int, y: int): void {}
}
function go(a: Cat | Dog, to: [int, int]) {
    a.move(to[0], to[1])
}
```
