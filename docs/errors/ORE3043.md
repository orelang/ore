# ORE3043

> Cannot assign to '…' because it is a constant.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Variables](../spec/02-types.md#variables)

## What it means

The name was declared with `const`, so it cannot be assigned again.

## Example

```ts
const limit = 10
limit = 20
```

## How to fix

Declare it with `let` if it changes:

```ts
let limit = 10
limit = 20
```
