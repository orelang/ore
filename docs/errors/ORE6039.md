# ORE6039

> A rest parameter must have an array type.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Functions and closures](../spec/04-functions.md#functions-and-closures)

## What it means

A rest parameter collects the extra arguments into an array, so its type is
an array type `T[]`.

## Example

```ts
function sum(...xs: int): int {
    return 0
}
```

## How to fix

Give it an array type:

```ts
function sum(...xs: int[]): int {
    return 0
}
```
