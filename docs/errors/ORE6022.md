# ORE6022

> 'async' is not supported in Ore. Use spawn() and channels.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Concurrency](../spec/06-concurrency.md)

## What it means

Ore has no `async` functions and no promises. Concurrency uses tasks (green
threads) and channels, as in Go: any function can wait — on a channel, a
socket, a timer — and only its task is blocked, so functions do not need to
be marked.

## Example

```ts
async function load(): string {
    return "data"
}
```

## How to fix

Remove `async` and return the value itself:

```ts
function load(): string {
    return "data"
}
```

To run work at the same time, start a task with `task.spawn` and send the
result over a channel:

```ts
function load(): string {
    return "data"
}
const result = new Chan<string>()
task.spawn(() => result.send(load()))
console.log(result.receive())
```
