# ORE6022

> The return type of an async function must be 'Promise<T>'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Concurrency](../spec/06-concurrency.md#async-functions-and-promises)

## What it means

An async function returns a promise at once, before its body has finished:
its declared return type is the promise, `Promise<T>`, and its `return`
statements give the value `T` (or a promise of it). Without an annotation,
the return type is `Promise<void>`.

## Example

```ts
async function count(): int {
    return 1
}
```

## How to fix

Declare the promise:

```ts
async function count(): Promise<int> {
    return 1
}
```
