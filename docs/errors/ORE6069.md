# ORE6069

> Unknown import type '…'. Use 'text' or 'json'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [JSON files](../spec/07-modules.md#json-files)

## What it means

The attribute `type` of an import says how to read the file: `"text"` as a
string, `"json"` as a JSON value. Ore knows no other types.

## Example

```ts
import data from "./data.yaml" with { type: "yaml" }
```

## How to fix

Import the file as text and parse it at run time, or convert it to JSON:

```ts
import data from "./data.json" with { type: "json" }
```
