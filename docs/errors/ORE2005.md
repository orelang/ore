# ORE2005

> A union cannot contain '…'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A union is a type of values, and `void` and `never` have no values: `void`
is the result of a function that returns nothing, `never` of one that never
returns. Neither can be a member of a union, but `void` with promises:
`void | Promise<T>`, the result of a callback that may be async, is
`Promise<T> | null`.

## Example

```ts
function find(id: int): string | void {}
```

## How to fix

To say that there may be no value, use `null`, and return it:

```ts
function find(id: int): string | null {
    return id > 0 ? "found" : null
}
```
