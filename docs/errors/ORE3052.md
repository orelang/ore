# ORE3052

> Only an object can be spread into an object literal, got '…'.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Object types](../spec/03-objects.md#object-types)

## What it means

`...x` in an object literal copies the fields of an object: an object type,
a class instance (its public fields) or an interface. Other values have no
fields to copy.

## Example

```ts
let n = 5
const o = { ...n }
```

## How to fix

Spread an object, or name the property:

```ts
let n = 5
const o = { n }
```
