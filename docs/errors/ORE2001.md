# ORE2001

> 'any' is not supported in Ore.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

Ore has no `any`. Every value has a static type that the compiler knows,
because that type decides how the value is laid out in memory and which
machine code operates on it; there is no dynamic representation that could
hold "anything" and be used without checks.

## Example

```ts
function show(value: any) {}
```

## How to fix

Name the types the value can have, as a union, and narrow it where it is
used:

```ts
function show(value: string | int) {
    if (typeof value === "string") console.log(value.toUpperCase())
    else console.log(value + 1)
}
```

When different types share the operations you need, describe them with an
interface, or make the function generic:

```ts
function first<T>(items: T[]): T {
    return items[0]
}
```
