# ORE4036

> '…' needs an integer, got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

The arithmetic atomics — `atomicAdd`, `atomicSub`, `atomicAnd`, `atomicOr`,
`atomicXor` — work on integers. `ptr` values can be loaded, stored and
exchanged atomically, but not added to.

## Example

```ts
let p = unsafe.alloc(8)
unsafe.atomicAdd(p, p)
```

## How to fix

Add an integer, or convert the pointer to an integer:

```ts
let p = unsafe.alloc(8)
unsafe.atomicAdd<u64>(p, 1)
```
