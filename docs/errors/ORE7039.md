# ORE7039

> This function takes … parameter(s), but … are expected.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Array methods](../spec/04-functions.md#array-methods)

## What it means

A function literal is passed where a function type is expected, and it
declares more parameters than that type gives. It may declare fewer: the
callbacks of array methods receive `(element, index)`, and can ignore the
index.

## Example

```ts
const xs = [1, 2]
xs.forEach((x, i, all) => {})
```

## How to fix

Declare only the parameters the function type provides, and use the array
from the enclosing scope:

```ts
const xs = [1, 2]
xs.forEach((x, i) => console.log(i, x, xs.length))
```
