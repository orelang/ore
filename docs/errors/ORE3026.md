# ORE3026

> A constant cannot be null.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

A numeric constant is compared with `null`. A constant always has a value,
so the comparison means nothing.

## Example

```ts
const missing = 0 === null
```

## How to fix

Compare a variable of a type that includes `null`:

```ts
let count: int | null = null
const missing = count === null
```
