# ORE5043

> 'super' must be called before accessing 'this' in the constructor of a derived class.

Group: [Classes and interfaces](README.md#ore5xxx-classes-and-interfaces) · specification: [Inheritance](../spec/03-objects.md#inheritance)

## What it means

In the constructor of a subclass, `this` cannot be used before
`super(...)`: the base class's part of the instance is not initialized yet.

## Example

```ts
class Shape {}
class Square extends Shape {
    side = 0
    constructor() {
        this.side = 1
        super()
    }
}
```

## How to fix

Call `super(...)` first:

```ts
class Shape {}
class Square extends Shape {
    side = 0
    constructor() {
        super()
        this.side = 1
    }
}
```
