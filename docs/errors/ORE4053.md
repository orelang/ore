# ORE4053

> Only named classes can be instantiated.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

`new` must name a class directly (`new Point()`), or through a module or
namespace (`new geometry.Point()`, `new process.Command(...)`). Classes are
not values in Ore, so `new` cannot instantiate the result of an expression.

## Example

```ts
class Point {}
const p = new (Point)()
```

## How to fix

Name the class:

```ts
class Point {}
const p = new Point()
```

To choose what to create at run time, pass a function that creates it:

```ts
class Point {}
const make = () => new Point()
const p = make()
```
