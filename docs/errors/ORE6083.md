# ORE6083

> 'yield*' takes a generator of the same value and next types: '…' and '…'.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Generators and iteration](../spec/04-functions.md#generators-and-iteration)

## What it means

`yield* other` of another generator passes the values it yields on, and
the values given to `next` to it, so both generators must have the same
value type T and next type TNext.

## Example

```ts
function* inner(): Generator<string> {
    yield "a"
}
function* outer(): Generator<int> {
    yield* inner()
}
```

## How to fix

```ts
function* inner(): Generator<int> {
    yield 1
}
function* outer(): Generator<int> {
    yield* inner()
}
```
