# ORE7034

> 'return' is only allowed in a function. Use 'process.exit()' to end the program.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Programs](../spec/01-programs.md#programs)

## What it means

The top-level code of a module is not a function, so it cannot `return`.
The program ends when the entry file's code ends, or with `process.exit()`.

## Example

```ts
if (process.args.length === 0) return
```

## How to fix

End the program with `process.exit`:

```ts
if (process.args.length === 0) process.exit(1)
```

Or put the code in a function, and call it:

```ts
function main() {
    if (process.args.length === 0) return
    console.log(process.args[0])
}
main()
```
