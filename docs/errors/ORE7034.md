# ORE7034

> 'return' is only allowed in a function. Use 'process.exit()' to end the program.

Group: [Statements](README.md#ore7xxx-statements) · specification: [04-functions.md](../spec/04-functions.md)

## Example

```ts
if (limit > 2) process.exit(0)
for (let i = 0; i < limit; i++) {
    if (i === 1) return
```
