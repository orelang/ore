# ORE4079

> Cannot infer the type of the array. Write 'new Array<T>(length)' or annotate the variable.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Arrays](../spec/02-types.md#arrays)

## What it means

`new Array(length)` makes an array of zero values, and their type comes
from a type argument or from the context, which this call has neither of.

## Example

```ts
const counts = new Array(3)
```

## How to fix

Give the element type:

```ts
const counts = new Array<int>(3)
const totals: f64[] = new Array(3)
```
