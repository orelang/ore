# ORE3073

> Tuple type '…' of length … has no element at index ….

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
let i = 0
const byVariable = t[i]
const outside = t[2]
```

`tests/diag/types/tuples.ore:6`: Tuple type '[i64, string]' of length 2 has no element at index 2.
