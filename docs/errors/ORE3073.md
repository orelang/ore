# ORE3073

> Tuple type '…' of length … has no element at index ….

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Tuples](../spec/02-types.md#tuples)

## What it means

A tuple has a fixed number of elements, known from its type, and the
constant index is past the last one. For arrays, an index out of range
panics at run time; for tuples it is found when the program is compiled.

## Example

```ts
const pair: [string, int] = ["a", 1]
console.log(pair[2])
```

## How to fix

Use an index below the tuple's length (counting from 0):

```ts
const pair: [string, int] = ["a", 1]
console.log(pair[1])
```
