# ORE2031

> Type '…' is not assignable to type '…': the value may be null. Check it with '!== null' first, or use '??' or '!'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Narrowing](../spec/03-objects.md#narrowing)

## What it means

The value has a type that includes `null`, and it is used where `null` is
not allowed. The compiler does not insert a check: you decide what happens
when the value is missing.

## Example

```ts
function greet(name: string | null): string {
    return name
}
```

## How to fix

Check for `null` first; after the check, the value's type no longer
includes it:

```ts
function greet(name: string | null): string {
    if (name === null) return "hello"
    return name
}
```

Give a default with `??`:

```ts
function greet(name: string | null): string {
    return name ?? "stranger"
}
```

Or assert that it is not null with `!`, which panics at run time if it is:

```ts
function greet(name: string | null): string {
    return name!
}
```
