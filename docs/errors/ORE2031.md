# ORE2031

> Type '…' is not assignable to type '…': the value may be null. Check it with '!== null' first, or use '??' or '!'.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [02-types.md](../spec/02-types.md)

## Example

```ts
n.set(1, 2)
n.set("a", "b")
const v: int = n.get("a")
```
