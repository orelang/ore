# ORE3041

> Only variables, fields and array elements can be assigned to.

Group: [Expressions](README.md#ore3xxx-expressions) · specification: [Variables](../spec/02-types.md#variables)

## What it means

The left side of an assignment, or the operand of `++` and `--`, must be a
place that holds a value: a variable, a field, or an element of an array or
tuple.

## Example

```ts
let a = 1
a + 1 = 2
```

## How to fix

Assign to a variable:

```ts
let a = 1
a = 2 - 1
```
