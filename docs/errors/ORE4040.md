# ORE4040

> 'unsafe.asm' can return a number or 'ptr', got '…'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

The result of inline assembly comes from a register, so its type, the type
argument of `unsafe.asm<T>`, must be a number or `ptr` (or `void` for no
result).

## Example

```ts
const s = unsafe.asm<string>("nop", "=r")
```

## How to fix

Return a number or a pointer, and convert it afterwards if needed:

```ts
const n = unsafe.asm<u64>("mov $0, #0", "=r") // arm64
```
