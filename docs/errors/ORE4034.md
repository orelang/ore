# ORE4034

> '…' needs the name of a top-level function.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [The unsafe namespace](../spec/09-unsafe.md#the-unsafe-namespace)

## What it means

`unsafe.functionAddress(f)` gives the machine address of a function, for C
callbacks and assembly. Only top-level functions have a fixed address and
no captured variables; closures, methods and function values do not.

## Example

```ts
const handler = () => 1
const p = unsafe.functionAddress(handler)
```

## How to fix

Pass the name of a top-level function:

```ts
function handler(): int {
    return 1
}
const p = unsafe.functionAddress(handler)
```
