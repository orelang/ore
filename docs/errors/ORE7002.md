# ORE7002

> 'using' needs a name and an initializer.

Group: [Statements](README.md#ore7xxx-statements) · specification: [Resources](../spec/04-functions.md#resources)

## What it means

`using` binds a resource to a name, from an initializer: `using x = value`.
The name is needed to dispose the resource when the block ends, so it
cannot be left out or destructured.

## Example

```ts
class File {
    [Symbol.dispose]() {}
}
function read() {
    using f
}
```

## How to fix

Give the resource its value:

```ts
class File {
    [Symbol.dispose]() {}
}
function read() {
    using f = new File()
}
```
