# ORE4057

> '…' is not a class.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Classes](../spec/03-objects.md#classes)

## What it means

`new` creates instances of classes. The name here is another kind of type,
such as an object type or an interface, which has no constructor: values of
those types are written as object literals.

## Example

```ts
type Point = { x: int; y: int }
const p = new Point()
```

## How to fix

Write an object literal:

```ts
type Point = { x: int; y: int }
const p: Point = { x: 0, y: 0 }
```

Or declare a class:

```ts
class Point {
    x = 0
    y = 0
}
const p = new Point()
```
