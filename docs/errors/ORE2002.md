# ORE2002

> 'unknown' is not supported yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [unknown](../spec/02-types.md#unknown)

## What it means

This message is no longer produced: `unknown` is the type of any value now,
boxed with its type, as described in the specification. Earlier versions
rejected `unknown` with this message.

## Example

<!-- no-check -->
```ts
function show(value: unknown) {}
```

## How to fix

Nothing to fix: `unknown` works. Narrow a value of type `unknown` with
`typeof` or `instanceof` before using it:

```ts
function show(value: unknown) {
    if (typeof value === "string") console.log(value.toUpperCase())
}
```
