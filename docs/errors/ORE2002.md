# ORE2002

> 'unknown' is not supported yet.

Group: [Types and constants](README.md#ore2xxx-types-and-constants) · specification: [Removed TypeScript features](../spec/10-differences.md#removed-typescript-features)

## What it means

`unknown` is planned as an explicitly boxed value that must be narrowed
before use, but it is not implemented yet.

## Example

```ts
function show(value: unknown) {}
```

## How to fix

Use a union of the types the value can have, and narrow it with `typeof`
or `instanceof`:

```ts
function show(value: string | int) {
    if (typeof value === "string") console.log(value)
}
```
