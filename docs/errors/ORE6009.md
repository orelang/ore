# ORE6009

> A thread-local variable starts at zero in each thread: write 'let name: T' with a type and no value.

Group: [Declarations, functions, generics, modules and C](README.md#ore6xxx-declarations-functions-generics-modules-and-c) · specification: [Directives](../spec/09-unsafe.md#directives)

## What it means

A thread-local variable has a separate value in each OS thread, which starts
at zero; there is no point where an initializer would run for each thread.
So it is declared with a type and without a value.

## Example

```ts
//ore:threadlocal
let depth = 0
```

## How to fix

Write the type, without a value:

```ts
//ore:threadlocal
let depth: int
```
