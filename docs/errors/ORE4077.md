# ORE4077

> '…' may be null: call it with '…?.(...)'.

Group: [Calls and built-in functions](README.md#ore4xxx-calls-and-built-in-functions) · specification: [Unions and null](../spec/03-objects.md#unions-and-null)

## What it means

The field holds a function or `null` (an optional field `start?: () => void`,
or a union with `null`), so calling it directly could call `null`. As in
TypeScript, a call of a value that may be null has to say what happens when
it is null.

## Example

```ts
class Job {
    done?: () => void
}
const job = new Job()
job.done()
```

## How to fix

Call it with `?.`, which skips the call when the field is null:

```ts
class Job {
    done?: () => void
}
const job = new Job()
job.done?.()
```

Or check it first:

```ts
class Job {
    done?: () => void
}
const job = new Job()
const done = job.done
if (done !== null) done()
```
