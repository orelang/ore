# Code of conduct

Ore follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. In short: be respectful and constructive, assume good faith,
and keep discussions about the work. Harassment of any kind is not
tolerated.

Report unacceptable behavior privately to the maintainers through
[GitHub](https://github.com/orelang/ore/security/advisories/new) or by
email to the address on the maintainers' GitHub profiles; reports are kept
confidential.
